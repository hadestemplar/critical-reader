# 08 · C 轨：非论证型文本的第二套判据

## 本层回答的唯一问题

**不做论证审查时，把它当信息或工具来用，站不站得住？**

> 本问句的**真源＝`references/00-protocol.md` §3 各层 `question` 固定表的 `LC` 行**；本处是**字面副本**，一旦与该表不一致，一律以该表为准（`docs/DECISIONS.md` #51 裁定）。

> 本文件不是 L1–L6 之外的新层，而是 C 轨在 `L1` 之后**替换 L2–L5** 的判据集（`references/00-protocol.md` §2 执行顺序：`C 轨 → L1 → C 轨判据 → L6`）。
> 一句话边界：**C 轨判的是「能不能用」，不是「说得对不对」**——因为这类文本本来就不是在论证。

## 输入

| # | 输入 | 来源 | 用途 |
|---|---|---|---|
| 1 | 原文全文 + 元数据（发布日期 / 最后更新 / 字数 / 提取覆盖率 / 采集方式） | 输入层 | C1 步骤清点、C2 时效比对、C3 密度计算 |
| 2 | `L0` 输出块（多标签体裁 + 论证性分数 + `disposition=C` + 判定理由） | L0 | 决定本层执行；体裁决定 C1 是否适用 |
| 3 | `L1` 输出块（作者可查性 / 利益相关性 / 横向核实结果 / `degraded`） | L1 | C2 的主证据来源 |
| 4 | 检索通道（`anysearch` CLI） | 环境 | C2 的横向核实动作；不可用时 `degraded=true`，C2 只能标 `无法判断` |
| 5 | `rubric/vetoes.md` | 本包 | 只取适用 C 轨的条目（R8） |

### L6 段（C 轨运行时按层序接在 `LC` 之后）

C 轨层序固定为 `L0` → `L1` → `LC` → `L6`：**不执行 L2–L5，但 L6 的否决项判定与档位分级照跑**（`references/00-protocol.md` §4 第 10 章对三条轨道都要求 L6；硬规则 9「降级传导」要求降级传导到档位；渲染侧见 `templates/report-c-track.md` 附录 A 的 `### L6 · 否决项与档位`）。本表登记 L6 块在 C 轨下的字段闭集：

| L6 字段 | C 轨允许取值 | 边界条件 |
|---|---|---|
| `layer` | `L6` | — |
| `question` | 逐字照抄 `references/00-protocol.md` §3 各层 `question` 固定表的 `L6` 行 | 不得改写 |
| `verdict` | `D` \| `C` \| `B` \| `A` \| `无法判定`（**档位即本字段**） | 与 `references/07-rating.md` R2 同源：红灯命中 → `D`；红灯为空时按 `rubric/quality-dims.md` §三 的同法计数映射落 `A` / `B` / `C`；档位合成不出来（任一层 `verdict = "无法判定"` 或 `degraded: true`，**且该层的产出按本层规则必须参与档位合成**，导致档位合成不出来）或判定者判不了 → `无法判定`；部分判据不可执行时在报告中标「条件性」（R9）；**L1 的降级不在其列**——按 `references/07-rating.md` R2 的 `L1` 行，L1 降级不压档，后果只由 `degraded` + `confidence` 承担。 |
| `gateHits[]` | 允许 `V2`–`V5` 与 `V7` / `V8` | 出现 `V1` / `V6` 即不合格（那两项要求论证要素，见 R8）；命中任一即 `verdict = D`／🔴 |
| `dims[]` | 只写 `C1` / `C2` / `C3` | 写 `D1`–`D4` 即不合格（`references/07-rating.md` R14 / R17） |
| `confidence` / `stability` | 同 `references/07-rating.md` 的字段表（v1 **不设** `calibration` 字段，见 `docs/DECISIONS.md` #58） | `stability=不稳定` 或 `=未执行` 时 `confidence` 不得为 `高` |

> `band` 字段**已废弃**（T-G6a 裁定）：C 轨的判决 = `verdict` = 档位；灯是 `verdict` 的**纯函数**（`A`→🟢、`B`→🟢、`C`→🟡、`D`→🔴、`无法判定`→🔵），映射的唯一真源见 `references/07-rating.md` R18——不设独立字段。

与 R9 是**同一条规则链**：某条判据不可执行 → 该条不参与计数 → 档位只由可执行判据产生（报告标「条件性」）→ 按 `07-rating.md` R2 的档位级条件取五值；只有三条判据**全部**不可执行（或输入残缺）时才取 `verdict = 无法判定`（第 2 章写 `🔵 无法判定 + ≤40 字理由`，第 10 章写 `无法判定 + 缺什么才能判`；`references/00-protocol.md` §4）。

## 判定规则

**R1【硬声明】报告必须逐字包含「本文未做论证审查，改按 C 轨判据评估」，并回答「为什么这篇不适合用论证审查」。**
全文不得使用「前提」「结论」「推理有效性」「谬误」这类论证审查词汇；`disposition` 必须是**带理由的判定**，不是静默门控。**禁用词只有这四个，不得扩大范围**——C 轨**允许**出现「校准」「档位」「门限」等评分制式词汇（C 轨第 2 章的标记口径见 `references/09-report-spec.md` §第 2 章：标题改中性措辞、**不追加** A / B 轨的标记串）。 **例外**——(a) 逐字引用的协议原文（如 `references/01-genre-routing.md` 体裁表的「成功标准」列）不受本节约束，但引用时必须加引号并写出出处；(b) 契约固定的章节名与字段名（`references/00-protocol.md` 第 2 章名、`templates/screening-card.md` 的栏头）不受本节约束。
〔出处：`references/00-protocol.md` 硬规则 5「C 轨换名」；`docs/DECISIONS.md` #9；`docs/research/genre-taxonomy.md` §5.2「C · 非论证型快筛」行（「不使用『前提/结论/推理有效性』这类词，避免用户误解为已做批判性审查」）与「`disposition` 必须带理由」〕

**R2 C 轨不执行 L2–L5。** 报告第 3 / 6 / 7 / 8 / 9 / 12 章一律写「无（C 轨，未做论证审查）」并注明对应判据见本文件，**章节不得省略**（第 12 章「要点提炼」的来源是 L2 + L5，C 轨两层都不执行）。
〔出处：`references/00-protocol.md` §2 执行顺序 + §4「可标「无」但不得省略」〕

**R3【可机械执行 · 计数】C1 可操作性（仅 `tutorial` / `reference` 类体裁执行）。**
五项逐条判定，每项都要落计数：
① 有序步骤数 `N_steps`（清点）；
② 每条步骤是否写明**成立条件**（判定者自己的表述，不得含禁用词；二元）；
③ 是否出现可识别的环境/版本号（正则 `\d+(\.\d+)+` 或「版本」字样，二元）；
④ 是否给出可验证的结果或验收方式（二元）；
⑤ 是否写明失败路径与限制（二元）。

C1 不适用于 `news` / `narrative` / `explanation` 类；不适用的判据必须显式写「不适用」，**不得**填「通过」以凑分。

**C1 的聚合与判定（`check`）**：只对**可执行**的项计数，① `N_steps` 只报计数、**不参与 `check`**。`N_steps = 0` → 整条记 `check=不适用`，固定字样写「不适用（无可核查步骤，`N_steps = 0`）」；体裁不适用写「不适用（体裁：`news` / `narrative` / `explanation`）」——两种「不适用」对 R9 的计数影响相同（该条不参与计数），但**书写字样必须区分**。`N_steps > 0` → 取 ②–⑤ 四项中答「是」的项数：**≥ 3/4 → `check=通过`；＝ 2/4 → `check=无法判断`（按 R9 记不可执行、不参与映射计数）；≤ 1/4 → `check=不通过`**。3/4 与 2/4 的取值为**无校准数据时的等权多数口径**（四项等权：过半即通过、正好对半即不可判、少数即不通过），**不是自定阈值**——本项目不引入任何数值阈值（`docs/DECISIONS.md` #55）。【本报告工程约定】
〔出处：`docs/research/genre-taxonomy.md` §2 表「教程/操作指南」行（Diátaxis：goal-oriented，帮助用户「correctly and safely」完成某事）与「技术参考」行（「The only purpose of a reference guide is to describe…」；「wholly authoritative」「Neutral description is the key imperative」）；Diátaxis 原文 <https://diataxis.fr/how-to-guides/>、<https://diataxis.fr/reference/>〕

**R4【可机械执行 · 计数】C2 来源可信度：横向核实是主判据，页面内特征只作问句清单。**
① 外部可点开出处计数 `N_sources`（按域名去重）；
② **横向核实动作**：离开原文去检索该来源与该主张的独立报道，记录检索词、返回的独立来源数、结论是否与原文一致；不一致 → `check=不通过`。
CRAAP 五问（Currency / Relevance / Authority / Accuracy / Purpose）只能用来**生成待查问题**，不得作为判定依据；任何 C2 判定必须落到「外部核实动作的结果」或「原文 span」上。
〔出处：`docs/research/genre-taxonomy.md` §5.2（横向核实 / SIFT 与 CRAAP 并列给出）；`docs/DECISIONS.md` #9（来源可信度核查 = CRAAP + SIFT 横向核实）；`docs/research/methodology.md` §5.2 淘汰清单「CRAAP / RADAR —— 全部判据都在页面内部，可被精心排版满足；横向阅读对照实验显示其更差且更慢」与 §3.5.2「低（作为问题清单可用，作为判定不可用）」〕

**R5【可机械执行 · 计数 + 判定】C3 信息密度：三个计数必须同时给出，且不得使用密度阈值。**
`N_units`（可识别信息单元数）、`N_words`（字数）、`N_dup`（同一信息以不同措辞重复出现的单元数）；广告 / 导购 / 导流段落占比单独清点，**只报数**，作为 `V3` 的输入、**不作本条判据**。
**C3 的判定（`check`）**：**先判** `N_units < 3` → `check=无法判断`（样本过小，比值不可信）；否则 `N_dup / N_units ≥ 一半` → `check=不通过`（信息有一半是重复的）；其余 → `check=通过`。**「一半」是无校准数据时的等权口径**（重复与不重复各半即视为信息增量失效），**不是自定阈值**——`docs/DECISIONS.md` #55 已取消 30 篇锚例校准程序，任何阈值当前不存在、也不得临时现设；本条因此**不用密度阈值**（如「每单元字数 < X」），只用一个可数的占比分界，密度比值仍只作报告里的解释性计数。【本报告工程约定】
〔出处：【本报告工程约定】；计数口径借自 `docs/research/genre-taxonomy.md` §3.3 可自动判定信号（指示词密度、步骤/代码块占比、引用密度、叙事密度）；`docs/research/methodology.md` §6.5（段落长度/句长只作难度与阅读成本指标，**禁止**当作质量或可信度指标）〕

**R6【可机械执行 · 日期比对】时效判定：三个日期与判定日期比对。**
元数据发布日期、最后更新日期、正文引用的最新年份，与判定日期比对；若某教程/参考类文章的正文明确宣称覆盖某版本/某年份，而 External 引用内容已被后续版本取代 → `check=不通过`。
〔出处：`docs/research/genre-taxonomy.md` §2 表「技术参考/说明书」行失败模式（过期、遗漏边界条件、以描述之名行推荐之实）〕

**R7 图文混排：关键信息只存在于图片 / 视频中时记 `无法判断` 并进 `unknowns[]`。**
该检查项**没有文献依据，是工程折衷**，必须随条目标注。
〔出处：`docs/research/methodology.md` §6.4（明确标注该检查项没有文献依据）〕

**R8【可机械执行 · 适用性判定】C 轨能命中的否决项是 `V2`（与标题 / 声称主题不符）、`V3`（主体为广告 / 软文 / 导流）、`V4`（零信息增量）、`V5`（正文不可用）、`V7`（无收获）与 `V8`（主张无据）。**
判定标准：**该否决项的触发条件是否要求论证要素（前提 / 结论 / 推理）**——要求的（`V1` 核心主张的支撑查无此物、`V6` 核心链断裂或核心假定未被辩护）C 轨一律不得使用；不要求的（`V2`–`V5`、`V7`、`V8`）C 轨可用。`V7` / `V8` **不得**被挡在 C 轨之外：叙述 / 访谈 / 纪实类正是这两条的典型命中面（`docs/DECISIONS.md` #56 ④ 已删除体裁豁免），排除它们等于保留另一条体裁豁免。命中即交 L6 定档 `D`／🔴，`gateHits[]` 允许出现 `V2`–`V5` 与 `V7` / `V8`（`references/07-rating.md` R17；触发条件唯一真源＝`rubric/vetoes.md`）。
〔出处：`rubric/vetoes.md` §三 逐条汇总表（每条否决项自带的「适用轨」字段）及其「C 轨适用性判据」；`docs/DECISIONS.md` #56 ④（删除体裁豁免）；`references/00-protocol.md` 硬规则 7「门禁先于总分」的执行细则（C 轨同受否决项约束，`gateHits[]` 允许出现 `V2`–`V5`、`V7`、`V8`；`V1` / `V6` 不可用）〕

**R9【可机械执行 · 映射】三条判据等权映射到档位（v1 不产出 0–120 数值），维度名 `C1` / `C2` / `C3`。**
**v1 只出档位**（`DECISIONS.md` #40、#55）：按 `rubric/quality-dims.md` §三 的**同法**处理——每条判据的取值**直接由 `check` 决定**（`通过` → `高`；`不通过` → `低`；`无法判断` → 不参与计数），再按计数映射为 `D` / `C` / `B` / `A`（**`S` 档已随 #56 ① 删除**），**不含任何待校准系数**；**C 轨不设中档**——三条判据本身是二元的（通过 / 不通过），再按「证据条数」分三值会产生伪精度（原按证据条数记中档的写法因无判定依据已删）；**档位还须按可执行判据数 `k` 封顶**（`k = 1` → 上限 `C`、`k = 2` → 上限 `B`，见下条 `verdict` 映射）；0–120 数值与任何切点**当前不存在**——校准程序已取消，样本由用户日常阅读自然积累（#55），恢复校准须重走「用户裁定 → 改写 → 契约登记」。
**某条判据不可执行时的分支（W3-06 裁定，可机械执行）**：档位与 `verdict` **只由可执行的判据产生**——不可执行的判据**不参与** `低` / `中` / `高` 与「通过 / 不通过」计数，**禁止**把它按最低档（`低`）或「不通过」计入（那属隐式兜底，会把档位从 `C` 压到 `D`）。此时报告第 10、13 章必须逐字写明：**哪条判据不可执行、原因**（如检索通道不可用）、以及「**档位为条件性，仅由可执行的判据产生**」。只有三条判据**全部**不可执行（或输入残缺）时才写 `无法判定`；存在不可执行判据时 `confidence` 不得为 `高`。
`verdict` 映射（与 `references/07-rating.md` R2 同源）：命中 `V2`–`V5` / `V7` / `V8` 任一 → `D`／🔴；无红灯时，每条判据先取值（`check=通过` → `高`；`check=不通过` → `低`；`check=无法判断` → 不可执行、不参与计数），再按 `rubric/quality-dims.md` §三 的同法计数（三条判据的 C 轨变体），**最后按可执行判据数 `k` 封顶**：设 `k` = **可执行判据数**（`check` 为「通过」或「不通过」的判据条数，`k` ∈ {0, 1, 2, 3}）——计数映射：`A` = `n_low = 0 ∧ n_high = k`；`B` = `n_low = 0 ∧ n_high ≥ ⌈k / 2⌉`；`C` = 其余（兜底档）。**档位上限封顶（取计数结果与上限中更低者）**：`k = 0`（三条**全部**不可执行）或输入残缺 → `无法判定`；`k = 1` → 上限 `C`（唯一一条可执行判据的取值不得独自把档位抬到 `B` / `A`，不论其 `check` 是通过还是不通过）；`k = 2` → 上限 `B`（两条判据全通过时按计数会得 `A`，**封顶为 `B`**）；`k = 3` → 无额外上限。部分不可执行时按可执行判据取值，并在报告标「条件性」。

## 已知局限

1. **三项判据的档位映射未经校准**：v1 只出档位、不出 0–120 数值（`DECISIONS.md` #40），映射沿用 `rubric/quality-dims.md` §三 的 `低 / 中 / 高` 三值计数法；`DECISIONS.md` #9 只定了判据名，没定权重、没定档位锚点；**#55 已取消 30 篇锚例校准程序**，样本改由用户日常阅读自然积累，故该映射在可预见的将来属【本报告工程约定】，C 轨档位只能当筛选指示，不得当作可比量。
2. **C1 只对教程 / 参考类有效**：`news` / `narrative` / `explanation` 类实际只跑 C2 + C3，维度数变化会让档位与其他篇目不可比——报告必须写出「本篇实际跑了哪几条判据」，并在标「条件性」（R9）时说明其档位不可与其他篇目直接比较。
3. **C2 依赖联网**：检索通道不可用时 C2 记「**不可执行**」，档位与 `verdict` 只由可执行判据产生并标「**条件性**」（R9）；**不得**把它按最低档位（`C`）或「不通过」计入（后者会把档位压到 `D`）、**也不得**据此把整篇退化为 `无法判定`（除非三条判据全部不可执行）。禁止伪造核查结论（#13、`00-protocol.md` 硬规则 3「L1 不得省略」）。
4. **C3 的「信息密度低」不等于「质量差」**：密度低可能是体裁特性（叙事、散文），因此 R5 禁止用单一密度阈值判不合格；该禁令与技术文献结论一致（`methodology.md` §6.5）。
