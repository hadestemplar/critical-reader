# 00 · 协议总览与接口契约

> 本文件是 critical-reader 的**接口契约**：规定六层的执行顺序、统一输出块、交付物结构与降级规则。
> 各层的判定细节在 `01-genre-routing.md` ~ `08-track-c.md`；**本文件管接缝，不管细节**。
> 改动本文件必须同步在 `docs/DECISIONS.md` 追加条目。

---

## 1. 这个协议回答什么

输入一篇中文文章（正文文本 + 元数据）→ 输出两件交付物（筛选卡 + 证据卷宗），回答四个问题：

1. **这是哪一类文本？该用哪套判据？**（L0）
2. **它在说什么？**——论题 / 结论 / 论据 / 前提假设与隐含假设（L2 + L3 合并产出）
3. **它站得住吗？**——来源、结构、假定、缺陷、证据五个角度（L1–L5）
4. **值不值得读？**——档位（L6）

**协议明确不回答**（越界即为不合格）：

| 不回答 | 原因 |
|---|---|
| 文中事实主张本身是否为真 | 需要外部检索且误判率高；只标注「需核查项」与缺失来源（`DECISIONS.md` #13） |
| 读者个人是否认同、对读者是否有用 | 属于读者相关性，不是文本属性 |
| 文章写得好不好看、修辞是否优美 | 与「值不值得读」不同构，已在调研中淘汰（#15） |
| 作者本人的信念 / 立场 / 情绪 | 审人不是审文；只作为**可选提示**，不计分（#17） |

## 2. 执行顺序与硬规则

```
L0 体裁与处置
 └─ A 轨（论证型）→ L1 → L2 → L3 → L4 → L5 → L6
 └─ B 轨（混合型）→ L1 → L2 → L3 → L4 → L5 → L6   （只审「可论证化的显式主张」）
 └─ C 轨（非论证型）→ L1 → C 轨判据 → L6          （必须显式声明「未做论证审查」）
```

硬规则（违反任一条即为协议执行失败）：

1. **顺序不可跳过**：L6 在任何前置层完成前不得给出档位。
2. **证据强制**：任何一层 `items[]` 中的条目，`evidence` 为空者**不得成条**——宁可写进 `unknowns[]`。
3. **L1 不得省略**：无网络时降级运行并标 `degraded: true` + 写明降级原因；**禁止伪造核查结论**（#13）。
4. **体裁不是硬门控**：L0 输出多标签体裁 + 论证性分数，**不得**输出单一标签后一刀切（#8）。
5. **C 轨换判据必须换名**：筛选卡须显式写明「本文未做论证审查，改按 C 轨判据评估」，不得沿用「批判性思维」名义（#9）。
6. **谬误只作提示**：L4 命中的具名谬误一律标「疑似」，不作终判、不直接扣分（#12）。
7. **门禁先于总分**：命中任一条否决项（`V1`–`V8`；`V7` 无收获、`V8` 主张无据，触发条件见 `rubric/vetoes.md`）即判 `D`/🔴，**不再进质量分级**（#6、#55、#56）。**v1 起不存在「门禁」这根独立轴**——灯与档位是同一根轴的两个形态，灯只是 `verdict` 的**协议内部一致性标记，不渲染到任何交付物**（`A`🟢 `B`🟢 `C`🟡 `D`🔴 `无法判定`🔵）。**C 轨同受否决项约束**，制式不变，但 `gateHits[]` **只允许出现 `V2`–`V5`、`V7`、`V8`**——`V1`/`V6` 的触发条件要求「前提 / 结论 / 推理」这类论证要素，C 轨文本没有这些要素，套用会系统性制造伪缺陷；而 `V7`（无收获）与 `V8`（主张无据）**不要求论证要素**，叙述 / 访谈 / 纪实类恰恰是它们的典型命中面——把这两条挡在 C 轨外，等于保留了另一条体裁豁免（#56 ④ 已删 `narrative` 豁免）（`08-track-c.md` R8；`rubric/vetoes.md` §三）。
8. **门禁触发条件唯一真源＝`rubric/vetoes.md`**：其余文件（含 `references/07-rating.md`）只许引用，**不得复述或另立条件**；两处不一致时一律以 `vetoes.md` 为准。本轮三份端到端首跑实测该链曾在三个文件里互相矛盾，导致最高阶结论只能靠执行者临场裁定。
9. **降级必须传导到档位**：任一层 `verdict: "无法判定"` 或 `degraded: true` 时，L6 **不得**给出高置信档位（`A`/`B`）；必须在筛选卡与证据卷宗里显式写出降级事实及其对档位的影响（#13）。降级导致档位合成不出时，取 `无法判定`（见 §4「红灯与 `无法判定` 的口径」）。

**编号冻结与官方短名表**（`docs/DECISIONS.md` #50、#51、#53）：

上列 1–9 的**编号从此只许末尾追加**，不得插入、重排或删号——编号是跨文件接口，不是排版细节。所有引用一律写成 `硬规则 N「短名」`，**禁止裸编号**。

**形态统一为 `「」`，不是 `（）`**：短名最常见的落点是**已经套在圆括号里的出处串**（如 `R7（§1 不回答表、硬规则 3「L1 不得省略」、#13）`），若用圆括号会形成同型嵌套 `（…（…）…）`，机械核对时难读也难正则。全库统一用全角直角引号，可机械匹配的模式是 `硬规则 \d+「[^」]+」`。注意 `「」` 在交付物里还用于**原文引用**；二者的区分靠位置——`「` 紧跟 `硬规则 N` 时是短名，其余是引用。

> **冻结记号**：`【本报告工程约定】` 读作「这是本项目的工程约定，不是学理结论」；它沿用 13 章成品形态时期的命名（该形态已由 `docs/DECISIONS.md` #76 废除），**名称不改**。机械扫描时，本记号整体按一个不可拆记号处理，不计入任何单字统计。

| 编号 | **官方短名**（引用时逐字使用） | 契约内的正式标题 |
|---|---|---|
| 1 | `顺序不可跳过` | 顺序不可跳过 |
| 2 | `证据强制` | 证据强制 |
| 3 | `L1 不得省略` | L1 不得省略 |
| 4 | `体裁不是硬门控` | 体裁不是硬门控 |
| 5 | `C 轨换名` | C 轨换判据必须换名 |
| 6 | `谬误只作提示` | 谬误只作提示 |
| 7 | `门禁先于总分` | 门禁先于总分 |
| 8 | `门禁唯一真源` | 门禁触发条件唯一真源＝`rubric/vetoes.md` |
| 9 | `降级传导` | 降级必须传导到档位 |

短名与正式标题**不同名时以本表为准**（第 5/8/9 条如此），引用时用的是短名列，不是标题列——这样第 8 条的标题里那个带反引号的路径不会渗进正文。

**短名是跨文件标识符，不是规则的描述**：规则正文被修订时，只要编号与短名未被显式重新发布，短名一律保持原样；引用方**不得**因为正文语义变了就自行改短名（#51 冻结编号，本条把短名一并纳入稳定性要求）。第 7 条即为此例：v1 分级改版（#55/#56）后它的正文重写为「红灯先于质量分级」，但短名仍是 `门禁先于总分`。

## 3. 每层的统一输出块

六层**必须**输出同构的块，便于 L6 合成与交付物渲染。

各层 `question` 字符串由下表**逐字规定**，是唯一真源；各层文件不得自行改写，也不得另行定义：

| layer | `question`（逐字，标点不得改动） |
|---|---|
| `L0` | 这是哪一类文本？该用哪套判据？ |
| `L1` | 来源是谁？有无利益与倾向？ |
| `L2` | 它到底在论证什么？链条完整吗？ |
| `L3` | 它默认了什么没说的前提？ |
| `L4` | 具体哪一步坏了？ |
| `L5` | 文中的事实主张有多硬？ |
| `L6` | 它值不值得读？ |
| `LC` | 不做论证审查时，把它当信息或工具来用，站不站得住？ |

`LC` 不是第七层，而是 **C 轨在 `L1` 之后替换 L2–L5 的判据块**（见 `08-track-c.md`）；该块内 `layer` 字段写 `LC`。

```json
{
  "layer": "L2",
  "question": "它到底在论证什么？链条完整吗？",
  "verdict": "<该层专属枚举值，见各层文件>",
  "items": [
    {
      "id": "L2-D2",
      "claim": "判定文字（一句话，可判定）",
      "evidence": "原文引用，直接摘自文章，不得改写",
      "locator": "定位信息：第 N 段 / 小标题「…」 / 第 N 节",
      "confidence": "高 | 中 | 低"
    }
  ],
  "unknowns": [
    { "item": "无法判定的项", "reason": "为什么判不了" }
  ],
  "degraded": false,
  "degradeReason": ""
}
```

字段约束：

| 字段 | 必填 | 约束 |
|---|---|---|
| `layer` | 是 | `L0`–`L6`，外加 C 轨判据块 `LC`（C 轨不执行 L2–L5，由 `LC` 块替换） |
| `items[].id` | 是 | 命名法钉死：`L<层号>-<块字母><序号>`（如 `L0-G1`、`L2-D2`）。块字母由各层自定并在本层「输出字段」表里给出对照；层内唯一，跨层不重复 |
| `question` | 是 | 必须**逐字等于**本文件 §3 上表本层行的取值，标点不得改动 |
| `verdict` | 是 | 枚举值由各层定义；枚举外取值即不合格 |
| `items[].claim` | 是 | 一句话，**可判定**（可数 / 二元 / 带明确档位边界），不得只有形容词 |
| `items[].evidence` | 是 | **原文引用**，不得改写、不得概括；空则本条不得存在 |
| `items[].locator` | 是 | 能让人回去找到那句话 |
| `items[].confidence` | 是 | 高 / 中 / 低；无依据时用「低」 |
| `unknowns[]` | 是 | 无内容时写空数组，**不得省略字段** |
| `degraded` | 是 | 布尔；无网络、输入残缺等触发 |
| `degradeReason` | 是 | 字符串；`degraded: false` 时写空串。必须写**通道名 + 失败证据**（如 `anysearch CLI 返回 429`），不得只写「失败了」 |
| `disclaimer` | 仅 `LC` 块必填 | 恒为逐字字符串 `本文未做论证审查，改按 C 轨判据评估`；不得改写、不得省略（硬规则 5「C 轨换名」/ #9） |

## 4. 交付物结构（固定）

**交付物只有两件，且必须同一次交付**（`docs/DECISIONS.md` #76）：

| # | 交付物 | 唯一规范 | 内容 |
|---|---|---|---|
| 一 | **筛选卡**（前置一页纸） | `templates/screening-card.md` | 三栏结论——「说得有道理吗」「说的是真的吗」「值得读吗」（各 `A`–`D` 四档 + 状态位）+「这篇文章在说什么」+「结构与标题」+「风险识别」（🔴／🟡／🔵）+「读它时要注意什么」+ 交付与边界。大卡 / 小卡两种形态按该模板 §0 判：**小卡 ⟺ 值得读吗 ＝ `D`**，其余一律大卡 |
| 二 | **证据卷宗** | `references/10-dossier.md` | 六层（L0–L6）的判定记录与依据：每层按该文件 §4 的统一输出块原样落条，附原文引用、缺口与降级说明（原「附录 A」的分层输出块要求原样搬到这里，见 `docs/fixwave-2.md` 簇 H1）。**缺任一层即本次交付不合格**。**卷宗的存在方式是「判定者必须生成并保留、默认不随卡交给读者、被要求时完整给出」**——它是判定的工作记录，不是成品；`templates/screening-card.md` §0 已写「**证据卷宗**：**默认不出**。它是卡的附件，只在被要求时另出」，此处与之一致 |

13 章完整报告已于 2026-10-17 废除（`docs/DECISIONS.md` #76）。

**六层判据（L0–L6）保留为内部分析步骤**：执行顺序与产出仍按 §2、§3 执行，只是其**输出形态**是证据卷宗里的分层条目，不再逐层渲染成章。分层的 `verdict`、`items[]`、`unknowns[]`、`degraded`、`degradeReason` 必须逐层原样可读（C 轨另含 `disclaimer`）。

**四要素表（论题 / 结论 / 论据 / 前提假设与隐含假设）是硬要求**（`docs/DECISIONS.md` #25）：落点为证据卷宗的 L2 + L3 条目；四项均为必填，**不得留空**。字段与引用格式由 `03-structure.md` 定义，隐含假设的**内容**由 `04-assumptions.md` 产出。原文引用的适用规则按项区分：

- **论题 / 结论 / 前提假设**：必须附原文引用；文章没有显式给出时，写「文中未显式给出」并给出**最接近的原文片段**。
- **论据**：每条必须写成 `[locator] 「原文逐字引用」`。
- **隐含假设**：按 §6 术语定义，它**没有写出来**，因此不存在可直接引用的原文。本项**豁免「必须附原文引用」**，改为强制给出三件：① 补全句 `P + 假定 ⇒ C`；② 最接近的触发片段（确无则写 `无`）；③ 「原文位置」字段取固定值 `文中未给出（隐含）`。补全句不得省略——豁免的是引用，不是可核查性。

**红灯与 `无法判定` 的口径**（`docs/DECISIONS.md` #55、#56）：

- **命中任一否决项或红灯判据（判 `D`/🔴）**：筛选卡「值得读吗」栏写 `D + 命中条目编号（V 编号）+ ≤40 字理由`；证据卷宗照常逐条列出否决项与红灯判据，档位位置写 `D`（红灯命中即档位 `D`，不存在「质量分级」这一步）。红灯是「不用读」的结论，**不是**「分数很低」——**不得**为填满字段而倒推一个可与红灯竞争的分级。
- **`无法判定` 是哨兵值（`verdict` 的第五个取值），不是第五「档」**：它表示「没有档位」，不参与排序、不参与比较、不计入任何统计，卡面一律渲染为 `—`；不得用 C 代替，不得与 C 合并。触发条件是任一层 `verdict = "无法判定"` 或 `degraded: true`，**且该层的产出按本层规则必须参与档位合成**，导致档位合成不出来。**L1 的降级不在其列**——按 `references/07-rating.md` R2 的 `L1` 行，L1 降级不压档，后果只由 `degraded` + `confidence` 承担（`docs/e2e-run-2-defects.md` G-01）。筛选卡「值得读吗」栏写 `— + 缺什么才能判`，证据卷宗写同一句话；L6 自身的 `verdict` 取第五值 `无法判定`（`07-rating.md`）。**不得**用任一默认档位填补——实测中该真空曾让三个端到端跑次各撞一次。
- **v1 不存在「总分」与「质量分」两个字段**（`docs/DECISIONS.md` #40、#55）：交付物里只有「三栏档 + 置信度」与卡上各栏的一句话理由——**不设总分行、不设质量分行，也不留「不适用」占位**。留占位等于把已废止的概念重新带回交付物；`band` 就是这么活下来的。0–120 数值与校准随锚例校准一并作废。
- **两件交付物同属一份交付**（#55）：筛选卡是前置一页纸，证据卷宗其后；**不得只交其一**。筛选卡**可以另外单独导出一份只含卡的一页纸**（便于直接转发），但**不得**以单独那份替代证据卷宗（`docs/DECISIONS.md` #62）。
- **文章元数据**（标题 / 来源 / 作者 / 日期 / 字数 / 采集方式 / 判定时间 / **判定者模型标识** / **自偏好风险**）：落点为证据卷宗的元数据区；卡面上只保留 `来源｜发表日期｜约 N 字` 与判定日期（见 `templates/screening-card.md`）。其中 **`自偏好风险`** 值域三值 —— `是` / `否` / `无法排除`：判定者模型与被判文本疑似的生成模型同族记 `是`；能确认不同族记 `否`；**判定者模型标识不可得时记 `无法排除`**（**不得**记 `是`——那会断言一个并未发生的事实），并在筛选卡「读它时要注意什么」栏写明原因。该字段只用于降置信度，**不直接扣分**。（`docs/e2e-run-2-defects.md` G-02）
- **字段与块级规则冲突时，以块级规则为准**：交付物照实写「不适用 / 不报」，**禁止**为满足栏目格式而虚构或倒推数据。

## 5. 降级与失败

| 情形 | 处理 |
|---|---|
| 无网络 / 检索通道不可用 | L1 降级：标注「来源未能外部核查」+ 记录**降级标记**（`degraded: true`，本层 `confidence` 不得为「高」；后果由硬规则 9「降级传导」在 L6 承担，**不体现为任何维度压档**）；`degradeReason` 写明。继续跑其余层 |
| 文章体裁无法归类 | L0 输出 `verdict: "混合/不确定"` + 论证性分数给区间；按 B 轨处理 |
| 正文提取不完整（截断 / 图片为主） | 元数据中标明提取覆盖率；L2 起对不可见部分一律进 `unknowns[]`，**不得推测** |
| 正文抓取不全：**仍可判** vs **不可判** | 分界：**仍能产出可判内容** → `degraded: true` 并继续跑其余层；**抓不到可判正文**（可读中文 <300 字 / 导航广告占比超一半 / 中途截断 / 整篇乱码）→ 落 `V5` 否决项（判 `D`/🔴），并在筛选卡「值得读吗」栏写明「`D`/🔴 在这里是『不进流水线』，不是『文章差』」。该分工为【本报告工程约定】 |
| 某一层完全无法产出 | 该层 `verdict: "无法判定"`，`items: []`，原因写进 `unknowns[]`；证据卷宗显式声明该层缺失，L6 不得据此给高置信档位 |
| 输入过长（>3 万字） | 分块处理，但四要素与否决项判定必须基于全文；分块策略与覆盖率写进证据卷宗的成本与局限条目 |

## 6. 术语

| 术语 | 本协议中的含义 |
|---|---|
| **论题** | 文章要回答的那个问题；可加问号还原 |
| **结论** | 作者对该问题的回答 |
| **论据** | 支持结论的理由与证据 |
| **前提假设** | 论证成立需要、但文中已经写出来的前提 |
| **隐含假设** | 论证成立需要、但文中**没有写出来**的前提（L3 的主要产出） |
| **论证性分数** | 0–1，文章在多大程度上依赖显式论证来支撑结论（L0 产出） |
| **轨**（`A 轨` / `B 轨` / `C 轨`） | L0 的分流结果，决定**用哪套判据看**：`A 轨`/`B 轨` 走 L2–L5 论证审查，`C 轨` 换用 C 轨判据（`LC` 块）并禁用四个论证审查词（硬规则 5「C 轨换名」、`08-track-c.md`）。**轨 ≠ 档**：轨是「看什么」，档是「值不值得读」。`A`/`B`/`C` 三个字母**同时**出现在两套命名里（`C 轨` vs `C 档`），因此引用时**必须带「轨」或「档」后缀**——裸写单个字母在协议与交付物里都算不合格引用 |
| **否决项**（v1 前称「门禁」） | `V1`–`V8`（`V7` 无收获、`V8` 主张无据）。命中任一项即判 `D`/🔴，不再进质量分级。**v1 起不存在独立的「门禁」轴，也没有门限值**（`DECISIONS.md` #55、#56）；触发条件唯一真源是 `rubric/vetoes.md`（硬规则 8「门禁唯一真源」） |
| **档位**（v1 前称「质量分 / 档带」） | v1 的结论形态，五值闭集：`A`（很好，值得精读）/ `B`（值得读）/ `C`（合格门槛，可以看）/ `D`（不用读）/ `无法判定`（哨兵值：没有档位，不得用 C 代替；不参与排序、比较与统计）。**灯是 `verdict` 的纯函数，只供协议内部一致性检查，不渲染到交付物**：`A`🟢 `B`🟢 `C`🟡 `D`🔴 `无法判定`🔵。**档位锚点**（每档「这类文章长什么样」的文字特征）定义在 `rubric/quality-dims.md` §二；**对 A / B 轨**，锚点是判定的必要条件——**指不出锚点特征的档位判定不成立**。**C 轨的档位锚点不是论证特征**：C 轨的档位由 `references/08-track-c.md` R9 的三条判据计数产生，其「锚点」是三条判据的取值组合，不以论证特征为必要条件（见 `rubric/quality-dims.md` §二 末段；`docs/e2e-run-2-defects.md` G-03）。`S` 档与 0–120 数值已于 v1 一并作废（`DECISIONS.md` #55） |
| **span** | 交付物中被判定对象对应的原文片段，必须逐字引用 |
