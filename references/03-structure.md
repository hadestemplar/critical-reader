# 03 · L2 结构完整性

## 本层回答的唯一问题

它到底在论证什么？链条完整吗？

> 该字符串逐字取自 `references/00-protocol.md` §3 每层的统一输出块「各层 question 固定表」的 `L2` 行（唯一真源，见 `DECISIONS.md` #26①）。另：本层与 L3 的四要素分工已由 §7 与 `docs/PLAN.md` §四验收标准表 D1 第 ④ 项统一（见 `DECISIONS.md` #26⑤）。

## 输入

| 输入项 | 必需 | 说明 |
|---|---|---|
| 正文全文 | 是 | 逐段可定位（段落编号 / 小标题）；提取覆盖率 < 100% 时必须给出覆盖率 |
| 元数据 | 是 | 标题 / 来源 / 日期 / 字数（用于判断是否分块；>3 万字时按 `references/00-protocol.md` §5 降级与失败「输入过长（>3 万字）」行分块） |
| L0 输出 | 是 | `verdict`（取值集合以 `01-genre-routing.md` 为准：`A 轨` / `B 轨` / `C 轨` / `混合/不确定` / `无法判定`）、多标签体裁与分数、论证性分数。**C 轨跳过 L2–L5**，本层不执行论证判据，只填四要素表的 1–3 项；**「跳过论证判据」不等于免检**——C 轨仍须由 L6 判 `V7`（无收获）/ `V8`（主张无据）（`DECISIONS.md` #56③④） |
| L1 输出 | 否 | 来源信息可用于理解「结论是谁的」，但**不参与**本层判定 |
| 本层不挖隐含假设 | —— | 隐含假设是 L3 的产出（`references/00-protocol.md` §7 各层文件与负责人边界）；本层只保留字段占位 |

## 输出字段

沿用 `references/00-protocol.md` §3 每层的统一输出块。除标准条目外，本层**必须**产出「四要素表」，其落点为**证据卷宗的 L2 + L3 条目**（`references/00-protocol.md` §4 交付物结构；形状见 `references/10-dossier.md`；`DECISIONS.md` #25）。

四要素表（固定 5 行，逐行必填，不得留空）：

| 行 | 字段 | 取值 / 格式 |
|---|---|---|
| 1 | 论题 | 1 条；原文引用 or `文中未显式给出` + 最接近的原文片段 |
| 2 | 结论 | 1 条；原文引用 |
| 3 | 论据 | 编号列表，≥1 条；每条 `[locator] 「原文逐字引用」` |
| 4 | 前提假设（文中已写出的） | 0–n 条；0 条时必须写 `文中未显式给出` |
| 5 | 隐含假设（由 L3 填） | 本层固定写 `见 L3` 占位，**不得**自行填写内容 |

`verdict`（枚举，必取其一）：

| 取值 | 判定条件 |
|---|---|
| `链条完整` | `claim` / `grounds` / `warrant` 三要素均在原文中找到逐字 span，且论题还原测试（L2-R2）通过，且论据 ≥1 条且非结论复述 |
| `链条残缺` | 三要素中缺 ≥1 项，或论据 = 0 条，或论题还原测试不通过 |
| `实为解释` | Toulmin 缺 `warrant`，且删除测试显示被当作前提的句子删除后结论可信度不下降 |
| `无显式论证` | 全文找不到可还原为「主张 + 理由」的段落（常见于消息、教程、叙事类，此类通常已在 L0 落 C 轨；**落 C 轨不等于合格**，仍须由 L6 判 `V7`/`V8`，`DECISIONS.md` #56④） |
| `无法判定` | 正文覆盖率 < 30%、截断、乱码 → `items: []`，原因写进 `unknowns[]` |

## 判定规则

- **L2-R1（Toulmin 五要素填空，0–5 计数）** 逐项填空并要求逐字 span：`claim`（主张）｜`grounds`（理由/数据）｜`warrant`（保证：理由为何能支持主张）｜`qualifier`（限定词：在什么范围内成立）｜`rebuttal`（例外/反例处理）。填不出的项写 `文中未给出`，**不得代作者补写**；缺少 `qualifier` / `rebuttal` 只记录、不单独扣分。【出处：`docs/research/methodology.md` §5.1 L2 行、§7.3 表（指南缺 qualifier/rebuttal，需从 Toulmin 补）、§8.2 第 3 条（填充率待实测）】
- **L2-R2（可机械执行：论题还原测试）** 把结论句加上问号，检查能否还原为文章开头或结尾提出的问题：能还原 → 对齐；不能 → 标「论题—结论未对齐（答非所问 / 偷换论题）」。二元判定，必须同时给出**结论 span** 与**论题 span**（或 `文中未显式给出` 的最近片段）两处原文。【出处：参考指南 L70「结论加个问号等于论题吗？有没有正面回答问题？」、L60–L63、L65–L68；`docs/research/methodology.md` §7.1 第 3 条、§7.3 表（对应 Stasis 层级定位）】
- **L2-R3（可机械执行：删除测试）** 对每个候选前提句执行「删掉这一句之后，结论是否仍被支持 / 可信度是否下降」：不下降 → 该句不是论据（属背景、解释或复述），不得记入论据；下降 → 记为论据。执行范围限定在**核心论证链 ≤ 5 个节点**，不逐段做全文映射。删除测试是最终判据，「因为」类标记只是候选定位器。【出处：`docs/research/methodology.md` §6.1（「因为」只能作候选定位器，最终判定回到删除测试）、§7.4（删除测试替换「因为」放置法）、§5.2（全文 Argument Mapping 已淘汰，只对核心链做轻量映射）、§8.2 第 2 条（节点上限待实测）；N=5 ＝【本报告工程约定】】
- **L2-R4（可机械执行：论证 vs 解释分流）** 对文中每个「因为 / 由于 / 所以 / 因此」类引导句按下列顺序判定：
  1. 引导的是**结果**（如「他一定很勇敢，因为他从不抱怨」）→ 属辩护（提出立场），计为论证；
  2. 引导的是**原因**且该事实在文中被当作已确立的共识 → 进删除测试（L2-R3）兜底，通过则记为论证，不通过则记为解释；
  3. 为**他人**的行为或心理给理由 → 判为解释，不计为论证。
  **命中解释形态时必须在 `items` 写明「该句把结论变成默认前提，未独立支持结论」。**【出处：`docs/research/genre-taxonomy.md` §1.5（Houtlosser 对「because」三种用法的分析）；参考指南 L122–L127（「解释的存在其实是一个陷阱，它并没有证明结论确实成立，而是把结论变成了默认的前提」）；`docs/research/methodology.md` §7.1 第 1 条、§7.4】
- **L2-R5（可机械执行：论据独立性与条数）** ① 论据条数必须 ≥1，否则 `verdict` 不得为 `链条完整`；② 单条论据若与结论句共享 ≥70% 实词且未提供新信息，判为**结论复述**，不计为论据。【出处：参考指南 L78–L80（「结论必须有论证支撑……才有资格被称为『结论』」）；70% ＝【本报告工程约定】】
- **L2-R6（可机械执行：结论先行检测）** 计算结论句首次出现位置 ÷ 全文段落数：`< 0.20` 且其后段落新增论据数为 `0` → 标「结论先行」，条目须写明「后续理由是维护结论，而非推导结论」。【出处：参考指南 L87–L91；0.20 与「新增论据数 = 0」＝【本报告工程约定】】
- **L2-R7（四要素抽取规则；`docs/PLAN.md` §四验收标准表 D1 第 ④ 项硬要求）**
  - **论题**：① 正文有提问句 → 直接取该句；② 无提问句 → 由结论倒推（「要回答什么问题才会得出这个结论」）；③ 倒推不出 → 写 `文中未显式给出` + 最接近的原文片段。**条数恒为 1。**
  - **结论**：取作者明确表态的判断句（可含「我认为 / 应该 / 必须 / 说明」等表态标记）；**条数恒为 1**；文中多结论时取全文最终回答论题的那一条，其余记入 `unknowns[]`。
  - **论据**：通过 L2-R3 删除测试的全部前提句，逐条编号（`E1`、`E2`…），每条附原文引用。
  - **前提假设（文中显式写出）**：文中写出、但自身未获论证的支撑句（即作者直接当作起点用的句子）；0 条时写 `文中未显式给出`。
  - **隐含假设**：**本层不产出**，固定写 `见 L3`；本层只负责把 L0/L1 与 L3 的字段接上（`references/00-protocol.md` §7 各层文件与负责人边界（`03-structure.md`/`04-assumptions.md` 两行）；`references/00-protocol.md` §4 交付物结构：四要素表的落点为**证据卷宗的 L2 + L3 条目**，其来源标注「L2 + L3」（形状见 `references/10-dossier.md`））。【出处：参考指南 L60–L70、L72–L80、L94–L107、L155–L157；`references/00-protocol.md` §4 交付物结构（四要素表落点＝证据卷宗 L2 + L3 条目）、§7 各层文件与负责人边界；`DECISIONS.md` #25】
- **L2-R8（原文引用格式；`docs/PLAN.md` §四验收标准表 D1 第 ④ 项硬要求）** 所有引用按固定格式书写：`[locator] 「原文逐字引用」`
  - `locator` 取值闭集：`第 N 段`｜`小标题「…」`｜`第 N 节`｜`行 N`（源文件行号）——四选一，**不得自造第五种**；**自然段边界不可判时**（如微信转 Markdown、`![图N]` 与文字行交错）**必须用 `行 N`**，不得估计段号；
  - **「段」的定义**：`第 N 段` 中的「段」＝**由空行分隔的连续非空行块**（段号从 1 起、按正文自上而下计数；同一块内可含多行文字、代码围栏或图片行）。`paragraphs` 字段是**正文非空行数**，**不是**自然段数，两者不得互算。【出处：`docs/e2e-run-2-defects.md` G-15；「段」的定义＝【本报告工程约定】】
  - 引用必须**逐字**，不得改写、不得概括、不得拼接不同位置的句子；超过 60 字可截断，但截断必须保留首尾逐字并以 `…` 结尾；
  - 每条引用后附 `confidence: 高|中|低`；无依据时用「低」；
  - **`evidence` 为空的条目不得成条**——宁可写进 `unknowns[]`。【出处：`references/00-protocol.md` §2 硬规则 2「证据强制」、§3 每层的统一输出块（字段约束表）、§6 术语「span」；`DECISIONS.md` #11；60 字上限＝【本报告工程约定】】
- **L2-R9（论题类型二元标注）** 论题必须标为 `事实判断型`（关于世界过去/现在/未来是什么样）或 `价值主张型`（关于世界应该是什么样），二者必取其一，供 L3 的价值型假定分流使用。【出处：参考指南 L54–L58】

## 已知局限

1. **四要素表第 5 项（隐含假设）依赖 L3（摩擦点已关闭）**：`references/00-protocol.md` §7 各层文件与负责人边界、`docs/PLAN.md` §四验收标准表 D1 第 ④ 项现已采用同一措辞——「L2 定四要素表的字段、引用格式与第 1–4 项规则；第 5 项由 L3 填，L2 只留占位 `见 L3`」，本层自己不挖隐含假设（`DECISIONS.md` #26⑤）。
2. **Toulmin 六要素的人工一致性 κ 未找到实证**（`docs/research/methodology.md` §8.1 第 8 条），本层的「填空率」只是过程指标，不是质量指标。
3. **中文公众号文章的 Toulmin 填充率可能只有 2–3 项**；是否需要「缺项不扣分、只记录」尚待实测（`docs/research/methodology.md` §8.2 第 3 条）。本层已按「只记录、不单独扣分」设计。
4. **删除测试的成本随段落数线性增长**，是否必须限定核心链节点数待实测（`docs/research/methodology.md` §8.2 第 2 条）；N=5 是工程折衷，非实证最优。
5. **「因为」的语用歧义无法完全消除**：Houtlosser 的结论是「判断某个『because』是推论性还是因果性本身就很困难」（`docs/research/genre-taxonomy.md` §1.5）；因此 L2-R4 之外必须有 L2-R3 兜底。
6. **中文零形回指**导致「研究表明」类无主语主张无法定位来源，本层只能记录、不能补全（`docs/research/methodology.md` §6.2；§8.1 第 3 条：零形回指密度与质量的相关性无实证）。
7. **中文语料缺口**：L2 判据从英文文献移植，无针对中文公众号文章的论证质量标注语料，只能靠锚例校准补偿（`docs/research/methodology.md` §5.3④、§6；`docs/PLAN.md` 第六节风险表）。
8. **本层不做的事（越界即不合格）**：不挖隐含假设（交 L3）、不判缺陷与谬误（交 L4）、不判证据真假（交 L5 + 人工核查）、不给分、不下档位/灯（交 L6，`DECISIONS.md` #56①②）。
