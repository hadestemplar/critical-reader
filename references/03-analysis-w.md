# 03 · `W` 轴：站得住

**`W` 轴只问一件事：从「文中给出的」前提，能不能推到「文中宣布的」结论；而且推的是不是「文章自己提的那个问题」。**（`docs/research/00-foundations.md:341`）

**输入范围：全部在文本内。** 本轴**不含**前提是否为真（那是 `C` 轴）、不含文笔与修辞、不含是否新（那是 `V` 轴）、不含作者动机。这条分界有出处：`Wachsmuth et al. 2017` 逐字 "It replaces truth, which is often unclear" ⇒ 可接受性在 `W` 侧、真假在 `C` 侧（`docs/research/00-foundations.md:347`）。**因此同一段原文可以同时进两条轴：重复的是判定动作，不是原文。**

本文件不写外部检索（`references/04-analysis-c.md`）、不写「对读者有没有用」（`references/05-analysis-v.md`）、不写红灯的触发条件（`references/07-redlines.md`，唯一真源）、不写状态位闭集（`templates/screening-card.md` §状态位，唯一真源）。

---

## §0 判定对象是论题，不是文章

本轴的判定对象是 `references/02-claim-split.md` §3 那张表里的**每一条论题**。没有那张表，本轴没有判定对象。

**逐条判，然后聚合。** 不允许先给整篇文章一个 `W` 结论，再回头找证据。

## §1 支撑四问

对一个主张只问一件事——**支撑够不够**；而「够不够」**永远只有四个方向，没有第五个**（`docs/error-casebook.md:32`）：

| 方向 | 判定时要问的 | 学理名字 |
|---|---|---|
| **前提** | 它还依赖什么没被说出来的东西（换一种问法：**它必须先成立什么**） | 保证（warrant）／隐含前提 |
| **范围** | 它在哪些情形下成立 | 领域的依赖性（field-dependence） |
| **边界** | 推到哪儿就过头了 | 过度推广 |
| **反例** | 有没有反着的情况 | 可证伪性 |

（表格逐字取自 `docs/error-casebook.md:36-39`；「它必须先成立什么」是本文件给「前提」一问的操作性问法，不改变该问的内容。）

**这四个方向不是一张检查表，是「支撑」这个概念本身的四个面。任何一个主张，只要有一个面是空的，支撑就不够；四个面都在，才算闭合。**（`docs/error-casebook.md:41`）

**学理归口**（`docs/error-casebook.md:184`）：支撑四问＝保证（warrant）＋ 领域依赖 ＋ 充分性（sufficiency）＋ 可证伪——**四问本身是学理，不是本项目的发明**。

## §2 三条硬判据

三条**不需要另外记忆**，它们是四问的直接推论（`docs/error-casebook.md:43-47`）：

| 硬判据 | 内容（逐字） | 违反时的后果 |
|---|---|---|
| **H1 · 换题** | 若论据证明的是 A、论题要的是 B，这不是「不够充分」，是**换了论题**，直接不合格。**可判定形态（对照）：两组对照必须来自同一总体**——若论据里的两组在关键属性上不属于同一个总体，则论据证的是「对另一组人的事实」，不是本文要的结论，按换题处理 | 该论题记 `D`；若该论题承重，轴层记 `D` |
| **H2 · 全称句** | 「最」「唯一」「必然」「一定」这类全称句，只要一个反例就倒——**所以碰到它们必须主动去找那个反例** | 找不到反例 ⇒ 该环节闭合（记通过）；找到一个 ⇒ 该论题按其承重性记 `C` 或 `D`。**「找不到」必须附检索证据，见 §4** |
| **H3 · 类比不是论据** | 类比、比喻、故事不是支撑——它们只能提出「这里需要一条理由」，不能提供理由 | 一条论题若**唯一**的支撑是类比／比喻／故事，按「零支撑」处理 |

**H3 的学理**：类比论证是似真推理，不构成演绎支撑（`docs/error-casebook.md:185`）。

**「对照可比性」不是独立判据，是 `H1` 的一个形态。** 它曾作为一项出现在 `references/01-purpose-routing.md` §2 的判据族清单里，但那份清单对它没有定义、本文件也没有引用过它——一个没有判据的词不能留在协议里。它要拦的事与 `H1` 是同一件事：对照组与结论所指的那组人不是同一个总体，论据就证了另一个命题。因此它并入 `H1`（见上表「可判定形态（对照）」），**不再单列、不再出现在判据族清单里**。

## §3 单条论题怎么判：先判承重，再判档位

### 3.1 先判这条论题承不承重

**判据：把这条论题（或这一环）抽掉之后，主论题还成不成立。**（`templates/screening-card.md:66`）

- 抽掉就塌 ⇒ **承重**。它出问题，整栏降档。
- 抽掉不影响 ⇒ **非承重**（引子、举例、顺带推广、外挂）。它出问题，只降不塌。

**由判定者直接判，不设机械判据**；判完必须在卡上写出「哪条是承重、抽掉会怎样」，让读卡的人能复核这个判断（`templates/screening-card.md:71`）。

### 3.2 再判档位

四档的**轴层**含义见 `templates/screening-card.md` §1「说得有道理吗」。逐条论题的档位按同一套语义落到单条上：

| 档 | 单条论题的判据 |
|---|---|
| **`A`** | 四问全部闭合：有明确论据；论据与该论题之间通过**真值改变测试**；范围与边界被写明；可预见反例被处理；该论题与其论据之间无自相矛盾 |
| **`B`** | 该论题的支撑主干通，断点只在**非承重**位置（引子、举例、顺带推广、外挂），不改变该论题的结论 |
| **`C`** | 有一处**承重环节**没接上——缺必要前提 / 论据不足以支撑 / 全称句找不到反例 / 承重链局部矛盾——**但该论题本身没被换掉** |
| **`D`** | **结构性失效**，四种形态任一：① 换题（`H1`，含「整篇为另一个问题给出完整论证」）；② 承重论题**零支撑**（且未被可接受性豁免，见 §4）；③ 承重链自相矛盾；④ 承重结论依赖一条未被辩护的承重假定 |

**判序即判定顺序**（`docs/research/00-foundations.md:344`）：

1. 承重论题清单（≤5 条，取自文章自己的主张句）
2. 结构：每条承重论题至少有一条论据指向它
3. **真值改变测试**：把前提的真值由真改假，结论的真值是否改变
4. 充分性：论据合起来够不够
5. 一致性：同一实体的关键数字／事实在文内是否互相冲突
6. 换题检查：全文各段的结论是否指向**同一个**主张
7. 可预见反例：文章自设论题的最强反对意见是否被处理

**第 7 步的出处逐字**：`Global sufficiency`「Argumentation is sufficient if it adequately rebuts those counterarguments to it **that can be anticipated**.」（`docs/research/00-foundations.md:75`）

**第 3 步的出处逐字**：`Hoffmann & Catrambone 2023`（`Informal Logic` 43(1) 23–90，DOI `10.22329/il.v43i1.7076`）4.5 问句「Does your assessment regarding the truth of the conclusion change if you change the truth value of the premise from true to false?」（`docs/research/00-foundations.md:155`）。中文落地四步见 `docs/research/00-foundations.md:164`：前提命题化 → 换成 ¬P → 只问「其余不变，本文对 C 的支持是否下降」→ 同义反复例外。**步骤 0「前提命题化」是该测试最大的失效点**，逐字登记在同处。

**第 6 步的出处逐字**：`Global relevance`「Argumentation is relevant if it contributes to **the issue's resolution**…」（`docs/research/00-foundations.md:73`）。这一条正是「整篇答了另一个问题，在前提↔结论之间却可以拿满分」的接住位置（`docs/research/00-foundations.md:78`）。

## §4 举证门槛：「没有 X」必须带证据

### 4.1 举证门槛随主张强度变（用户裁定 `#75`）

**举证门槛 ＝ 反常度 × 读者信错的代价**：两个都小 ⇒ 不举证无妨；反常度大 或 代价大 ⇒ 必须举证（`docs/DECISIONS.md:141`）。

**这条是工程约定，不是学理**：学理只给「反常度」这一因子（非凡主张命题）与「举证责任随对话类型变」（Walton），「信错代价」来自决策论，两者相乘是合成（同处逐字登记）。

**因此本轴不得对每个主张一律要论据。** 论证评价的三判据是相关性 / **可接受性** / 充分性；**可接受性的定义即「属于常识或受众共识的前提已算通过」，举证义务根本没被触发**（`docs/DECISIONS.md:141`）。对每个主张一律要论据，等于扔掉可接受性、只剩充分性。

**「核起来贵」推不出「作者可以不举证」**——它只推出「我们不必每条都去核」（同处）。

### 4.2 「文章没有 X」的证据义务（硬约束）

**报告「文章没有论据 / 没有反例 / 没有处理 X」之前，必须同时给出检索方式与命中数为 0 的证据。**（`docs/DECISIONS.md:141`）

这条是上一轮真错过的形态：把「我没抽到」当成「文章没有」，把全篇论证最完整的一节判成「没有论据」（同处）。**本轴任何一处写「未处理某个反例」，都必须带：检索方式（怎么找的）+ 命中数（0 条）+ 检的范围（哪几节）。缺任一项，该判定作废，改写为「本跑次未检到，见证据卷宗」。**

**与 `H2` 的接口**：全称句必须主动找反例——「找过、命中 0 条」是**闭合**，「没找」不是。

## §5 聚合：多条论题 → 轴层一个档

### 5.1 主规则：承重优先

**轴层档位 ＝ 承重论题里最差的那一条。只有承重全为 `A` 时，才让非承重论题把档位拉下来。**

1. **承重优先**（承重论题 ≥ 1 条时，只看承重；非承重在这一步不参与）：
   - 任一承重论题 `D` ⇒ 轴层 `D`
   - 否则任一承重论题 `C` ⇒ 轴层 `C`
   - 否则任一承重论题 `B` ⇒ 轴层 `B`
   - 否则（承重全为 `A`）⇒ 进第 2 步
2. **承重全 `A` 时，才看非承重**：
   - 非承重全 `A` ⇒ 轴层 `A`
   - 非承重有断点 ⇒ 轴层 `B`

**承重论题为 0 条**时本条不适用：那说明 §3.1 没判出承重结论，按 `references/01-purpose-routing.md` §3 走 Step 1 → Step 3 落 `P0` 兜底，本轴按 §6 处置（不出档）。

**归类：模型推论，不是工程约定**（分类口径按 `#74` 的闸门，`docs/DECISIONS.md:137`）。推出链三步，不需要新出处：

1. 模型一要求先切主张、并给每条主张一个身份——主论题 / 独立论题 / 纯建议（`references/02-claim-split.md` §2；出处 `docs/error-casebook.md:28`）。
2. 承重与非承重**不是同一种东西**：承重论题被抽掉之后主论题就不成立，非承重抽掉不影响（`templates/screening-card.md:66`）。
3. 让非承重论题与承重论题**等权**参与聚合，等于拿一个自己声明「主张不等权」的切分去做计数投票——自相矛盾。所以聚合必须**先看承重**；非承重只在承重全通时起降档作用。

**「不是刻度」这条不变**：聚合出的档位只是一个**阅读提示**——不出分数、不与其他轴相加、不构成总体等级（三构念**不可加总**，`docs/research/00-foundations.md:40`、`:346`）。两句话说的是不同的事：「等权不可加」禁止的是把论题折算成分数再求和；「承重优先」是**在同一根轴内部**按身份取最差。

### 5.2 三条自检（说明这条规则为什么长这样）

1. **「全 `A` → `A`」「全 `D` → `D`」都是特例，自动成立**，不是另立的规则：全 `A` 时承重全 `A` 且非承重全 `A`（第 2 步给 `A`）；全 `D` 时承重里必有 `D`（第 1 步给 `D`）。
2. **`B` 有两条可达路径**：`n = 1` 且该论题为 `B`；承重全 `A` 而非承重有一处断点。若按等权计数的旧写法，轴层 `B` 永不可达，与 `templates/screening-card.md:40` 的 `B` 档（「主干全通，断点只在非承重位置」）冲突——本规则下已解。
3. **`D` 只要有一条承重论题断裂就成立**，与 `templates/screening-card.md:42` 逐字（「承重主体断裂，或主论题本身没有支撑」）对齐——本规则下已解。

### 5.3 聚合之后

- 轴层出了 `A`–`D` ⇒ 该轴状态位是 `已评估`（档位与状态位的对应规则见 `templates/screening-card.md:89`：档位写 `—` 当且仅当状态位不是 `已评估`）。
- 本轴的**红灯**是 `W-1` 与 `W-2`；**触发条件唯一真源是 `references/07-redlines.md`，本文件不复述**。命中任一 ⇒ 本轴记 `D`，其余两轴照常判，三轴并排不合成。

## §6 本轴怎样才会「跑不了」

以下事实**只记录、不自行定值**，取值一律按 `templates/screening-card.md` §状态位：

1. 文章找不到承重结论 ⇒ `references/01-purpose-routing.md` §3 Step 1 失败，落 `P0` 兜底，本轴可能整轴不跑。
2. 命中 `P3`（体验与欣赏）⇒ 本轴不跑，只出提示串（`references/01-purpose-routing.md` §6）。
3. 输入残缺（只取到片段、目录页）⇒ 本轴判不了。
4. 前提无法命题化（步骤 0 失效）⇒ 真值改变测试执行不了，该条论题的支撑判定记不出来。

**「没去核」与「去了核不了」是两件事，各有各的状态位取值，不得互相顶替**（`templates/screening-card.md:75`）——这一条同样适用于本轴：**跑不了不等于文章差**。

## §7 残留自由度（两个判定者会在这里分档）

1. **承重论题的识别**——哪 5 条算承重，由判定者判（`templates/screening-card.md:71` 已明写「不设机械判据」）。
2. **中文前提的命题化**——步骤 0 是该测试最大的失效点（`docs/research/00-foundations.md:164`）。
3. **「可预见反例」的边界**——哪一个反对意见算「可预见」，没有机械判据。
4. **换题与「不够充分」的分界**——`H1` 说换题直接不合格，但「论据证明的是 A、论题要的是 B」要靠判定者判。

**这四条不装精度。** `A4` 下 v1 只声称**重测稳定性**，跨判定者一致性**未测**（`docs/research/00-foundations.md:397`）。

## §8 本轴必须能表达什么

本轴要能对**任何一篇**文章的每条承重论题给出 `A`/`B`/`C`/`D`，并且**四个档位都要能被走到**。下面四条是这条表达力要求的判定面——不是样例，是「规则若成立，就必须能区分这四种情形」。

| 必须能表达的情形 | 本轴的落点 |
|---|---|
| 承重论题**完全没有支撑**，或被换题（论据证明的是另一个命题） | `D`（§3.2 的 `D` 形态①、②） |
| 承重链有**一处承重环节没接上**，但论题没被换掉 | `C` |
| 支撑主干通，断点只在**非承重位置** | `B` |
| 四问全部闭合 | `A` |

**为什么不能拿「正向原文片段条数」当质量指标**（一般论述，不针对任何具体文章）：片段条数度量的是**材料可得性**，而支撑度量的是**材料与该主张的关系**。两者可以完全脱钩——一篇材料充足的文章，若每条材料证明的都不是它要的论题，片段越多、`D` 越确定；反过来，一条论证紧凑的短论可能只有两处引用却四问全通。用条数代替关系，等于把一个关系问题降级成计数问题，判定者会得到「材料很多 ⇒ 看起来扎实」的假阳性，同时把「没抽到材料」误判成「文章没有材料」（§4.2 已把这条列为硬约束）。

**判定的最小可复核痕迹**：卡上对每条承重论题写出三段原文——**论题句**、**为它提供支撑的论据句（没有就写「无」）**、**断开处在哪一环**。缺这三段，读者无法复核「凭什么是这个档」，判定退化为结论宣告。

**本文件不提供任何一篇具体文章的判定结果**：本文件是被判者与判定者都会打开的必读件，写进具体判定（文章身份、档位、判词）会让本轴无法被独立检验——判定者无法自证他的判定不是抄来的。
