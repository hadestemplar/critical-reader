## 一、缺陷簇

### 簇 A · L0 论证性分数不可复算 ★★★ → T-F1
- **A1** `references/01-genre-routing.md:53` 的 `P`（「含断言谓语（情态/评价/因果谓词）」）**没有闭集词表**。实测四种可辩护口径给出 `score` 0.48 / 0.57 / 0.61 / 0.71，**跨 0.60 硬边界** → 同一篇文章既可能进 A 轨也可能进 B 轨。
- **A2** `:55` 的 `O`（「有人认为 / 反方 / 反驳 / 然而…但」*类*标记）只给举例、无判定规则。取 0 会让 `score` 从 0.40 掉到 0.21，**B→C 翻转**；而 `L0-R6` 的二次判定区间 `[0.25,0.35]`/`[0.55,0.65]` **恰好不覆盖 O 的不确定性**。
- **A3** `:59`/`:33-40`：**分数档位与体裁处置冲突时以谁为准，协议没写**。实测 `ctrack` 跑：机械分数 0.40 → B 轨，而实体特征指向 C 轨，执行者只能自行取舍。
- **A4** `:48` 的 `L0-R3⑥`「人称与时态分布」—— 汉语无 tense，「时态分布」不可执行；且 `④⑥` 在规则链里**无消费方**。
- **A5** `:62` 的 `L0-R6`「换提示或打乱顺序做第二次独立判定」—— 单执行者不可满足「独立」；执行者两跑均如实记「未执行」。
- **A6** `:61` 的 `L0-R5`「直接判 C 档」与契约硬规则 4「体裁不是硬门控」存在张力；须明确「硬覆盖优先，且必须在 `L0-D1` 写明被它覆盖掉的分数与档位」。
- **A7** `:37-40` 的标签分 0–1（如 `argument=0.85`）**没有任何锚点**，执行者只能自拟。

### 簇 B · 门禁链三处不一致 ★★★ → T-F2
- **B1** `references/07-rating.md:71`「承重主张无出处 / 不可核 → `V1` → `Reject`」**vs** 同文件 `:80`「`V1` = `L2` 承重主张定位 ∧ `L5` 出处属性（三形态之一）」**vs** `rubric/vetoes.md:14-18`：`V1` 三个形态**全部以「存在一份被引材料」为前提，根本不含「无出处」**。→ 三份文本给出两个相反结论。
- 门禁是协议**唯一的非补偿机制**，它自相矛盾时全报告最高阶结论只能靠执行者临场裁定（`argumentative` 跑的 `Borderline` 就是这么来的）。
- **要求**：定**单一真源**（所有触发条件写在一处，其余文件只引用），并在 `vetoes.md` 里把「无出处」到底算不算 `V1` 一次性写清。
