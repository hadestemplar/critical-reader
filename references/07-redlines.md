# 07 · 红灯与档位

> **定位**：本文件是**红灯触发条件的唯一真源**，并给**档位四值的定义与判定侧锚点**。
> **不复述**状态位闭集（唯一真源＝`templates/screening-card.md` §状态位，见 §5 指针）、不复述任何单轴判据（在 `03` / `04` / `05`）、不设任何「计数 → 档位」的机械映射（档位由判定者按 §3 锚点直接判）。
>
> **铁律**：**一盏红灯只判自己那一轴，不跨轴一票否决。** 命中 `W-1` 只让 `W` 轴不合格；`C` 轴与 `V` 轴照常判定、照常出档。

---

## §1 四条红灯（唯一真源）

四条，不多不少：`W-1`、`W-2`（`W` 轴）、`C-1`（`C` 轴）、`V-1`（`V` 轴）。**不设第五条，不设跨轴红灯。**

### §1.1 `C-1`（`C` 轴 · 信得过）

**触发条件**：**承重**事实主张的支撑，**经本跑次外部核查后出现正向发现**，三形态任一：

| 形态 | 条件 | 需要外部核查 |
|---|---|---|
| ① | 按图索骥后，在原文与该材料的可打开来源中**都找不到**这个材料 | 需要 |
| ② | 同一材料在文中两处**数字或说法互相矛盾** | 不需要（文本内即可判） |
| ③ | 被引来源的强度被**明显加码**（来源说「可能 / 相关」，文中写成「证明 / 导致 / 必然」） | 需要 |

**形态 ①③ 在本次未执行外部检索时不得命中**——此时该轴写状态位、不写红灯。形态 ② 不受此限。

**命中后的结果**：`C` 轴档位记 `D`。卡上必须逐字引出错处原文与 `locator`，并写明三形态里命中的是哪一条。

**不是红灯的两种情况**（曾经被误当红灯）：材料「没有出处」、材料「不可核」——这两种是**文本属性**，只进状态位，不进红灯。

### §1.2 `W-1`（`W` 轴 · 站得住）

**触发条件**：**通篇没有回答它自己声称要回答的问题**，三形态任一：

| 形态 | 条件 |
|---|---|
| ① | 标题 / 开头承诺的要点数 `M` 与正文实际覆盖数 `N` 相比 `M/N < 1/2`（**阈值属【本报告工程约定】**，未校准） |
| ② | 主体段落在讲另一个话题（逐个主体段落做主题清点，讲的是 B 而不是承诺的 A） |
| ③ | 结论不是对声称论题的正面回答，**或整篇为另一个问题给出了完整论证**（对应学理里的 *Global relevance*：论证是否推进**该议题**的解决） |

**形态 ③ 是这条红灯的主要用途**：文章可以论证得很完整，但完整论证的是另一个问题。判定对象是**该议题的解决**，不是段内推理是否成立。

**形态 ③ 不设机械判据——这是有意的，不是漏写。** 判定者直接回答一句话：**「这篇文章完整论证的，是不是它自己声称的那个议题？」**给出结论与理由即可，不填表、不打分、不设阈值。

理由：把「议题」机械化（比对关键词、比对标题词、比对段落主题词）会把「论证服务于另一个问题」退化成**字符串匹配**；而这条红灯抓的是**内容层面的错位**，字符串匹配恰好看不见它。把判断换成执行，是本项目已经付过代价的错法（`docs/error-casebook.md`）。

**分工（两半都得有人管）**：

- **可机械核对的那一半已经由 `H1 换题` 承担**（`references/03-analysis-w.md` §2，含「两组对照必须来自同一总体」这一可判定形态）。
- **形态 ③ 管 `H1` 盖不住的那一半**：论据与论题**各自都成立**，但**论题本身不是文章该回答的那个问题**——这时没有任何一组对照可以拿来比。

**归类（`#74`）：模型推论 + 学理。** 推出链：承重性与充分性都以「**该论题**」为参照系（Toulmin 的 warrant 与 field-dependence 都是论题相关的）；若论据证明的是另一个命题，它对**本论题**的支撑即为零——所以形态 ③ 不是新增判据，而是「支撑不足」的极端形态（`D` 档形态 ① 换题已收录）。学理出处见 §6 的 *Global relevance*（`E17-1017`）。

**命中后的结果**：`W` 轴档位记 `D`。`M/N < 1/2` 只是形态 ① 的工程约定门槛，判错门槛不改变「答非所问」这一判断本身。

### §1.3 `W-2`（`W` 轴 · 站得住）

**触发条件**：核心主张**在文本内撑不住**，两形态任一：

| 形态 | 条件 |
|---|---|
| **A** | 存在一条**致命**缺陷，且它属于结构缺口 / 推理失效 / 预设装载，且落在承担全文核心主张的段落上 |
| **B** | 核心主张**零支撑**（既无可指认的推理链，也无可核验材料）；**或**核心主张的**承重前提在文本内完全未被辩护**——含「把作者旧文里的判断、文外结论当已确立前提」 |

**形态 B 是本条的主入口**，两条问句都在文本内可判：① 这一环是否承重（抽掉它，主论题还成不成立）；② 文本内有没有为它给出辩护。

**形态 A 不以「致命」标签的松紧为准**：标签缺位（全篇只有「重要 / 提示」）不构成「不命中」的理由，此时按形态 B 重判。**承重与否由判定者直接判，不设机械判据**（判据见卡模板 §1「承重与非承重」），判完必须在卡上写出「哪条是承重、抽掉会怎样」，让读卡的人能复核。

**命中后的结果**：`W` 轴档位记 `D`。

### §1.4 `V-1`（`V` 轴 · 值得读）

**触发条件**：读完之后**无收获或零增量**，两形态任一：

| 形态 | 条件 | 需要外部核查 |
|---|---|---|
| **A** | 全文既无任何可用信息 / 事实 / 方法，也无任何新观点——**两个问句都答「无」**，且必须写出「找过哪三处」 | 不需要 |
| **B** | 抽查 3 个信息单元，**全部**能在已有材料中找到同一内容，**且**全文未提供新的组织方式（新分类 / 新框架 / 新对比 / 新证据链） | 需要 |

**形态 B 在本次未执行外部检索时不得命中**（连同抽查记录一起进未核项）。

**重言式（正确的废话）归本轴**：说法都对、都不新，仍是无增量。

**命中后的结果**：`V` 轴档位记 `D`。卡上必须写出参照集合是什么（相对哪一组已知公开讨论判的「不新」）。

## §2 红灯的通用约束

1. **一条红灯只挂一个轴。** 同一条原文片段**不得同时登记两条红灯**（互斥）。
2. **命中必须给证据**：逐字原文片段 + `locator`。写不出原文的命中**不成立**——改记入未核项。
3. **不得增设**第五条红灯；**不得**把两条红灯合并成一条「综合不合格」。
4. **不得把风险项当红灯**：风险识别栏的命中项（风险 `C1`–`C4` / `D1`–`D4` / `E1`–`E4` / `F5`）只作提示。
5. **不得跨轴**：任一红灯都不影响另外两轴的档位与状态位。卡面必须让三轴并列可见。
6. **形态不成立时写状态位，不写红灯**：判不了就说判不了，不用默认档补齐。

### §2.1 同一轴命中多条红灯时卡面怎么写

同一轴命中**两条或更多**红灯（来自**不同原文片段**）时：

1. **两条都写**，逐条列出，每条给三件：**红灯代号** + **命中的论题句**（逐字原文 + 定位）+ **断点位置**（断在哪一步）。
2. **禁止折成一条「综合不合格」**（同 §2 第 3 条），也**禁止只写「更重的那一条」**——读者需要知道断在哪几处。
3. **轴层档位仍取最差，不因红灯条数改变**：一条红灯和三条红灯**可以是同一个档**（都是 `D`）；条数不进入档位计算，也不构成新的刻度。
4. **两条红灯指向同一条论题时仍分列**（断点不同），但**必须标明它们指向同一条论题**——否则读者会以为文章断了两处论题。
5. **卡面格式的唯一真源是 `templates/screening-card.md`**（「命中红灯」块）；本节只规定判什么、不规定怎么写。

## §3 档位（每轴各取一个）

### §3.1 通用四档

| 档 | 通用含义 |
|---|---|
| `A` | 该轴判据全部跑通，找不到断点 |
| `B` | 该轴主干成立，问题只在**非承重**位置（引子、举例、顺带推广） |
| `C` | 该轴有**一处承重环节**没接上 |
| `D` | 该轴承重主体断裂（`W` / `C` / `V` 各自的红灯即落在这一档） |

**四档是有序的名义档位**：`A` > `B` > `C` > `D` 只表示次序，**不提供任何数值刻度**，不得做算术、不得跨轴相加、不得跨轴平均。

### §3.2 每轴的判定侧锚点

> 卡面逐栏释义（写给读者看的措辞）在 `templates/screening-card.md` §1。本节给的是**判定侧最低条件**——判定时必须能指出这一条，才算到了这一档。两者冲突时**以卡面为准**，并回头改本节。

**`W` 站得住**

| 档 | 判定侧至少要能指出 |
|---|---|
| `A` | 每条论题的四个方向都跑通过（论据是什么 / 它必须先成立什么 / 反例与适用边界 / 断在哪），且承重前提**在文本内被辩护** |
| `B` | 主干全通；断点只在非承重位置（引子、举例、顺带推广） |
| `C` | 一处**承重环节**没接上：换了论题、缺了必要前提、或全称句找不到反例 |
| `D` | 命中 `W-1` 或 `W-2` |

**`C` 信得过**

| 档 | 判定侧至少要能指出 |
|---|---|
| `A` | 承重事实主张都有可打开、可定位的线索，且本跑次抽核结果与原文一致 |
| `B` | 承重主张都查到了源头，只有次要说法没核到；或承重主张只有单一来源转述 |
| `C` | 有**承重**论据查不到源头 |
| `D` | 核到与源头冲突（命中 `C-1`） |

**`V` 值得读**

| 档 | 判定侧至少要能指出 |
|---|---|
| `A` | 至少一个可指认的新观点 / 新思考 / 新信息增量，并写明**相对什么参照集合**是新的 |
| `B` | 有少量新东西（一两条），核心判断仍是既有材料的重述 |
| `C` | 基本是已有概念的复述或常识整理 |
| `D` | 没有信息增量（命中 `V-1`） |

### §3.3 哨兵值 `—`

`—` **不是第五档**，是「**没有档位**」：该轴没有出档（判据未执行、或判不了）。

- 卡面一律渲染为 `—`，**不参与排序、不参与比较、不参与任何跨文章统计**。
- 档位写 `—` **当且仅当** 状态位不是 `已评估`（= 硬规则 7）；出了档必须写 `已评估`。
- 不得把 `—` 当 `D` 用（那是「拿缺失当最低分」），也不得把 `—` 当 `A` 用。

## §4 轴内聚合

- **通用原则：轴内取最不利、不补偿**——一条承重环节不合格，即拉低该轴；不得用其他环节的良好表现把它平回来。
- 一篇文章有多个主张单元时，**各轴的聚合细则写在 `03` / `04` / `05` 各自的「聚合」节**，本文件不重复。
- **轴与轴之间没有聚合**：不存在把三轴合成一个结论的步骤（硬规则 6）。

---

## §5 状态位：只留指针

状态位的**闭集与「必须附写」全部**在 `templates/screening-card.md` §状态位。本文件只登记三条推论，避免各处重复解释：

1. 状态位不是「第二根轴」：它不产生档位、不参与判定，只说明这一轴跑到哪一步。
2. 状态位不是 `已评估` 的轴**不得参与任何跨轴叙述**，也不得用默认档补齐（硬规则 9）。
3. 状态位**不能替代红灯**，红灯也不能替代状态位：前者说的是「查出来是坏的」，后者说的是「没查 / 查不了」。
