> **用途**：把协议跑在 30 篇真实中文文章上，产出一张可供人工复核的判定表。
> 你只需要**标出不认同的行**（见 §5 的勾选说明），不需要先读 30 篇文章。
>
> **运行条件（务必先读，它决定了下面所有数字的含义）**
> - 六个执行者，每 5 篇，**全程禁止联网**。

## 2. 三条判读（这是我的结论，不是执行者的）

### 2.1 ★ 门禁在实测中**没有产生任何独立信息**——两根轴塌成了一根

`07-rating.md` R2 的定义是：`Reject` =命中否决项 **或** 档带 `D`；`Borderline` =否决项为空 **且** 档带 `C`；`Pass` =否决项为空 **且** 档带 ∈ {`B`,`A`,`S`}。

30 篇实测结果：**`Pass` 恰好＝9 篇档带 A/B；`Borderline` 恰好＝19 篇档带 C；`Reject` 恰好＝1 篇档带 D；`无法判定` 恰好＝1 篇资格不可判定。零例外。**

也就是说：**否决项在这 30 篇里一次都没独立命中**（`V2`/`V3`/`V5`/`V6` 全 0 命中，`V1`/`V4` 不可执行），门禁的取值**完全由档带决定**。

> 你要的是两根轴：「合不合格」+「到底好不好」。**现在它们给出的是同一个答案**。这不是实现 bug，是我在设计门禁时把它写成了档带的函数；而这批数据第一次把它量化出来了。

### 2.2 C 轨在无网条件下**机制性封顶 C 档**——19 篇 C 里约 10 篇是机制造成的

`08-track-c.md` R3 规定 `C1`（可操作性）对 `news`/`narrative` 类**固定「不适用」**；`C2`（来源可信度）需要横向外核，**离线不可执行**；`R9` 又规定不可执行的判据**不参与计数**、且**禁止按最低档兜底**。

结果：C 轨只剩 `C3`（信息密度）一条可执行判据，`n_high` 最多为 1，而计数映射要求 `n_high ≥ 2` 才能给 B → **上限只能是 C**。

**所以 C 轨那 11 篇的「C 档 / Borderline」是机制决定的，不是内容评价。** 把它们当成「文章差」是错的；把聚合分布当成「协议没有区分度」也是错的——**A/B 轨那 18 篇的分布（A 2 / B 7 / C 8 / D 1）是正常的**。

### 2.3 离线环境把 `confidence` 清零了

`L1` 一律降级 ⇒ `confidence ≤ 低`。加上单执行者 `stability = 未执行`，**30 篇里 29 篇是「低」**，唯一一篇「中」也是贴着上限给的。

含义：**在不能联网的使用场景里，这份报告几乎永远不会说「我对这个判定有把握」**。这不是缺陷，是设计的诚实；但你必须知道它，否则会把「低置信」误读成「工具不可靠」。

## 4. 这批数据**不能**证明什么

1. **不能证明协议的准确率**——没有人工金标准，本轮只是产出候选答案供你复核。
2. **不能证明复现性**——没有一篇被两个执行者独立跑过（D7 的正式实验未做）。
3. **不能证明门禁有效**——见 §2.1，它在这批数据里没有独立命中过。
4. **不能证明 C 轨可用**——见 §2.2，无网条件下它封顶 C 档，**C 轨的端到端能力至今未真正验证过**。
5. 阈值仍未校准（`T_pass`/`T_border` 与四维三值边界都是工程约定），本表用途是**给校准提供人工锚点**，不是最终判定。

### 5.1 五篇判 D 的理由是同一句话

「**观点没有论据，不能到 C**」（#1/#3/#6/#7/#10）。这五篇的体裁是散文、访谈、自述——**正是被我方协议豁免了论证审查的那一类**（`references/01-genre-routing.md:55` 七体裁表的 `narrative` 行）。**用户的标准里没有体裁豁免。**

### 5.2 #21 是决定性证据：问题不在判据执行，在档位定义

我用「主张明确、正面回应最强反方并自列不确定」描述它，用户用「论证过程相对比较清楚，但整体不是很严谨、论述不全面」。**我们描述的是同一组事实、给出了不同的档**——我判 A、用户判 B。同理 #1/#3/#6/#7/#10：我方的判定理由（「无可核外部来源」「无独立可检验主张」）与用户的「观点没有论据」**不是互相矛盾的观察**，是两个不同的阈值。

→ 本轮暴露的问题**不是「判据执行错了」，而是「档位语义与用户不一致」**：
- 协议的 `C` ＝「条件性」（需附加条件才可读）；
- 用户的 `C` ＝「合格线——论题、论点、结论都过了及格线」。

同一个符号，两个语义。**这是我设计时没有向用户确认过的定义。**

3. 「门禁判定完，红灯的文章就是不值得花时间的文章，黄灯可以把原因写在报告中人类读摘要看要不要继续读，绿灯就是值得一读的文章。」
