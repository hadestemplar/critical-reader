## 一、项目目标

**一句话**：给 Agent 用的文章筛选协议包——收到一篇文章（公众号分享链接 / PDF / MD / TXT / 粘贴正文），产出一份带原文证据的判断报告，回答**「这篇文章值不值得花时间读」**（收益预估：要么有新的信息 / 知识 / 数据，要么有有价值或新颖的观点）；**质量分级（论证扎不扎实）降为第二问**，不产出任何数值刻度（`DECISIONS.md` #55、#56）。

**不做什么**（YAGNI，防止范围蔓延）：

| 不做 | 原因 |
|---|---|
| 图形界面 | 用户明确「不需要图形化交互界面」 |
| 内置 LLM 调用引擎 | 判断由使用者的 agent 用自己的模型执行 ⇒ 零 API key、零成本转嫁 |
| 批量扫目录模式 | v1 只做单篇（`DECISIONS.md` #20） |
| 公众号长链抓取 | 实测被风控拦截；只支持 `/s/<id>` 分享短链（#3） |
| 自动事实核查（联网检索并判真假） | 只**标注**需核查项与来源缺失，不自动判事实真假——成本高、误判率高（#13） |
| ACH / Bloom 层级 / 谬误计数扣分 / 全文论证图 | 已在调研中淘汰，各有实证理由（#15） |
| 多语言（英文文章判定） | v1 只针对中文文章 |

## 二、已对齐的决策

见 `docs/DECISIONS.md`（**条数以该文件为准**）。其中**不可变更的硬约束**：

1. 交付形态 = 技能目录，clone 即安装（#2）
2. **否决项 + 档位五值闭集** `A`/`B`/`C`/`D`/`无法判定`（**灯是 `verdict` 的纯函数，只供协议内部一致性检查，不渲染到交付物**；`无法判定` 是哨兵值（没有档位，不参与排序/比较/统计），卡面渲染为 `—`）；`D` ＝命中任一否决项且不进质量分级；**v1 不产出数值刻度、无阈值**（#56①②③；原 #4/#5/#6 的门禁轴与数值档带已作废）
3. 体裁三**轨**处置 `A 轨`/`B 轨`/`C 轨`（**轨 ≠ 档**），`C 轨`配第二套判据且不免除把关（#8/#9；#56④）
4. 六层全跑（#10）
5. 每条判定必须附原文引用 span，无引用不得成条（#11）
6. 代码 MIT + 文档 CC BY 4.0；不得引入 CASP / AAC&U / JBI / Wikipedia 的表述（#23）
7. 报告必含**四要素表**：论题 / 结论 / 论据 / 前提假设与隐含假设——四项均为必填输出字段、**不得留空**；论题 / 结论 / 前提假设须附原文引用（无则写「文中未显式给出」+ 最接近片段），论据须附 `[locator] 「原文逐字引用」`，**隐含假设豁免原文引用**，改为强制给出补全句 `P + 假定 ⇒ C` + 最接近的触发片段（无则写 `无`），位置字段取 `文中未给出（隐含）`（#25、#26）

## 四、交付物与验收标准

> **通用条款**：每条验收标准必须给出**可复核证据**（文件 + 行号、或命令 + 输出）。验收以产物本身为准，不以「已完成」的口头声明为准。

| #      | 交付物                                           | 验收标准（可判定）                                                                                                                                                                                                                                                                                                                                                              |
| ------ | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **D1** | `references/00-protocol.md` ~ `08-track-c.md` | ① 六层中每一层都写明：**本层回答的唯一问题 / 输入 / 输出字段 / 判定规则 / 已知局限**五项，缺一即不合格；② 每层至少 1 条判定规则是**可机械执行**的（可数、可二元判定、或带明确档位边界），不得只有形容词；③ 每条规则标注出处（用户指南行号 / `docs/research/*` 章节 / 外部 URL），无出处者标【本报告工程约定】；④ `references/03-structure.md` 必须给出四要素表的**字段、原文引用格式与第 1–4 项（论题 / 结论 / 论据 / 前提假设）的抽取规则**；第 5 项隐含假设在本层只留固定占位 `见 L3`，其抽取规则由 `references/04-assumptions.md` 给出（后者还须给出事实型 / 价值型假定的分流判据） |

### 五.1 样本集：校准覆盖清单（**已由 #55 降级**：样本改为用户真实投喂、校准改为逐篇积累；本节保留为历史设计记录）

来源：protocol-tail 在 L4–L6 批次复盘中给出，由我核定并补注（⚠ 为我的补注）。没有这份清单，T-F 会退化成「随便凑 30 篇」，比对结果不可复核。

**分层要求**：不合格 10 篇 / 边界 10 篇 / 合格及以上 10 篇；**边界例 ≥ 总数的 1/3**（边界例对判据的分辨力贡献最大）。

**体裁与情形配齐**：

| 体裁簇 | 篇数 | 必须覆盖的情形 |
|---|---|---|
| 论证 / 评论 | 3 | 论证链断裂（拟命中 `V6`）｜拟给 `A` 的优质样本｜**伪装成论证的软文** |
| 学术 / 技术论证 | 3 | 相关当因果｜`A` 档候选 |
| 教程 / 操作指南 | 4 | 缺前提不可复现｜版本过期｜优质 how-to 的 C 档上限｜**仅目录页（拟命中 `V5`）** |
| 新闻报道 | 3 | 标题党（拟命中 `V2`）｜匿名来源「有消息称」｜时效过期 |
| 科普 / 解释 | 3 | 实为解释却被当论证｜伪引用｜正常科普 |
| 个人随笔 / 评论 | 4 | 「显然 / 众所周知」预设装载｜零形回指致主体模糊｜拟给 `B`｜拟给 `D` |
| 营销 / 说服 | 3 | 导流（拟命中 `V3`）｜健康类 FLICC（应只作提示、不计分）｜偏推销 |
