# 00 · 契约（新链总纲）

> **定位**：本文件管**接缝**——判定顺序、术语、交付物、硬规则。**不含任何单轴判据细节**：单轴判据在 `02`–`06`，红灯触发条件在 `07`，状态位闭集在 `templates/screening-card.md` §状态位，卷宗规范在 `10-dossier.md`。本文件若与它们重复表述，**删本文件那一句**。
>
> **冲突处理**：①「顺序」冲突 → 以本文件 §3 为准；②「红灯触发条件」冲突 → 以 `07` 为准；③「状态位」冲突 → 以卡模板为准；④ 其余判据细节 → 以各自的判据文件为准。

## §1 三轴与零合成

| 轴 | 一句话 | 输入范围 |
|---|---|---|
| `W` 站得住 | 从**文中给出的**前提，能不能推到**文中宣布的**结论；且推的是不是**文章自己提的那个问题** | **仅文本内** |
| `C` 信得过 | 文中**关于世界的可核事实主张**，是否与**文本外可打开的证据**一致 | **必须含外部检索** |
| `V` 值得读 | 相对一个**已声明的参照集合**（已知公开讨论），提供了多少**新的观点 / 思考 / 信息** | 判定者知识，不占外部检索通道 |

- 三轴**并立、互不代偿**：任何一轴不合格，不代表另外两轴也差。
- **轴间零合成、零加权、零一票否决**：不出总分、不出总体档位、不出总体建议。
- **轴内保留非补偿**：一条承重环节不合格即拉低该轴（取最不利）。
- `V` 轴**不回答**「这篇对我有没有用」——那由读者自己判。

出处：`docs/research/00-foundations.md` §3 `A3`（三轴、互不代偿）与 §6.1（轴间零合成；依据 `E17-1017` 两条合取定义句、RoB 2「取最不利」、AMSTAR 2 "not intended to generate an overall score"、GRADE "not a quantitative system"）。

## §2 记号、术语与硬规则

### §2.1 记号与冻结声明

| 记号 | 含义 |
|---|---|
| `【本报告工程约定】` | 这是本项目的工程约定，不是学理结论（**冻结记号**，名称不改） |
| `【无来源，本文自定】` | 这一条没有文献或实践出处，是本项目自己定的 |
| `【待核实】` | 判定者未能核实，如实标注，不得当已核实使用 |

**冻结记号**：`【本报告工程约定】` 读作「这是本项目的工程约定，不是学理结论」；它沿用 13 章成品形态时期的命名（该形态已废除），**名称不改**。

**每一条判据都要能指出它属于哪一类**：学理推论（给可核出处）／工程约定（标 `【本报告工程约定】`）／单篇观察（不得单独进判据）。

### §2.2 术语表

| 术语 | 含义 | 唯一真源 |
|---|---|---|

| **风险项** | 风险识别栏的命中项，**只作提示**，不参与档位 | `06` |
| **目的** | 这一次执行的是哪种阅读活动，取值 `P0`–`P3` | `01` |

### §2.3 硬规则 1–9

| # | 硬规则 | 一句话判据 |
|---|---|---|
| **硬规则 1** | **顺序不可跳过、不可回填** | 只能按 §3 的五步走；某步跑不动就如实写状态位，不得拿下游结论反推上游 |
| **硬规则 2** | **证据强制** | 写不出原文片段（逐字引文 + `locator`）的判定不得成立；写不出就记入未核项，不落档 |
| **硬规则 3** | **单轴独立** | 每个轴只用自己的判据与自己的证据通道；不得用另一轴的证据代替 |
| **硬规则 4** | **红灯只判自己那一轴** | 触发条件只在 `07`；其余两轴照常判定，不得跨轴一票否决 |
| **硬规则 5** | **风险项不升格** | 风险识别栏的命中项只作提示，不得当红灯用 |
| **硬规则 6** | **零合成** | 不出总分、不出总体档位、不出总体建议；任何位置都不得出现跨轴的合成分 |
| **硬规则 7** | **档位与状态位自洽** | 档位写 `—` **当且仅当** 状态位不是 `已评估`；出了档必须写 `已评估` |

| **硬规则 9** | **降级传导** | 状态位不是 `已评估` 的轴**不得用默认档补齐**、不得参与任何跨轴叙述；其后果必须写进卡面与卷宗 |

## §3 判定顺序（唯一真源）

**任何文件不得另立顺序。** 五步，一步都不能跳、不能回填：

**起始前置（第 0 步）· 判定对象存在性**：五步之前先确认「有正文可判」——正文确实取到了（链接可打开、非付费墙、非仅标题/摘要、文件未损坏）才进入第 1 步。

1. **判定对象不存在 ⇒ 不出判定**。抓不到正文时**不得**凭标题、摘要、二手转述或同题他文开判。
2. **仍要出交付物时**（用户明确要一张卡）：三栏档位全写 `—`、三栏状态位全写 `无法判定`；风险识别栏写 `未执行（无正文）`；并在卡面写明**实际发生了什么**——哪一步取正文失败、失败原因逐字给出。
3. **禁止静默降级**：不得把「正文不可得」渲染成一张看起来正常、只是碰巧全 `—` 的卡；不得隐去原因。
4. **与 `无法核` 的分界**（不得互相顶替）：`无法核` 是**有正文、某个事实核不了**，影响落在 `C` 轴局部；「正文不可得」是**连判定对象都没有**，整个判定不成立。



1. **切主张**（`02`）——把文章切成主张单元：主论题 / 独立论题 / 纯建议；并列多论题是常态，不是缺陷。
2. **目的路由**（`01`）——定一条 `purpose`（`P0`–`P3`），据此选判据族。声明 > 推断 > `P0` 兜底；推断必须逐字披露。
3. **逐轴判**（`03` / `04` / `05`）——`W` → `C` → `V` 各判各的，每轴产出：档位候选 + 逐条判定的原文依据 + 未核项。
4. **红灯**（`07`）——逐轴对照四条红灯；命中即该轴不合格，**其余两轴照常**。
5. **聚合与落位**（本文件 §4 + 卡模板）——轴内按最不利聚合出一个档位，写状态位，按卡模板出卡；被要求时按 `10-dossier.md` 出卷宗。

**条款 · `purpose` 与红灯的关系（`G4`）**：

- **`purpose` 只决定跑哪些轴、每套轴用哪套判据族，不改变红灯的判定。红灯是轴的属性，不是目的的属性。**
- 因此 `P2`（获取信息）下若一条承重论题确有论证缺陷，`W-1` / `W-2` **照常可触发**（触发条件仍只在 `07`，本文件不复述）。
- 变的只是**卡面措辞**：按「获取信息」这个用法说清**这条缺陷对想拿信息的人意味着什么**——`P2` 的读者要的是信息、不是被说服，所以措辞落在「这条信息的承重环节没接上，取用它的时候要自己补」这类后果上，**不落在**「你不该被说服」上。
- **不得**因为在 `P2` 就把红灯降级、免触发，或把它改写成风险项（与硬规则 4「红灯只判自己那一轴」、硬规则 5「风险项不升格」同向）。
- 反例（禁止的读法）：**「反正是 `P2`，论证缺陷不算数。」**
- **`P3` 不在此列**：`P3` 是**不跑轴**（`05` 规定三栏不出档、只给提示串），不是「跑了轴但把红灯降级」。两种情形不得互相援引。

判不出时**不许猜**：写 `—` + 状态位，并在未核项里写明「缺什么才能判」。

## §4 交付物

**两件，只有两件**：**筛选卡**（必出）、**证据卷宗**（默认不出，被要求时另出）。13 章完整报告已废除。

### §4.1 筛选卡（唯一规范：`templates/screening-card.md`）

形态要点（**措辞与细节以模板为准**，本节只登记契约层必须成立的东西）：

1. **三栏并立**——「说得有道理吗」（`W`）/「说的是真的吗」（`C`）/「值得读吗」（`V`），各取 `A` / `B` / `C` / `D` 四档之一。
2. **每栏各带一个状态位**，闭集与「必须附写」由卡模板 §状态位 规定；本文件不复述。
3. **不变式**：档位写 `—` 当且仅当状态位不是 `已评估`（= 硬规则 7）。
4. **风险识别栏**独立于三栏，只列命中项，只作提示（= 硬规则 5）。
5. **两种形态**：**小卡 ⟺「值得读吗」这一栏为 `D`**；该栏为 `A` / `B` / `C` 出大卡（判据见卡模板 §0）。
6. **零总体等级**：卡面任何位置不得出现总分、总体档位、总体建议、跨轴合成结论。
7. **卡面不写灯**：档位只用 `A` / `B` / `C` / `D` / `—` 渲染。

### §4.2 证据卷宗（唯一规范：`references/10-dossier.md`）

- **默认不出**；被判定的读者或派发者索要「依据 / 卷宗 / 你怎么判的」时才出。
- 卷宗是卡的**附件**：按卡上栏目顺序组织，**只放证据**（每条判定的原文片段与位置、本次检索了什么、未核项），不另起目录、不重复卡上的结论。
- 本文件只管「什么时候出、出给谁」；**卷宗里放什么、怎么排版，全部在 `10-dossier.md`**。

## §5 分工、不变式与边界

### §5.1 三处必须一致（跨文件不变式）

| 不变式 | 唯一真源 | 其余文件 |
|---|---|---|
| 状态位闭集与必须附写 | `templates/screening-card.md` §状态位 | 只许引用，不得复述 |
| 红灯触发条件 | `07` §1 | 只许写 id（如「红灯 `W-2`」），不得复述条件 |
| 判定顺序 | 本文件 §3 | 只许引用，不得另立顺序 |

### §5.2 文件分工

| 文件 | 管什么 | 不管什么 |
|---|---|---|
| `00`（本文件） | 接缝、顺序、术语、交付物、硬规则 | 任何单轴判据 |
| `01` | 目的路由 `P0`–`P3` | 判据内容 |
| `02` | 切主张、论题表、拼盘与结构标题 | 各轴判据 |
| `03` / `04` / `05` | `W` / `C` / `V` 三轴判据 | 别的轴；红灯条件 |
| `06` | 风险识别 13 项 | 档位（风险项不升格） |
| `07` | 四条红灯 + 档位定义与锚点 | 状态位闭集（只留指针） |
| `10-dossier` / `10-limits` | 卷宗规范 / 局限索引 | 判据与顺序 |

### §5.3 边界（本协议不做什么）

- **不判事实真假**：`C` 轴只判「该核的核没核、核到的与源头一致不一致」，不判「这个说法在世界上是否为真」。
- **不做读者适配**：不按立场、兴趣、身份推荐读或不读；`V` 轴不问「对你有用没」。
- **不评价文笔、不揣测动机、不做身份背景审查**。
- **不产出跨轴合成**：没有总分、没有总体等级、没有综合建议。
- **不联网也能跑**：`C` 轴会停在 `未核查` 或 `无法核`，其余两轴照常判；**不得用默认档补齐**（= 硬规则 9）。

### §5.4 必读件的洁净约束

**必读协议文件（`SKILL.md` + `references/*`）不得包含任何具体文章的判定结果——文章身份、档位、判词、以及「某篇该判哪一档」的推理路径，一律不得出现。样本与其判词只存在于 `examples/`、`docs/`、`_scratch/`；判定者在出判定之前不得读这三处。**

理由：必读件里装着样本答案，等于这个轴无法被独立检验——判定者无法自证他的判定不是抄来的。

触发：`_scratch/stage3-acceptance/` 那次跑次因 `references/03-analysis-w.md` §8 泄漏样本结论而使 `W` 轴失效（已由 protocol-core 修复）。**归类的词可以留**（如「学理 + 用户判词」是归类），**引语与结论不许留**。

### §5.5 机械核对：与 `scripts/check-card.mjs` 共用同一份规则表

`scripts/check-card.mjs` 只查**形状与残留**，**不查内容质量**——这条边界不许破：它判不出「说得有没有道理」，只判得出「这张卡合不合模板、有没有把已作废的字段带回来」。

**规则清单**（按脚本里的 `add("Rn", …)` 归并；同一 `Rn` 下可能有多条判定，此处只写它查什么）：

| 规则 | 查什么 |
|---|---|
| `M1` | 首行是否逐字是 `# 值不值得读 · 一页纸` |
| `M2` | `H1` 之后是否为：空行 + `**《<文章标题>》**` + `<来源>｜<发表日期>｜约 N 字`（分隔符全角 `｜`，字数纯数字） |
| `M3` | `## 三个问题分开看` 之后是否有表格、是否恰好 3 个数据行、第一列是否逐字为「说得有道理吗」「说的是真的吗」「值得读吗」 |
| `M4` | 结论/档位列取值是否落在 `{A, B, C, D, —}` 内 |
| `M5` | 形态是否自洽：大卡（有 `## 说得有道理吗：` 标题）与小卡（「值得读吗」＝`D` 且无该标题）**恰好一个成立** |
| `M6` | 每一栏是否都带状态位；状态位取值是否在闭集内；状态位为 `无法判定` 时是否写了「缺什么才能判」 |
| `M7` | `判定者模型标识` 是否非空且不等于 `AI`；`自偏好风险` 是否落在 `{是, 否, 无法排除}`；标识＝`未提供` ⇒ 风险是否为 `无法排除`；记 `是`／`无法排除` 时同节是否有说明文字 |
| `M8` | 是否残留已作废的分数/档带字段；档位列是否用「不适用」占位（应写 `—`） |
| `M9` | 是否有 `**一句话**：` 且其后不少于 10 个非空白字符 |
| `M10` | 是否有 `## 这篇文章在说什么` 且该节非空 |
| `M11` | 档位列是否出现灯符号 |
| `M12` | 档位与状态位是否对得上（`—` 当且仅当 状态位 ≠ `已评估`） |
| `M13` | 某一轴栏内出现红灯代号（`W-1`/`W-2`/`C-1`/`V-1`）时，该栏内是否至少有一条**合规登记行**（形如 `- \`代号\` ｜论题句：「逐字原文」（定位）｜断点：…`）；只查形状，不判内容 |
| `M14` | 覆盖率是否自洽：出现「已核 N 条 / 共 M 条」时，① 分子不大过分母；② 同一栏不出现两个分母；③ 同栏写「另有 X 条未核」时分母须含这 X 条；④ 「共 M 条」须能在本栏数出 M 条条目，或本栏给出指向卷宗的指针 |
| `M15` | 「说的是真的吗」栏（**仅大卡**）是否有一句**切分口径**披露（形如 `**切分口径**：…`，冒号后 ≥6 字），表明把什么算作一条承重事实主张；该栏档位为 `—` 时不要求 |

**退出码**：`0` 全部通过；`1` 存在违规（逐条打印 `M编号` + 行号 + 原因）；`2` 用法或读写错误。
