# `04` · `C` 轴判定（信得过）

> **本文件回答的唯一问题**：文中**关于世界的可核事实主张**，是否与**文本外可打开的证据**一致。
> **本文件不定义**：红灯的触发条件（唯一真源＝`references/07-redlines.md`）、状态位闭集（唯一真源＝`templates/screening-card.md` §状态位）。本文件只写「本轴怎么判、怎么出档、什么时候不出档」。
> **位置**：在 `references/00-protocol.md` §3 判定顺序 的「逐轴判」一步内执行；本文件不得另立顺序。

---

## 1 边界：什么归本轴，什么不归

| 问题形态 | 归谁 |
|---|---|
| 这个说法**是不是真的**（与文本外证据是否一致） | **本轴（`C`）** |
| 这个前提**撑不撑得住**那个结论 | `W` 轴（`references/03-analysis-w.md`） |
| 这个说法**新不新** | `V` 轴（`references/05-analysis-v.md`） |
| 来源类型（一手／二手）、学科领域、作者动机、文笔与修辞 | **三轴都不进** |
| 「对我有没有用」 | **三轴都不进**（已由用户裁定移出框架） |

**「可接受性」与「真」是两件事，这是本轴存在的理由**：`E17-1017` §2 p.177 逐字「(local) acceptability means that a premise is rationally worthy of being believed by the target audience of the argument. **It replaces truth, which is often unclear** (Hamblin, 1970).」——见 `docs/research/00-foundations.md:347`。⇒ 同一段原文可以同时进 `W` 与 `C`，但**判定动作不同**：`W` 问「它在文中站不站得住」，本轴问「它与外面的世界对不对得上」。**不是同一次判定记两次分**。

〔模型推论：由「三轴各判一件事」＋上面这条逐字出处推出〕

## 2 输入：两件东西

**（a）可核事实主张的清点；（b）外部检索。缺 (b) 时本轴不能出档。**

### 2.1 清点口径

1. **优先级**：含数字的断言句、具名机构／研究报告的声明句，先清点——它们是「可核」成本最低、也最容易被读者当成论据的部分。【本报告工程约定】
2. **承重的事实主张必须全部进清单**：凡在 `references/02-claim-split.md` 的论题表里被标为承重的条目，其事实主张**一条不漏**；**未进清单的条目不得被算作「已核」**。
3. **不设固定抽样条数 `k`**。理由：抽样比例无来源（`_scratch/source-audit/stage2/s1-axes.md` §2.2 残留自由度①：抽多少条，文献没给，本协议不装精度）。代价照实写：长文的工作量**不封顶**。【本报告工程约定】
   - **覆盖率的分母必须等于卷宗里逐条列出的条目数**：读者照着卷宗数一遍，数出来的条数必须与卡上写的「共 M 条」相等。
   - 判定者**必须用一句话披露自己的切分口径**（把什么算作「一条承重事实主张」：按断言句／按段落／按论题下的主张簇）；口径可以不统一，但**必须写明**。
4. 每条给**原文片段**（逐字，不转述）+ **位置**（小节标题或段号）。转述过的片段不算证据。

### 2.2 外部检索是硬分界

本轴是三条轴里**唯一必须离开文本**的轴（`docs/research/00-foundations.md:342`：「输入必须含文本外检索」）。因此：

- 本次**没有发起**任何外部检索 ⇒ 状态位取 `未核查`，本轴**不出档**（档位写 `—`）。
- 发起了但拿不到结果（通道 429／断网／无权威源／无作者身份标识）⇒ 取 `无法核`，同样不出档。
- **不得**因为「文章看起来不可信」就把没核的那几条记成低档——那是把缺失当取值，文献三派（显式类别／低确定性／缺失值）**没有一派**把「没查」记为低分（`docs/research/00-foundations.md:223-226`）。

### 2.3 核验深度三分（`#75` 裁定）

**不是每条主张都要回源头。三档深度，按「反常度 × 读者信错的代价」选：**

| 深度 | 什么情况 | 动作 |
|---|---|---|
| 不核 | 常识性主张（受众共识即可接受） | 记「常识，不核」 |
| 浅核 | 信错代价低 | 只核「有没有出处、出处能不能定位」 |
| 回源头 | **反常 且 代价大** | 打开原始材料逐字比对 |

- **标【本报告工程约定】**：三个门槛值、以及「反常度 × 代价」这个**相乘**合成，都是本项目的工程约定，**不是学理**（`docs/DECISIONS.md:141`）。
- **有出处的那一半**：反常度出自「非凡的主张需要非凡的证据」这一命题（Sagan／Truzzi；其正式形态是贝叶斯的先验—似然关系）；「信错的代价」出自决策论。相乘是我的合成（同上）。
- **一条容易搞反的推论**：「核起来贵」**推不出**「作者可以不举证」，它只推出「我们不必每条都去核」（`docs/DECISIONS.md:141`）。

### 2.4 「来源可查性」——只判可不可查，不判可不可信

对清单里每条主张所声称的来源，记三问（各二元）：

1. 能不能**定位**到具体文献／机构／页面（有题名、作者、年份、机构名之一即可起查）；
2. 能不能**打开**（付费墙、已删除、只在图片或视频里 = 打不开）；
3. 是不是**转述的转述**（「据某媒体报道」而没有更上一层）。

三项只描述**可查性**。**不得**据此给来源贴「可靠／不可靠」标签——来源类型不进任何轴（`docs/research/00-foundations.md:342` 的 `A2` 口径）。

【本报告工程约定】三问的措辞与「三问」这个数目；借自 SIFT 四步「Investigate the source / Trace claims to the original」的动作方向（`docs/research/methodology.md` §3.5.1）。

### 2.5 「查不到」不是随口说的

判定者写「查不到 / 文章没有出处 / 这篇文章没有处理 X」之前，**必须同时给出检索方式与命中数**（检索词、通道、返回条数）。给不出，就只能把该条记作**未核**，不得记作「查不到」（`docs/DECISIONS.md:141` 的 `#75` 新纪律）。

## 3 每条主张的核查三态

| 态 | 判定 | 证据（必须随条目给出） |
|---|---|---|
| `一致` | 与可打开证据相符，**对象、年份、口径**都对齐 | 外部证据的逐字片段 + URL／DOI |
| `查不到` | 按 2.5 的检索式检索后**命中 0** | 检索词 + 通道 + 命中数 |
| `冲突` | 与可打开证据**直接冲突**，且**同一对象、同一口径** | 双方原文片段各一段 |

- 三态都是**二元判定**，逐条给，不给概率、不给分数。
- **口径对齐是残留自由度**：同一数字在不同年份、不同校区、不同统计口径下不同，**不算冲突**。凡判 `冲突`，必须写出「对齐的是哪个口径、为什么这两个数说的是同一件事」。

## 4 档位

| 档 | 条件 | 一句话 |
|---|---|---|
| `A` | 被核的承重主张**全部** `一致`，**且覆盖了全部承重主张** | 信得过 |
| `B` | 被核的承重主张**全部** `一致`，**且没有任何一条 `查不到`**；未核的部分照实写进覆盖率 | 信得过，但只覆盖被核的那几条 |
| `C` | 被核的承重主张**一部分一致、一部分 `查不到`** | 部分信得过 |
| `D` | **≥1 条**承重主张与可打开证据**直接冲突** | 信不过（红灯 `C-1`） |

- `B` 与 `C` 的分界是「**有没有查不到**」，**不是**「来源好不好」——来源类型不是判据（见 §2.4）。
- 取 `B` 时**必须同时写出覆盖率**（「已核 x 条 / 共 M 条承重主张」）——`B` 允许覆盖不完整，代价就是覆盖率必须写在读者看得见的地方（写法同 §5.1）。
- 无 `一致` 且无 `冲突`（全部查不到）时按 `C`，并在卡面写明「全部未查到」。
- 出档的前提是状态位 `已评估`；状态位不是 `已评估` 时档位写 `—`（不变式见 `templates/screening-card.md` §状态位）。

〔模型推论：由「被核的全部一致 → 信得过」「部分一致 → 部分信得过」「直接冲突 → 信不过」三条短句（`_scratch/source-audit/stage2/s1-axes.md` §2.2）加「覆盖是否完整」这一维推出。`B` 这一档是 `#79` 五值状态位之后新增的：覆盖不完整必须能被表达，否则又回到「要么全核、要么记未核查」的二选一〕

## 5 状态位在本轴的用法

闭集与「必须附写」列见 `templates/screening-card.md` §状态位，**本文件不复述**。本轴只补充三条取值边界：

1. `未核查` = **该核，本次没去核**（含「通道完全不可用所以一次检索都没发起」）。
2. `无法核` = **去核了，但核不了**：检索通道不可用、找不到任何权威源、或文本没给出作者／机构身份标识因而无从起查。
3. `已评估` = 跑了。**注意**：文本**没有可核项**也取 `已评估`，附写「已核 0 条：无可核项」——「没东西要核」不等于「没去核」。
4. 以上三条的判据是「**有没有发起核查**」，不是「核了几条」：只核了一部分的取哪个状态位、覆盖率怎么写，见 **§5.1 部分执行**（不复述）。

### 5.1 部分执行（G3）：**不能二选一**

外部检索**只做了一半**（核了一部分承重主张、其余因通道被限速或文本线索不足没核完）时：

- 状态位仍取 **`已评估`**（跑了）；
- 「必须附写」列必须写**覆盖率**：`已核 X 条 / 共 M 条承重主张；未核 Y 条，原因：<通道限速／无定位线索／…>`；
- 档位只对**被核子集**负责，卡面该栏必须写出「结论仅覆盖被核的 X 条」；
- **不得**因为没核全就整栏记 `未核查`（那等于把已做的核查作废），也**不得**只写「已核」而不写覆盖率（那等于假装核全了）。

【本报告工程约定】覆盖率写法与「已评估＋附写覆盖率」这个组合。依据：`#79` 已把「没去核」与「去了核不了」分开，剩下的「核了一部分」必须落在 `已评估` 内的附写里，否则又出现第三种无处可写的情形。

## 6 红灯 `C-1`

- 本轴**唯一**的红灯是 `C-1`。**触发条件的唯一真源是 `references/07-redlines.md`**，本文件不复述条件原文（跨文件不变式：红灯条件只许在一处写全）。
- 本文件只约束两件事：
  1. **命中即本轴记 `D`，且不得抹掉另外两轴**——三轴并排呈现、不合成、不互相否决（`references/07-redlines.md` §2 红灯的通用约束）。
  2. **命中以「经本跑次核查」为前提**：状态位是 `未核查` 或 `无法核` 时，本轴**不产生红灯**；此时只能写「本次未核，未判定」。

## 7 与相邻轴的边界（防重复计分）

- **同一段原文可以同时进 `W` 与 `C`，但只判两件不同的事**（见 §1 的逐字出处）。
- **禁止**把「来源可核」当作 `V` 轴的加分，也**禁止**把「一手材料多」当作本轴的加分——本轴只看**真值一致性**，`V` 只看**新颖性**。
- **未实测前只声称「判定动作已分开」，不声称三轴已被证明可分离**（区分效度需实测秩相关，阈值必须实测标定，不得编数字；工具见 `docs/research/00-foundations.md:238`）。

## 8 已知局限（照实写）

1. **抽多少条没有依据**：不设固定 `k`，长文工作量不封顶；覆盖率只能在卡上暴露，不能被"标准化"。
2. **「直接冲突」需要口径对齐**，而口径对齐本身要判断——同一数字的年份／校区／统计口径差异不算冲突。
3. **Admiralty 移植到文章无背书也无批评文献**【待核实】：本协议只借「来源与信息分开评」这一**结构**，不声称等价（`docs/research/00-foundations.md:232`）。
4. **旧的四分类（一手／二手／无出处／不可核）已废止**：它把「类型」「属性缺失」「流程状态」三种逻辑混在一处（`docs/research/00-foundations.md:230`）；本协议只保留「有没有出处」＋状态位两件东西。
5. **本轴是三条轴里唯一会被通道状态直接打垮的轴**：通道不可用时它交不出档位，只能交状态位。另两轴不受影响。
