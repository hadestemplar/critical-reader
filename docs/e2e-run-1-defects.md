## 1. 核心结论（先给判断，再给证据）

**三份产物都不构成可复现的 v1 样例。** 三条独立理由：

1. **A 轨执行者的档位与轨道都取决于两条互相冲突的读法**（M1 / M2 / M4：`B`🟢 ↔ `C`🟡、`A 轨` ↔ `B 轨`）。它自己写明「同一篇跨档」。
2. **C 轨执行者的轨道与档位也取决于读法**（A1 / A3：`C 轨` ↔ `B 轨`、`C`🟡 ↔ `无法判定`🔵）。它的 `score_raw = 0.299988`，**舍入到 0.30 就落 B 轨、不舍入就落 C 轨**。
3. **B 轨执行者**的档位没有跨档分叉（`C`🟡），但它报出的同一批矛盾里，M1 的读法 A 会把它从 `C` 拉到 `B`——它自己在 B1/B2 里逐字写出了这两种读法。

**共通根因只有三条**（见 §3）：① 同一件事被两个文件用不同口径各自映射（映射表 vs §二锚点 / 契约 vs 脚本 / 契约 vs 报告规范）；② 硬边界上没有「取未舍入值还是展示值」的规定；③ 离线是本仓常态，而协议里仍有若干规则把「查不了」写成了「没通过」或「查过且通过」。

### 共因一 · 同一件事被两个文件用不同口径各自映射

#### D-01 ★★★ 映射表给出的维度取值与 §二 锚点冲突，且出现闭集外的非法值
- **证据 1（非法值）**：`references\07-rating.md:65` 把 `L4 = 可败` 映射为 `D2` **中低档**——而维度取值闭集是三值（`rubric\quality-dims.md:67` 与 `:71-73` 的 `低` / `中` / `高`）。**「中低档」不是合法取值**（lead 已在现盘复核原文）。
- **证据 2（同维两套口径）**：`07:70` 把 `L5 = 弱` 映射为 `D4` 低档；而 `rubric\quality-dims.md:71` 规定 `低` ＝「只能给出负面判定（缺什么）」或「写不出任何原文片段」，对 `D4` 另加限定「指**文本自身**未给署名、未给出处、无可溯源线索」。三篇文章里都出现了「L5 弱但文本自身给出了若干线索」的情形 → **映射表说 `D4` 低、锚点说 `D4` 中**。

- **lead 复核**：已复核 `07:60-75`、`07:156-159`、`quality-dims.md:65-75` 原文，冲突成立。
