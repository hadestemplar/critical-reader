# 01 · L0 体裁与处置

## 本层回答的唯一问题

这是哪一类文本？该用哪套判据？

> 该字符串逐字取自 `references/00-protocol.md` §3 每层的统一输出块「各层 question 固定表」的 `L0` 行（唯一真源，见 `DECISIONS.md` #26①）。

## 输入

| 输入项 | 必需 | 说明 |
|---|---|---|
| 正文全文（归一化 Markdown） | 是 | 含标题与全部段落；截断时必须给出正文覆盖率 |
| 元数据 | 是 | 标题 / 来源（公众号名或站点）/ 作者 / 发布日期 / 字数 / 采集方式（`references/00-protocol.md` §4 报告结构「第 1 章 文章元数据」） |
| 结构统计（JSON） | 是 | 由 `node scripts/struct-stats.mjs <正文文件> --json` 生成，输出 JSON，字段名固定为 `sentences`（句数）/ `paragraphs`（**正文非空行数，含非文本行；它不是「段落」的个数，不是自然段落数**）/ `orderedListItems`（有序列表项数）/ `codeBlockLines`（代码块行数）/ `externalLinks`（外部链接数）/ `blockquotes`（引用块数）/ `chars`（字符数）/ `latinWords`（拉丁词数）/ `frontMatterLines`（YAML front-matter 行数）/ `textLines`（**正文文本行数** = `paragraphs` 减去非文本行；非文本行 = `![图N]` 独占行、纯 URL 独占行、水平分割线行、纯标点行。`L0-R4` 的 `S` 与 `L0-R5①` 的分母**必须**用该字段）；脚本不可用或字段缺失时本层 `degraded: true`，并在 `unknowns[]` 逐字记录缺失字段名（用英文键名，不得自造字段名） |
| 上游 | 无 | L0 是六层的第一层，不依赖其它层 |
| 本层不消费 | —— | 检索通道、外部网络、其它层的判定结论 |

## 输出字段

沿用 `references/00-protocol.md` §3 每层的统一输出块，**不新增块级字段**；L0 专属信息全部落在 `items[]`，用固定 `id` 前缀约束。

`verdict`（枚举，必取其一）：

| 取值 | 含义 | 下游动作 |
|---|---|---|
| `A 轨` | 全量批判性审查 | L1 → L2 → L3 → L4 → L5 → L6 |
| `B 轨` | 降级审查：只审「可论证化的显式主张」（≤3 条；定义、裁剪与覆盖率规则见 `L0-R9`） | L1 → L2 → L3 → L4 → L5 → L6（只审显式主张子集） |
| `C 轨` | 非论证型快筛（换判据，**不换审核义务**） | L1 → C 轨判据（`08-track-c.md`）→ L6；**不进入 L2–L5 的论证判据**，但**仍须由 L6 按 `DECISIONS.md` #56③ 判 `V7`（无收获）与 `V8`（主张无据）** |
| `混合/不确定` | 体裁无法归类，或两个标签分数并列且无法区分主副 | 按 B 轨处理，并显式记录不确定 |
| `无法判定` | 输入残缺（正文覆盖率 < 30%、乱码、仅目录页） | 该层 `items: []`，原因写进 `unknowns[]` |

> **轨 ≠ 档（#55① 根因）**：本表三个取值是**审查轨道**（决定该用哪套判据），**不是** L6 的档位／灯。L6 档位闭集＝`A`｜`B`｜`C`｜`D`｜`无法判定`（删 `S`；`S` 作为「操作块占比」信号仍留在本层 `L0-R4` 内），灯映射 `A`🟢 `B`🟢 `C`🟡 `D`🔴 `无法判定`🔵（`DECISIONS.md` #56①②）；**红灯 ＝ 命中否决项 `V1`–`V8` 任一**（`V7` 无收获／`V8` 主张无据）⇒ `D`／🔴 且**不进质量分级**（#56③＋编号更正）。本层只出行轨道，**不下档位、不下灯、不判 `V1`–`V8`**（交 L6）。

`items[]` 固定条目（`id` 前缀即语义，缺条即不合格）：

| id | 承载内容 |
|---|---|
| `L0-G1` … `L0-G7` | 七个体裁标签各一条，至多出现 3 条；`claim` 固定格式：`体裁标签 <label>=<score>`，其中 `<score>` **只能取五档锚点值** `0｜0.25｜0.50｜0.75｜1.00`（锚点定义见 `L0-R10`） |
| `L0-S1` … `L0-Sn` | 每个计入分数的信号一条（可数证据） |
| `L0-A1` | 论证性分数一条：`论证性分数 = <score>；候选轨道 = <A 轨|B 轨|C 轨>；O = <1|0.5|0>`（O 必须落条，供 `L0-R6` (b) 机械判定） |
| `L0-D1` | 处置与一句话理由 + 覆盖公示（三段都不得省略）：`处置 = <A 轨|B 轨|C 轨|混合/不确定|无法判定>；理由 = <≤40 字>；覆盖记录 = <无｜硬覆盖 <特征> 覆盖 <被覆盖的分数与候选轨道>｜体裁实体判定 <行名> 覆盖 <被覆盖的分数与候选轨道>>` |

七个标签取值（闭集，不得自造）：`argument` 论证/评论｜`academic` 学术/技术论证｜`tutorial` 教程/操作指南｜`news` 新闻报道｜`exposition` 科普/解释｜`narrative` 叙事/文学｜`persuasion` 营销/说服。

## 七体裁成功标准与典型失败模式（自足副本）

| 标签 | 原表行名 | 该体裁的「成功标准」 | 典型失败模式 | 该体裁**看什么**（阅读取向；**不决定是否审查**，#56④） |
|---|---|---|---|---|
| `argument` | 论证/评论类 | 主张明确、前提成立、推理有效、回应最强反方、结论与前提自洽 | 单一来源、诉诸情绪、稻草人、循环论证、隐含假定未辩护 | 看论证链（核心场景） |
| `academic` | 学术/技术论证类 | 问题—方法—证据—结论链条完整、可复现、局限性明示 | 混淆相关与因果、过度外推（非人类研究→人类）、p-hacking、幸存者偏差 | 看方法—证据链条（其权重要高于修辞） |
| `tutorial` | 教程/操作指南 | 步骤可复现、前提条件与环境写全、结果可验证（Diátaxis：goal-oriented，帮助用户「correctly and safely」完成某事） | 漏掉前提/版本、环境差异、幸存者偏差（只展示成功路径）、把「我这能跑」当「通用可行」 | 不看论证链（论证审查无效）；**仍须过 `V7`（无收获）筛** |
| `news` | 新闻报道（消息类） | 来源可靠、事实准确、框架不偏、可追溯到一手材料 | 单一来源、事实错误、框架偏斜、转载放大 | 不看论证链；看来源、事实与框架（事实核查）；并**按 `V8`（主张有没有支撑）筛** |
| `exposition` | 科普/解释类 | 事实准确、因果机制交代清楚、不确定性如实呈现 | 把「解释」写成「论证」（伪因果）、夸大效应、省略不确定性、以科普之名复制新闻稿夸大 | 只审其**显式主张** |
| `narrative` | 文学/叙事类 | 审美与情感效果、叙事自洽（内部一致性） | 「不真实」不是失败；事实错误通常不构成缺陷 | 不看论证链；但按 `V7`（有没有收获）与 `V8`（承重主张有没有支撑）审——**叙述／抒情形态照受不合格判定**（#56④） |

> **注（W3-11 裁定，本层操作性口径优先于本副本原表行文）** `narrative` 一行原表的「审美与情感效果」**不作为本层的判定依据**（它给不出可数证据）。本层 `narrative` 标签只依**可数信号**判定：① 第一人称段落占比（`L0-R3` ⑥）；② 时间 / 场景标记密度；③ 无显式主张段占比。原表行文保留不改，以维持本副本的逐字完整性。【出处：`docs/fixwave-3.md` §3 W3-11 裁定；【本报告工程约定】】
| `persuasion` | 营销/说服文案 | 达成说服效果（Reiss: operative, equivalent effect） | 「效果导向」天然与「真相导向」冲突：夸大承诺、隐藏成本、制造紧迫 | 暴露其说服手段与未言明代价（不评「推理是否有效」）；同样照受 `V7`／`V8` 判定 |

## 判定规则

- **L0-R1（多标签强制）** 必须输出 1–3 个体裁标签，每个带 0–1 分数；输出单一标签即不合格、输出 ≥4 个标签即不合格。不得出现「非此即彼」的单标签硬门控。【出处：`DECISIONS.md` #8；`docs/research/genre-taxonomy.md` §0①、§4.1、§5.1】
- **L0-R2（标签边界＝成功标准）** 每个标签的判定必须引用该体裁的「成功标准 / 典型失败模式」行，不得凭语言表面特征贴标签。七行见本文件「七体裁成功标准与典型失败模式（自足副本）」表（argument / academic / tutorial / news / exposition / narrative / persuasion 逐行），**运行时不依赖仓库外文件**。【出处：`docs/research/genre-taxonomy.md` §2（副本已随本文件固化，复制日期 2026-10-13）】
  **表：标签 → 轨**（实体判定的产物；主标签＝标签分最高者，并列时取更严者。判据列引本文件「七体裁成功标准与典型失败模式（自足副本）」的「该体裁看什么」列）

  | 主标签 | 轨 | 依据 |
  |---|---|---|
  | `argument` | `A 轨` | 论证链是核心场景（表「看什么」列） |
  | `academic` | `A 轨` | 同上 |
  | `persuasion` | `A 轨` | 说服文的主张—理由结构必须审 |
  | `exposition` | `B 轨` | 表定「只审其**显式主张**」＝B 轨定义 |
  | `news` | `B 轨` | 表定「看来源、事实与框架」＋`V8` 筛＝审显式主张 |
  | `tutorial` | `C 轨` | 表定「不看论证链」 |
  | `narrative` | `C 轨` | 表定「不看论证链」 |
  | `混合/不确定`、或无法给出主标签 | 按 `L0-R4` 的**分数候选轨道** | 实体判定无输出时的唯一兜底 |

  - **配套一**：`L0-R5` 硬覆盖仍是最上级——`L0-R5` ③（`persuasion` + 导流 + 独立信息 0 → `C 轨`）**覆盖**本表的 `persuasion → A 轨`。
  - **配套二**：`L0-R9` 是**唯一的上调例外**（`score ≥ 0.60` ∧ 命中 `tutorial`／`news`／`narrative` → `A 轨`，只审显式主张），它**只升不降**。
  - **配套三**：分数候选轨道**降为兜底**——`L0-R11` 的 ③ 只在上表落「`混合/不确定`、或无法给出主标签」时**作为最终轨道**；其余情形它仍有值、仍要公示，但不决定轨道。

  【出处：`docs/e2e-run-2-defects.md` G-16；不得用 `m/M`／`k` 下调审查强度的依据＝`docs/calibration-30.md` §6.2（标签档位不可复现、`score` 5/5 逐字相同）；映射表本身＝【本报告工程约定】】

- **L0-R3（可数信号表，含消费方映射）** 下列信号必须逐个统计并落成 `L0-S*` 条目，且每项必须写明其**消费方**（无消费方的信号不得作为独立条目存在）：① 论证指示词密度 → 消费方 `L0-R4` 的信号 `D`（＝论证指示词密度）；② 主张（论断）句比例 → 消费方 `L0-R4` 的 `P`；③ 可见对立结构 → 消费方 `L0-R4` 的 `O`；④ 数字 / 引文 / 来源标记密度 → 消费方 `L0-R2` 的体裁实体判定与 `L0-R5③` 的导流计数（**不进入分数合成**，只作出处证据；理由：该项对 `news` / `exposition` 的判别力在调研中无实证，见已知局限 4）；⑤ 步骤 / 命令 / 代码块占比 → 消费方 `L0-R4` 的 `S`；⑥ 第一人称段落占比（= 含「我」的段落数 ÷ 段落数）→ 消费方 `L0-R5②` 的机械输入（**不进入分数合成**）。原有第 ⑥ 项「人称与时态分布」中的「时态」**已删除**——汉语无 tense，该项不可执行。**计数工具（G-18）**：`P` / `D` / `O` 的分子**没有任何现成脚本产出**（`scripts/struct-stats.mjs` 只输出结构量：`sentences` / `paragraphs` / `textLines` / `orderedListItems` / `codeBlockLines` / `externalLinks` / `blockquotes` / `chars` / `latinWords` / `frontMatterLines` / `bytes`）；判定者必须**自写计数**，并把**所用命令与输出**逐字写进该 `L0-S*` 条目，使第三方可按同一命令复核；**不得只写结果不写命令**（第二轮三个执行者各用不同办法，同一篇的 `P` / `D` / `O` 因此不可跨执行者比较，原因正是缺这条）。【出处：信号定义见 `docs/research/genre-taxonomy.md` §3.3 特征表；④⑥ 的消费方绑定、⑥ 的定义与「时态」删除＝【本报告工程约定】】
- **L0-R4（可机械执行：论证性分数合成与候选轨道边界）** 按固定权重合成，权重之和 = 1.00：

  | 信号 | 计算式 | 权重 | 归一方式 |
  |---|---|---|---|
  | P 主张句比例 | 含下列**闭集断言谓语词表**任一逐字命中的句子数 ÷ 句数（同一句命中多词只计 1 句） | 0.40 | 直接取值（0–1） |
  | D 指示词密度 | 词表命中总数 ÷ 句数 | 0.30 | `D' = min(D / 0.30, 1)` |
  | O 可见对立结构 | 按下方「O 判定表」逐字匹配，取三档值 `1｜0.5｜0` | 0.20 | 三档 |
  | S 操作块占比 | （有序列表项数 + 代码块行数）÷ **正文文本行数**（脚本字段 `textLines`；**分母只允许是脚本字段 `textLines`，不得使用任何无字段来源的行数口径**） | 0.10 | 反向：`1 − min(S / 0.40, 1)` |

  `论证性分数 score = 0.40P + 0.30D' + 0.20O + 0.10(1 − min(S/0.40,1))`。**全场判定一律使用未舍入的原始 `score`；四舍五入到两位小数只用于展示与记录。**
  **候选轨道边界（硬边界）**：`score ≥ 0.60` → A 轨候选；`0.30 ≤ score < 0.60` → B 轨；`score < 0.30` → C 轨。**本边界一律使用未舍入 `score`**（依据 `docs/DECISIONS.md` #61④）。
  论证指示词词表（闭集）：`因为｜由于｜所以｜因此｜然而｜但是｜显然｜由此可见｜研究表明｜数据显示｜综上｜可见｜这说明｜这意味着｜反驳｜有人认为｜另一方面`。

## 已知局限

1. **候选轨道边界与权重无先验依据。** 0.60 / 0.30 / 0.40 等数值全为工程约定，必须由锚例校准钉死并冻结，不得事后按心情调整（校准方式已由 `DECISIONS.md` #55 改为随用户真实投喂逐篇积累，#7 的「30 篇锚例」方案已被 #55 取代；`docs/research/rating-design.md` §3）。在此之前，本层结论应视为**待校准**。
2. **中文不能照搬英文阈值。** 中文论证常以零形式衔接推进（无显式连接词），指示词密度阈值不可照搬英文语料；该断言本身在调研中标为**推断、无直接实证**（`docs/research/genre-taxonomy.md` §3.4「需谨慎」第 1 条）。
3. **「因为」类指示词的语用歧义无法靠词表消解**：指示词在解释文中同样高频（`docs/research/genre-taxonomy.md` §3.3 已知风险行；`docs/research/methodology.md` §6.1）。因此 L0-R4 的 D 只能作为**旁证**，不得单独决定处置。
4. **可见对立结构对中文论证文覆盖不足**：大量中文论证文并不显式反驳（`docs/research/genre-taxonomy.md` §3.3）。该项记 0 不等于无数论证。
5. **「5+1 类」与「7 个标签」的表述冲突**：`docs/research/genre-taxonomy.md` §5.1 标称「5+1 类」却列出 7 个标签。本文件按**7 个标签**执行，与 `DECISIONS.md` #8 的括号内枚举一致；该冲突**已在调研文档修正**（`genre-taxonomy.md` 已统一为「7 类（闭集）」）。
6. **LLM 的体裁排序能力可靠度高于其绝对置信度**：应按「多标签 + 分数 + 显式理由」输出，不得输出单一高置信断言（`docs/research/genre-taxonomy.md` §4.2 综合判断）。
7. **本层不判结构。** 论题/结论/论据的抽取属 L2，本层越界即不合格（`references/00-protocol.md` §7 各层文件与负责人边界）。
8. **C 轨不是「无需把关」。** 判 C 轨只改变判据集合，不改变把关义务；C 轨必须配第二套判据、显式声明未做论证审查，并**由 L6 按 `DECISIONS.md` #56③ 判 `V7`／`V8`**（#9、#56④；`docs/research/genre-taxonomy.md` §5.4 方案丙）。
9. **标签分五档锚点与 P 闭集词表同为工程约定、尚未校准**：五档锚点与 P 词表能让两个独立执行者复算出同一个 `score`，但**不保证该分数与「论证性」真值相关**（锚点本身也是人写的）；须与已知局限 1 在同一冻结窗口内由锚例校准钉死（校准方式见 `DECISIONS.md` #55），在此之前本层结论一律视为待校准。
10. **三行「未纳入闭集形态」的映射规则未经实测检验**：映射附录中「技术参考 / 说明书」「个人随笔 / 观点帖」「工具 / 产品更新说明」三行形态的映射目标与分流阈值（`score ≥ 0.60`）在现有三跑样本里**没有对应文本**，属于为消除「无对应实体判定行」缺口而补的规则；出现该类文本时必须单独记录实际判定，作为后续校准的锚例来源。
