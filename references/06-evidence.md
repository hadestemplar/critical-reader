# 06 · L5 证据强度

## 本层回答的唯一问题

**文中的事实主张有多硬？**

> 逐字出处：`references/00-protocol.md` §3 各层 `question` 固定表（唯一真源）；该表与 `docs/research/methodology.md` §5.1 六层协议表「L5 证据强度」行一致。报告与本层输出块的 `question` 字段必须逐字使用这一句，标点不得改动。
> 本层边界（`references/00-protocol.md` §7）：只做「事实主张清点、出处类型、证据等级」，**不判真假**（交人工核查）。

## 输入

| # | 输入 | 来源 | 用途 |
|---|---|---|---|
| 1 | 原文全文（含小标题层级、段落编号、图表位置标记） | 输入层 | 所有 `items[].evidence` 只能逐字取自这里 |
| 2 | `L0` 输出块（体裁多标签 / A 轨·B 轨·C 轨处置） | L0 | 决定本层是否执行 |
| 3 | `L1` 输出块（作者可查性 / 利益相关性 / 外部交叉核查结果 / `degraded`） | L1 | 判断某条出处是否可被外部打开；L1 降级时本层不得补做核查 |
| 4 | `L2` 输出块（论据清单、四要素） | L2 | 确定哪些事实主张**承担论证重量**（其余主张只作清点） |
| 5 | `L4` 输出块 | L4 | 只读，避免把同一 span 重复登记为缺陷与证据问题 |

执行条件：**仅 A 轨与 B 轨执行本层**。C 轨不执行 L5，改按 `references/08-track-c.md`（`00-protocol.md` §2、§7）；**C 轨不执行 L5 不等于免检**——仍由 L6 判 `V7`/`V8`（`DECISIONS.md` #56④）。

## 输出字段

统一输出块字段见 `00-protocol.md` §3；本层的取值与专属字段如下。

| 字段 | 取值 | 必填 | 说明与出处 |
|---|---|---|---|
| `items[].id` | `L5-<块字母><序号>`；块字母＝`P` 一手出处 / `S` 二手出处 / `N` 无出处 / `U` 不可核（按该条 `sourceType` 取） | 是 | `00-protocol.md` §3 字段约束表 的 `items[].id` 命名法：层内唯一、跨层不重复 |
| `verdict` | `强` \| `中` \| `弱` \| `无法判定` | 是 | 由 R10 的相对判据产生，不引入外部比例阈值 |
| `items[].sourceType` | `一手` \| `二手` \| `无出处` \| `不可核` | 是 | 四分类，定义见 R4；`DECISIONS.md` #13 要求的「出处类型」字段 |
| `items[].needManualCheck` | `是` \| `否` | 是 | `DECISIONS.md` #13 要求的「是否需要人工核查」字段；取值规则见 R5 |
| `items[].imvain` | 6 位 `0/1` 串（I-M-V-A-N-E 顺序）；`sourceType` 为「无出处」或「不可核」时固定写 `—`（**不得**留空、**不得**编造 6 位串） | 当 `sourceType ∈ {一手, 二手}` 时必填 | methodology §3.5.5；`—` 口径＝【本报告工程约定】 |
| `items[].downgrade` | 命中的打折域名称数组（可为空） | 是 | methodology §5.1 L5 行 + §5.3②；**必须声明它不是 GRADE 本身** |
| `items[].bearsWeight` | `true` \| `false` | 是 | 该主张是否承担论证重量（由 L2 论据清单决定） |

`items[]` 由**逐条事实主张**构成，不是逐段、更不是整篇一句话。清点结果必须输出两个计数：`N_total`（事实主张总数）、`N_with_source`（有可打开出处的主张数）。

## 判定规则

**R1【可机械执行 · 计数】事实主张必须逐条清点，结论只能用两个计数表述。**
报告与本层块必须给出 `N_total` 与 `N_with_source`；任何概括性表述（「这篇文章出处很多」「基本没给来源」）**不得**作为本层结论，只能作为对两个计数的附注。
〔出处：`docs/DECISIONS.md` #13 与 `references/00-protocol.md` §4 第 9 章（事实主张逐条 + 是否给出处 + 出处类型 + 是否需要核查）〕

**R2【可机械执行 · 字符串扫描】无主语来源指称必须逐句登记。**
扫描核心词表 `研究表明`、`有数据显示`、`专家指出`、`业内普遍认为`、`相关人士透露`、`据悉`、`有消息称`、`网上说`、`大家都知道`，每一处命中登记为一条 `item`（`sourceType=无出处`），附原句与 `locator`；**命中数 = 登记条数**。
**兜底句式（防系统性漏登）**：任何满足「**无主语 + 认知 / 言说类动词**」的句子必须同样登记，即使不含上面任何一个词。可机械执行的检索式：`(文献|学者|专家|研究者|资料|史料|报道|媒体|业内|观点|数据|调查|统计|研究)[^。；\n]{0,6}(发现|表明|指出|认为|显示|采用|提出|证实|报道|透露|称|说)`，以及 `有(人|观点|说法|资料|文献|学者|专家|史料|报道|调查)[^。；\n]{0,4}(发现|表明|指出|认为|显示|称|说|透露)`。实测中文长文的主要形态是 `有文献发现`、`有学者采用`、`有史料表明`、`有观点认为`——旧的闭集词表一条都扫不到（`docs/fixwave-2.md` 簇 G2：机械扫描得 0 条、实际 7 处）。命中一律 `sourceType=无出处`，并在 `trigger` 里写明命中的是哪个句式。
〔出处：`docs/research/methodology.md` §6.2 后果 1 —— 主语缺失导致责任主体模糊：「研究表明」「有数据显示」这类无主语句在中文里语法上完全合法，因此不能靠语法异常检测，只能靠**专门的来源缺失检测**；新增词条与兜底检索式（G2 修复项）为【本报告工程约定】〕

**R3【可机械执行 · 二元 × 6】每条有出处的来源主张，必须过一遍 IMVAIN 六问，记 6 位 0/1。**
I＝Independent（是否独立于被报道对象）；M＝Multiple（是否有第二个独立来源）；V＝Verifies（是否做了核实而非只是转述声称）；A＝Authoritative/Informed（是否该领域的知情者）；N＝Named（是否具名）；E＝Evidence-based（是否指向可查证的材料）。任一问无法判断记为 `0` 并写入 `unknowns[]`；`sourceType` 为「无出处」或「不可核」时 `imvain` 固定写 `—`（**不得**留空、**不得**编造 6 位串）。
〔出处：`docs/research/methodology.md` §3.5.5 —— IMVAIN 六条，「每条是判定式问句，可直接机器化」；§5.1 L5 行指定采用〕

**R4 出处类型四分类（判定式定义）。**
- `一手`：给出可打开的原始材料（原始数据、论文、法规原文、官方公告、现场记录、可复现的实验步骤），且不是对他人转述的转述。
- `二手`：给出的是转述、编译、二手综述、他人报道（含"据某媒体报道"）。
- `无出处`：该事实主张在文中没有任何来源标记（含 R2 命中的全部条目）。
- `不可核`：形式上给了来源但无法打开或无法对应（匿名信源、已删除链接、付费墙后材料、只存在于图片/视频中的内容）。
四分类本身为【本报告工程约定】；「来源」与「信息」分开评级的做法借自 methodology §3.5.4 Admiralty Code（两轴分离）。
**判定优先序（机械，按 ①→④ 顺序取第一个命中项，不得按印象切换）**：① 材料可打开且是原始材料 → `一手`；② 材料可打开但是转述 / 编译 / 二手综述 / 他人报道（含「据某媒体报道」） → `二手`；③ 形式上有来源标记但打不开、或指向匿名信源 / 已删除链接 / 付费墙 / 只存在于图片视频中 → `不可核`；④ 文中**没有任何来源标记**（含 R2 命中的全部条目） → `无出处`。**「转述他人研究但没有文献标识」按 ④（`无出处`）登记**——按定义它没有可对应的来源标记，不得因为「读起来像是引用」而记 `二手`。
〔出处：`docs/research/methodology.md` §3.5.4、§3.5.5；分类粒度与优先序（G4 修复项）为工程简化 / 【本报告工程约定】〕

**R5【可机械执行 · 二元】`needManualCheck` 取值规则。**
取 `是`，当且仅当满足其一：① `sourceType ∈ {无出处, 不可核}` **∧ `bearsWeight=true`**；② `imvain` 中出现 `0` 且 `bearsWeight=true`；③ `sourceType=二手` 且 `bearsWeight=true`。其余取 `否`。取 `是` 的条目必须同时出现在报告第 11 章「不确定与待核实」中。
〔出处：【本报告工程约定】——落实 #13「只标注需核查项，不自动判真假」；三段条件分别对应「无据」「来源质量不足」「非一手但承重」三种风险形态，三段**均以 `bearsWeight=true` 为前提**（G5 修复项：非承重主张不进人工核查队列，避免把全文每一条事实都推给人工）〕

**R6 打折卡：五个降级域逐条二元判定，命中只记录不折算分数。**
① 对象 / 情境外推（研究做在别的对象或环境上）；② 样本量或数据范围未交代；③ 相关性被表述为因果；④ 结论强度超出证据（无区间、无不确定性、无边界条件）；⑤ 只呈现支持性证据、未见反例或被排除的解释。命中项写入 `downgrade`。**报告必须同时声明：这是 GRADE 五降级域的通俗化工程折衷，不是 GRADE 本身。**
〔出处：`docs/research/methodology.md` §5.1 L5 行「GRADE 五降级域通俗化」+ §5.3②「GRADE 通俗化会损失严谨性……报告里必须声明它不是 GRADE 本身」〕

**R7 不得判真假。** 本层**禁止**输出「该主张为真 / 为假 / 虚假 / 已被证伪」。只输出四件事：是否给出处、出处类型、是否需要人工核查、（可选）打折域命中。任何真伪结论都属越界。
〔出处：`references/00-protocol.md` §1 不回答表 + 硬规则 3「L1 不得省略」；`docs/DECISIONS.md` #13〕

**R8【可机械执行 · 二元】图片承载的关键信息必须单独登记。**
若关键数据或结论只出现在图片 / 截图 / 动图中，而正文无法独立复述该信息，**该主张不得成为 `items[]` 条目**（按硬规则 2「证据强制」：`evidence` 为空者不得成条），改为在 `unknowns[]` 记一条：`item` = 「关键信息仅存在于图像（正文无法独立复述）」，`reason` = 「无文本证据可引用，需人工看图核查」。若该主张另有可逐字引用的正文片段，则照常成条并按 R9 判定。该检查项**没有文献依据，是工程折衷**，必须随条目一并标注。
〔出处：`docs/research/methodology.md` §6.4 —— 「协议结论（工程决策，非文献结论）：把『图片承载的关键信息是否可被文本独立复述』作为一条检查项……并明确标注该检查项没有文献依据」〕

**R9 不重复计条。** 已被 L2 登记为「论据」的同一 span，本层只做证据属性判定（`sourceType` / `imvain` / `downgrade`），**不**重新判定它在论证结构中起什么作用；同一条事实主张在同一篇文章中只出现一次。
〔出处：`references/00-protocol.md` §7 层间边界（L5 不判结构）+ 【本报告工程约定】的去重规则〕

**R10【可机械执行 · 相对判据】`verdict` 不由比例阈值产生，只由「承重主张的出处状态」产生。**
- `强`：全部 `bearsWeight=true` 的事实主张 `sourceType ∈ {一手}`，且 `needManualCheck` 均为 `否`；
- `中`：全部承重主张均有出处，但其中 ≥1 条为 `二手` 或 `不可核`，或 ≥1 条 `imvain` 含 `0`；
- `弱`：≥1 条承重主张 `sourceType=无出处`；
- `无法判定`：输入残缺（提取覆盖率不足）或 L2 未能产出论据清单，原因写进 `unknowns[]`。

本判据用「承重主张的出处状态」而非「有出处条数占比」，是为了避免引入未经校准的比例阈值（阈值待 30 篇锚例校准，见 `references/07-rating.md` R10）。
〔出处：【本报告工程约定】；分级结构参考 `docs/research/methodology.md` §3.5.4 Admiralty Code 的两轴分档思路〕

## 已知局限

1. **「有出处」不等于「出处对」**：本层不判真假（#13），因此引用了一份错误来源的文章在本层可能拿到 `强`。这是本协议为规避高误判率付出的已知代价，必须在报告第 13 章声明。
2. **中文语境的具名率低**：自媒体常以「某业内人士」规避具名（`methodology.md` §3.5.5 局限），IMVAIN 的 Named 项会普遍为 0，本层分数在中文语料上会系统性偏低，**不能与英文语料横向比较**。
3. **四分类的边界靠判断**：`二手` 与 `不可核` 在「来源给了但打不开」时容易互换；Admiralty 信源可靠性 A–F × 信息可信度 1–6 的边界同样需要判断，且无公开信度研究（`methodology.md` §3.5.4 标【待核实】）。
4. **打折卡不是 GRADE**：五域通俗化会损失严谨性，是工程折衷（`methodology.md` §5.3②）。它给出的是提示性降级项，不是证据等级结论。
5. **R8 无文献依据**（`methodology.md` §6.4）；图片为主的文章会大量落在 `不可核`，导致 `verdict=弱`，这是提取能力限制而非文章缺陷。
6. **无网络时无法补核查**：L1 降级时本层只能把来源标为 `不可核`，不得伪造核查结论（`00-protocol.md` §5、#13）。
7. **`bearsWeight` 依赖 L2**：L2 若未产出论据清单或清单不全，R10 的判据整体失效，只能给 `无法判定`。
8. **R2 的兜底句式仍会误登**：明确的转述语境（如作者已交代「我读到一篇论文」后紧接「研究发现」）也会命中无主语句式；本层按「宁多登不漏登」处理——错登可由 R9 去重与人工复核消化，但会推高 `N_total`，进而影响 `N_with_source` 的比值观感。
