## 3. 裁定已定（2026-10-13，由我拍板）

### W3-10 `L0-R5` 三条硬覆盖在 30 篇样本上全部不可命中

**裁定：不调数值。**
理由：`DECISIONS.md` #7 明令阈值数字**必须由 30 篇锚例校准产出、不得事后按心情调整**；而「本批 30 篇打不出来」既不能证明阈值过高、也不能证明过低——本批样本本身是**公众号通道产物**，30 篇 `codeBlockLines` 全为 0，天然缺少真正的操作型文档。
**动作**：① 在 `references/01-genre-routing.md` 的 `L0-R5` 处加一行**实测声明**（30 篇样本实测全部未命中：`S` 最大 0.118、第一人称段落占比最大 50.8%、导流闭集 0 命中），并明确「该声明不构成对阈值正确性的证据」；② 三条阈值的正确性登记进 **T-F7 校准清单**（锚例集须**刻意补入**真正的操作型教程与强第一人称随笔各 ≥2 篇，否则这三条永远测不出来）。

### W3-11 `narrative` 的「审美与情感效果」不可给可数证据

**裁定：移除不可数判据。** `narrative` 标签的判定依据**限定为可数信号**（第一人称段落占比、时间/场景标记密度、无显式主张段占比），删除「审美与情感效果」这项。

### W3-12 `R10`「部分满足」计数法未定义 + `R6` 时效比对无过期门限

**裁定**：
- **`R10` 取消「部分满足」中间态**——标签分必须是闭集取值 `0 / 0.25 / 0.50 / 0.75 / 1.00`，每档判据必须是**二元合取**，不允许「半通过」这种无法复算的表述。
- **`R6` 不设通用时效门限**（「多久算过期」在不同体裁下无普适标准，凭空设一个数就是伪造）。改为要求写出**可核实的时效事实**：能确定发布日期与所引材料日期时标注间隔；只在「引用了已被取代的版本」这类**可判定**情形下写「时效问题」，否则一律进 `unknowns[]`。门限问题同样登记进 **T-F7 校准清单**。
