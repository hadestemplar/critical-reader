# 质量维度与档位锚点（rubric/quality-dims.md）

## 这份文件怎么用（定位）

本文件是 L6 的**计分卡**：定义质量分级的四个维度、五个档位（含灯）的锚点描述、合成规则与防膨胀机制。
**本文件刻意不含任何阈值数字或分数切点**——v1 的档位由红灯判据 + 四维计数映射产生（`DECISIONS.md` #56），不依赖数值切点；0–120 数值留待样本积累后再议（#55 已取消 30 篇锚例校准程序）。所有需要数字的位置一律写「待样本校准」。
配套文件：红灯判据（否决项）见 `rubric/vetoes.md`；L6 的执行规则见 `references/07-rating.md`。

## 一、四个维度（4 维等权）

> **适用范围**：四维**只用于区分 `A` / `B` / `C` 三档**。红灯（`V1`–`V8`）命中即定 `D`／🔴，**不再评四维**；`无法判定`（🔵）不评分（`DECISIONS.md` #56 ①③；`rubric/vetoes.md` §一）。

| 维 | 名称 | 判定问句 | 证据来自 | 与调研建议（`docs/research/rating-design.md` §5.1 轴 2 维度行）的关系 |
|---|---|---|---|---|
| `D1` | **信息增量** | 读完后，我获得了**多少**原本不知道、且无法轻易自行获得的东西？ | `L0` / `L2` / `L5` | 沿用 §5.1 第 1 维 |
| `D2` | **论证质量** | 核心主张的**支撑有多好**：有几条、有没有处理反例与限定、核心链条是否可被检验？ | `L2` / `L3` / `L4` | 沿用 §5.1 第 2 维（「论证与证据」），把「反例处理」写进判定问句 |
| `D3` | **结构与可复用性** | 能否被快速提取、索引、复用为后续工作的输入？ | `L0` / `L2` | 沿用 §5.1 第 3 维（「结构」），把「可复用」并入判定问句 |
| `D4` | **来源与可核查性** | **文本自身**是否给出了可被外部打开、可独立复核的出处（署名 / 出处引用 / 可溯源线索）——即「它是否使核查成为可能」？ | `L5`（文本内的出处属性；`L1` 只提供核查结果，不决定本维档位，见第 5 条后的注） | **替换** §5.1 的「表达（语言质量、可读性）」——理由见下 |

**维度与红灯的边界（同一篇不得重复计数）**

| 问题 | 归谁 | 判据形态 |
|---|---|---|
| 有没有**任何**可用的信息 / 事实 / 方法，或**任何**有价值的观点？（全是空的 → 🔴） | 红灯 `V7`（无收获） | 二元、致命 |
| 信息增量**有多少**？ | 维度 `D1` | 程度（低 / 中 / 高） |
| 承重主张有没有**任何**支撑？（完全悬空 → 🔴） | 红灯 `V8`（主张无据） | 二元、致命 |
| 支撑**有多好**？ | 维度 `D2` | 程度（低 / 中 / 高） |

两条红灯的原文形态与**不触发**情形（例如「有作者自己的推理链支撑、只是材料少」属 `D2` 低，**不命中红灯**）见 `rubric/vetoes.md`（唯一真源）。

**为什么是这 4 个（理由，不是「调研推荐」）**

1. **为什么 4 维而不是 5–7 维**：`rating-design.md` §4 的结论是「在没有标注数据的情况下，**等权 + 否决**是唯一有证据支撑且可审计的组合方式」。加权方案的权重来源不可验证（Saaty-ANP 被批评「does not define the basic concepts, nor does it check the rationality of the structure, which may lead to meaningless solutions」）；学习式合成在无标注数据时不可行且把分数当优化目标会触发 Goodhart 效应。维度越多、权越不可验证，越容易误设，因此**不新增第 5 维**，只在与筛选目的直接相关的 4 条上分。
2. **为什么保留 `D1` 信息增量**：它是筛选问题的直接映射——用户要决定「读不读」，唯一不能由其他维度替代的理由就是「有没有我原本没有的东西」。删掉它，等于把「值不值得读」偷换成「写得规不规范」。
3. **为什么保留 `D2` 论证质量**：本协议的 L2 / L3 / L4 三层全部产出都落在这个维度上（结构、假定、缺陷）；删掉它会使三层的工作在 L6 无出口。
4. **为什么保留 `D3` 结构与可复用性**：中文长文的实际成本主要是提取成本（能否取出结论、方法、清单），这与「值不值得读」直接相关。
5. **为什么用 `D4` 来源与可核查性替换「表达」**（这是对调研建议的**有意偏离**，须在筛选卡中声明）：
   - `references/00-protocol.md` §1 不回答表已把「文章写得好不好看、修辞是否优美」划出回答范围，并在调研中淘汰（`DECISIONS.md` #15）；「表达（语言质量、可读性）」与之高度重叠。
   - 「表达」在中文长尾语料上几乎只能给印象分，无法满足「每一处加减分必须附 ≥15 字原文片段」的强制证据引用要求（`references/07-rating.md` R5）。
   - 来源与可核查性直接对应 `DECISIONS.md` #13 要求的两组字段（出处类型 + 是否需要人工核查），是四维中唯一可以完全机械落地的维度。

> **注：`D4` 不因 `L1` 降级被压档（K-6 裁定）。** `D4` 只度量**文本自身是否使核查成为可能**（署名 / 出处引用 / 可溯源线索）；外部核查**未执行**（`L1` 降级、`degraded=true`）的后果只由 `degraded` 与 `confidence` 承担——该篇 `confidence` 不得为 `高`，筛选卡「读它时要注意什么」节与三栏的状态位必须写出降级事实，**但不得据此把 `D4` 判为 `低`**（契约硬规则 9「降级传导」的措辞是「不得给出**高置信** `Pass`」；`Pass` 在 v1 的两段映射里即 `B` / `A` 档，**低置信的 `B` / `A` 都是合法输出**）。文本自身无署名、无出处、无可溯源线索 → `D4` 低，这是**文本属性**，与判定者能否联网无关（`docs/fixwave-3.md` §6 K-6；`references/07-rating.md` R15）。

## 二、五个档位锚点（含灯；只写特征，不写数字）

档位是**唯一的分级输出**；灯（🔴 🟡 🟢 🔵）是它的**展示形态**，不是第二根轴——灯由档位机械映射，无独立判定（`DECISIONS.md` #56 ②）。

| 档位（灯） | 锚点描述：这一档的文章长什么样 / 什么样的文章算这一档 |
|---|---|
| **`D`（🔴 不合格 · 不用花时间）** | 命中红灯 `V1`–`V8` **任一**（判据唯一真源＝`rubric/vetoes.md`）。`D` **不进质量分级**：不再评四维、不出数值；筛选卡只写「为什么不用读」（红灯编号 + 触发原文 + ≤80 字摘要）。 |
| **`C`（🟡 合格门槛 · 可以看）** | 有收获——新信息 / 数据 **或** 有价值或新颖的观点**至少占一条**；但明显不全：论据不足 / 结构有洞 / 覆盖面小。论题、论点、结论至少都过及格线。（用户口径：「合格门槛、可以看」——不是「条件性」，也不是「平均水平」） |
| **`B`（🟢 值得读）** | 论证较清楚、有实质内容，但**不严谨或不全面**（＝用户给第 21 篇的定位：论证过程相对比较清楚，但整体不是很严谨、论述不全面）。 |
| **`A`（🟢 好）** | 论证扎实、内容充实；主要主张**有可核验支撑**，且**覆盖了主要反面**。`A` 不含任何「无瑕疵」要求。 |
| **`无法判定`（🔵）** | 判定者知识范围不足，或判定标准本身模糊——**必须写清「缺什么才能判」**。**独立一档，不得与 `C` 合并**（`DECISIONS.md` #56 ②：用户明确要求「单独一档，用蓝灯，不要和 C 重复」）。 |

**档位切点与数值：待样本校准**（`DECISIONS.md` #55 已取消 30 篇锚例校准程序，样本改为用户日常阅读中自然积累）。
v1 的档位判定**不依赖切点数字**：红灯命中 → `D`；红灯为空 → 按 §三 的四维计数映射落 `A` / `B` / `C`；`无法判定` 由「判定者判不了」或「四维凑不齐」产生。0–120 数值与切点**当前不存在**（`DECISIONS.md` #40、#55）。

**C 轨的档位锚点不是论证特征。** C 轨不执行论证审查（`references/08-track-c.md` R1 硬声明），其档位由 `references/08-track-c.md` R9 的三条判据计数产生——C 轨的「锚点」是三条判据的取值组合（`k` 条可执行判据的 `check` 结果），**不以论证特征为必要条件**；本表 `B` / `A` 锚点里的「论证较清楚」「论证扎实……覆盖了主要反面」**只适用于 A / B 轨**。C 轨的对应义务是在筛选卡「说得有道理吗」栏逐字声明「未做论证审查」（`references/08-track-c.md` R1 / R2）。
〔出处：`docs/e2e-run-2-defects.md` §3 `G-03`；`references/08-track-c.md` R1、R9；`references/00-protocol.md` §6（档带锚点口径）〕

## 三、合成规则（v1 只出档位，且机械可执行）

**v1 不产出 0–120 数值**（`DECISIONS.md` #40）：数值的合成系数须由样本校准产出，当前协议内不存在可执行的公式。因此 v1 的合成是**红灯 → 档位**与**四维取值（`低` / `中` / `高`）→ 档位**的两段直接映射，**不含任何待校准系数**；顺序是**先红灯、后分级**。

**第 0 步（红灯，先做）**：命中 `rubric/vetoes.md` 的 `V1`–`V8` 任一 → 档位＝`D`／🔴，**第 1、2 步不执行**，不再评四维（`DECISIONS.md` #56 ③）。

**红灯为空 → 执行第 1、2 步（分级）**

**第 1 步：每维取三值之一**（取值必须能指着 §二 该档锚点描述里被指认的特征，并附原文片段）：

| 取值 | 含义（可机械核对） |
|---|---|
| `低` | 该维只能给出负面判定（证据形态是「缺什么」），或写不出任何原文片段；对 `D4` 而言，指**文本自身**未给署名、未给出处、无可溯源线索——**不得**因 `L1` 降级或「没联网」判 `低`（见 §一 注） |
| `中` | 能写出 **1 条**正向原文片段，但只有一处、不强 |
| `高` | 能写出 **≥2 条**正向原文片段，且彼此不冲突 |

**第 2 步：按四维取值计数直接映射档位**（记 `n_low` = 取 `低` 的维度数，`n_high` = 取 `高` 的维度数）：

| 档位（灯） | 机械条件 | 对应的 §二 锚点 |
|---|---|---|
| `A`（🟢） | `n_low = 0` ∧ `n_high = 4` | 「四维证据充分且彼此不冲突」 |
| `B`（🟢） | `n_low = 0` ∧ `n_high ∈ {2, 3}` | 「四维都能写出正向证据，且至少两维不止一条」 |
| `C`（🟡） | **其余全部组合（兜底档）** | 「至少一处有用信息、至少一处可指认依据」——即未达 `B` 的覆盖面 |
| `D`（🔴） | **不由本映射产生**：按第 0 步由红灯 `V1`–`V8` 命中定档 | 见 `rubric/vetoes.md` |
| `无法判定`（🔵） | 任一维因上游 `无法判定` 而**无取值**（四维凑不齐 → 映射不可执行）＝本层不产出档位；或判定者知识不足 / 标准模糊 | 必须写清「缺什么才能判」 |

- 红灯为空时，映射**全覆盖且互斥**：任一取值组合恰好落 `A` / `B` / `C` 一档，不存在「有合法输入、无合法输出」的取值。
- 若某维无取值（`references/07-rating.md` 映射表写「不计分」）→ 本层**不产出档位**，L6 取 `无法判定`（该文件 R2）；**不得**用默认档（如 `C`）补齐。
- **非补偿**：红灯命中即定 `D`，四维得分**不得**把它拉回 `A` / `B` / `C`；反之，四维计数也不得把命中的红灯降级。
- 判定顺序：**先红灯**（触发条件见 `rubric/vetoes.md`）、**后分级**，两次独立提问（`references/07-rating.md` R4）。
- **刻度未校准**：三值取值的边界仍靠 §二 的文字锚点，本映射只保证「档位级可比」（`DECISIONS.md` #37、#56）；v1 **不产出任何数值**（#40），样本自然积累到足以校准时再由用户裁定是否恢复数值刻度（#55 已取消原校准程序）。
〔出处：`docs/DECISIONS.md` #56（v1 分级定义，唯一真源）、#55（范式转向）、#40（v1 不报数值）、#37（可比性只到档位级）；`docs/research/rating-design.md` §5.1（轴 2 与合成规则）、§4（等权理由）；**四维三值 + 计数映射表本身为【本报告工程约定】**〕

## 四、每一维必须落到原文证据（硬性）

- 每维判定必须附 **≥15 字原文片段** + `locator`；没有片段支撑的加减分视为无效，该维作废后单独重跑。
- 四个维度**分 4 次独立提问**，不是一次要 4 个分。
〔出处：`docs/research/rating-design.md` §5.1（防膨胀表「强制证据引用」「逐维独立提问」）；`references/07-rating.md` R5〕

## 五、防膨胀与防漂移机制（计分卡的配套约束）

| 机制 | 做法 | 出处 |
|---|---|---|
| 顶档稀缺约束 | `A` 档只由 §三 第 2 步的硬条件（`n_low = 0 ∧ n_high = 4`）触发，不靠判定者印象；同批次 `A` 档 >30% → 强制人工复核（`S` 档已随 `DECISIONS.md` #56 ① 删除，原「顶档」约束落在 `A` 档上）。实证：顶端档位一旦可达即膨胀（A 档 43%） | rating-design §5.1（防膨胀表「顶档稀缺约束」行）；`DECISIONS.md` #56 ① |
| 多次采样取中位 | 同一样本 3 次独立判定：**档位不一致 → `stability=不稳定`**（阻断级：该篇档位不得采信，进 `unknowns[]`、`confidence` 不得为 `高`）；**3 次档位一致 → `稳定`**；**只做 1 次判定 → `未执行`**（该篇 `confidence` 不得为 `高`，理由：单执行者无法满足「独立复跑」）。v1 只比档位、不比分数（`DECISIONS.md` #55/#56；执行规则见 `references/07-rating.md` R6） | rating-design §5.1（防膨胀表「多次采样取中位」行）；`DECISIONS.md` #55、#56 |
| 回测（无锚例集） | v1 **没有锚例集与阈值文件**（`DECISIONS.md` #55 已取消 30 篇锚例校准程序）；回测基准改为**用户日常阅读中自然积累的已判篇目**：同一篇重跑出现档位漂移时只报告、不改本次档位，并把漂移写进筛选卡「读它时要注意什么」节（执行规则见 `references/07-rating.md` R12） | `DECISIONS.md` #55；rating-design §5.1（防膨胀表「锚例回测」行，原设计） |
| 不报数值（v1） | v1 一律不报 0–120 数值：**v1 不设 `score` 字段**（`DECISIONS.md` #58），筛选卡只出档位与灯 | `references/07-rating.md` R7；`DECISIONS.md` #40、#55、#58 |
| 双序成对比较 | 边界样本与拟给 `A` 档的样本，与用户已判篇目做 A/B 与 B/A 两序比较取平均（位置偏差缓解）；无已判篇目时本条记「不适用」 | rating-design §5.1（防膨胀表「双序成对比较」行） |
| 独立于作者模型 | 判定者与被判文本的作者模型相同时，必须标记「自偏好风险」；承载位置＝筛选卡「交付与边界」节的「自偏好风险」说明（`templates/screening-card.md`），并在「读它时要注意什么」节复述 | rating-design §5.1（防膨胀表「独立于作者模型」行） |
| 置信度 | **高**＝3 次判定档位一致 ∧ 无 `degraded` ∧ `stability=稳定`；**中**＝档位一致，但 `stability ≠ 稳定` 或命中任一「降置信度＝是」的映射行；**低**＝档位不一致，或存在 `degraded=true`，或某维无取值。旧口径「三次分数是否落在档带切点 ±5 分内」随 `DECISIONS.md` #55 取消数值刻度一并作废（v1 无切点、无分数） | `references/07-rating.md` R8 / R6；`DECISIONS.md` #55、#56 |

## 七、已知局限

1. **四维等权隐含「各维可完全补偿」**（`rating-design.md` §4 等权行的已知缺点）；它只有在与红灯的非补偿性配合时才成立，缺了红灯就是纯补偿模型。
2. **`D1` 信息增量依赖对「读者原本知道什么」的假设**，无法外部验证；同一篇文章对不同读者的信息增量不同，本维度本质上是「对本项目用户的增量」，不是客观属性。
3. **`D4` 替换「表达」是工程偏离**：语言质量差但来源扎实的文章在本计分卡上会意外地不难看。判定者必须在筛选卡里显式声明「未评表达」，不得让读者误以为已评。
4. **档位锚点是文字描述，不是可测量边界**：没有锚例集，也没有可用的数值切点（`DECISIONS.md` #55 已取消 30 篇锚例校准程序、#40 明令 v1 不报数值），两个判定者对同一篇的判断可能相差一档；兜底只能靠 `references/07-rating.md` R6（3 次判定 + 档位一致性）与 R11（批内 `A` 档占比闸门），本文件无法消除该不确定性。
5. **锚点是按中文语料写的**（中文论证标记词与引用习惯），不得直接用于英文语料；中文语料本身没有论证质量标注数据，外部效标缺失（`methodology.md` §5.3④）。
6. **（本条作废，保留编号）** 原记录「『超额证据』四类（新事实 / 新框架 / 可复用方法论 / 罕见一手经验）来自 `rating-design.md` §5.1，其边界需要判断」——`S` 档与超额证据条款已随 `DECISIONS.md` #56 ① 删除，本条失去对象；`A` 档不含「无瑕疵」要求，其条件见 §二 与 §三。
7. **同质化风险**：`D1`（信息增量）与 `D4`（来源与可核查性）在「一手材料多的文章」上会同向变化，等权会重复计分；本文件不设权重调整（权重不可验证），但判定者仍可能被这种相关性误导。
8. **§三 映射表的输入仍是判断**：`低 / 中 / 高` 的边界靠 §二 的文字锚点，不是可测边界；两个判定者对同一篇的同一维可能给出不同取值，进而跨档。兜底靠 `references/07-rating.md` R6（3 次判定 + 档位一致性）与 R11（批内档位占比闸门），本文件无法消除该不确定性。
9. **v1 没有任何数值刻度**：0–120、任何分数切点与「距切点 ±5 分」类判据在当前协议内**不存在**（`DECISIONS.md` #40、#55），因此分数不能用作跨篇比较、漂移度量或置信度判据；一切比较只在档位级成立（#37）。下文凡出现「分数」「切点」均属对已停用旧制式的指称。
