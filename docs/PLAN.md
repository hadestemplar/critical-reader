## 一、项目目标

**一句话**：给 Agent 用的文章筛选协议包——收到一篇文章（公众号分享链接 / PDF / MD / TXT / 粘贴正文），产出一份带原文证据的判断报告，回答**「这篇文章值不值得花时间读」**（收益预估：要么有新的信息 / 知识 / 数据，要么有有价值或新颖的观点）；**质量分级（论证扎不扎实）降为第二问**，不产出任何数值刻度（`DECISIONS.md` #55、#56）。

**不做什么**（YAGNI，防止范围蔓延）：

| 不做 | 原因 |
|---|---|
| 图形界面 | 用户明确「不需要图形化交互界面」 |
| 内置 LLM 调用引擎 | 判断由使用者的 agent 用自己的模型执行 ⇒ 零 API key、零成本转嫁 |
| 批量扫目录模式 | v1 只做单篇（`DECISIONS.md` #20） |
| 公众号长链抓取 | 实测被风控拦截；只支持 `/s/<id>` 分享短链（#3） |
| 自动事实核查（联网检索并判真假） | 只**标注**需核查项与来源缺失，不自动判事实真假——成本高、误判率高（#13） |
| ACH / Bloom 层级 / 谬误计数扣分 / 全文论证图 | 已在调研中淘汰，各有实证理由（#15） |
| 多语言（英文文章判定） | v1 只针对中文文章 |

## 二、已对齐的决策

见 `docs/DECISIONS.md`（**条数以该文件为准**）。其中**不可变更的硬约束**：

1. 交付形态 = 技能目录，clone 即安装（#2）
2. **三轴并立、不合成任何总分**：`W`（站得住）/ `C`（信得过）/ `V`（值得读），每轴取 `A` / `B` / `C` / `D` 四档，并各带一个状态位（五值：`已评估` / `未评估` / `未核查` / `无法核` / `无法判定`）。**没有总分、没有总体等级、没有灯**；不变式：**档位写 `—` 当且仅当 状态位不是 `已评估`**。**v1 不产出数值刻度、无阈值**（`#76`/`#79`/`#84`；非补偿先例见 `#69`；原「否决项 + 档位五值闭集 / 灯 / `无法判定` 哨兵值」三条已于 2026-10-18 作废）
3. **目的路由 `P0`–`P3`**（`P0` 定位与筛选＝兜底 / `P1` 明辨真伪 / `P2` 获取信息 / `P3` 体验与欣赏——`P3` 不建判据族，只给提示）取代体裁路由。**否决项 `V1`–`V8` 废止，代之以四条红灯 `W-1` / `W-2` / `C-1` / `V-1`；一条红灯只判它自己那一轴，不跨轴一票否决**（`#83`；原 `#8`/`#9` 的三轨处置与 `C 轨`第二套判据一并作废）
4. **判定顺序不可跳步、不可回填**：切主张 → 目的路由 → 逐轴判 → 红灯 → 聚合。顺序的正文与九条硬规则在 `references/00-protocol.md` §2.3，**任何文件不得另立一套**（`#83`；原「六层全跑」的层名体系已作废）
5. 每条判定必须附原文引用 span，无引用不得成条（#11）
6. 代码 MIT + 文档 CC BY 4.0；不得引入 CASP / AAC&U / JBI / Wikipedia 的表述（#23）
7. **四要素表由证据卷宗承载**（`references/10-dossier.md` §8；**筛选卡不承载四要素表**）：论题 / 结论 / 论据 / 前提假设与隐含假设——均为必填输出字段、**不得留空**；论题 / 结论 / 前提假设须附原文引用（无则写「文中未显式给出」+ 最接近片段），论据须附 `[locator] 「原文逐字引用」`，**隐含假设豁免原文引用**，改为强制给出补全句 `P + 假定 ⇒ C` + 最接近的触发片段（无则写 `无`），位置字段取 `文中未给出（隐含）`（#25、#26；承载者由「报告」改为卷宗见 `#76`）

## 四、交付物与验收标准

> **通用条款**：每条验收标准必须给出**可复核证据**（文件 + 行号、或命令 + 输出）。验收以产物本身为准，不以「已完成」的口头声明为准。

### 五.1 样本集：校准覆盖清单（**已由 #55 降级**：样本改为用户真实投喂、校准改为逐篇积累；本节保留为历史设计记录）
