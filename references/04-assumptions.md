# 04 · L3 假定与预设

## 本层回答的唯一问题

它默认了什么没说的前提？

> 该字符串由 `references/00-protocol.md` §3「各层 question 固定表」的 `L3` 行**逐字规定**（唯一真源，见 `DECISIONS.md` #26①）；本文件「本层回答的唯一问题」节与其逐字一致，该缺口已关闭。

## 输入

| 输入项 | 必需 | 说明 |
|---|---|---|
| L2 输出 | 是 | 四要素表：论题 / 结论 / 论据（已过删除测试的核心链）/ 显式前提；**本层的主要输入是 `grounds → claim` 这一对** |
| 论题类型标注 | 是 | L2-R9 产出的 `事实判断型` / `价值主张型`，用于 L3-R3 的分流加权 |
| 正文全文 | 是 | 用于取原文位置与逐字引用（复用 L2 的 locator 闭集） |
| L1 输出 | 否 | 仅在 L3-R6 使用：`L1-B1` 为 Admiralty 信源可靠性 `D`–`F` 档时给事实型假定标「来源未核实」；L1 降级时本层照常执行，只跳过 L3-R6 |
| 本层不判缺陷 | —— | 越界判缺陷是 L4 的事（`00-protocol.md` §7 边界行：`04-assumptions.md`「不判缺陷（交 L4）」） |

## 输出字段

沿用 `00-protocol.md` §3 的统一输出块，并必须满足 §4 第 7 章的要求：隐藏假定**每条**给出四个字段 —— `假定内容` + `类型（事实型 / 价值型）` + `是否可核实` + `原文位置`（`00-protocol.md` §4 第 7 章）。

`items[]` 固定条目：

| id | 承载内容 | 必填 |
|---|---|---|
| `L3-A*` | 假定条目，一条一项，四字段齐全（`假定内容` / `类型` / `是否可核实` / `原文位置`）；另加 `发现方法`（观点者/第三方）与 `承重性`（承重/非承重） | 是，0–7 条 |
| `L3-B1` | 预设触发词扫描：命中词 + 次数 + 命中句原文位置 | 是（可为 0） |
| `L3-C1` | 分流表：事实型假定条数 / 价值型假定条数 / 复合条数 | 是 |
| `L3-D1` | 承重性结论：全部承重假定列表 + 「若全部不成立，结论是否仍成立」的三分结论 | 是 |
| `L3-E*` | 越界拦截记录（未在 L3 判定的项，如假定真假、作者动机）→ 进 `unknowns[]` | 是（可空数组） |

`verdict`（枚举，必取其一）：

| 取值 | 判定条件 |
|---|---|
| `假定已显式化` | 找到 ≥1 条假定，且每条都写明类型与是否可核实（即四字段齐全） |
| `存在可疑假定` | 找到 ≥1 条假定，且至少 1 条满足下列任一（取值必须照抄 L3-R5 的三值，**不得自造「可驳」**）：① 按 L3-R5 质证为 `不成立`（承重假定：若它不成立则结论不成立）；② 按 L3-R5 为 `部分成立`（适用范围受限）；③ 该假定与个人经验或知识背景冲突（须在 `L3-A*` 附冲突所依据的知识条目） |
| `未发现隐含假定` | 仅当 L3-R9 的三个条件全部满足时可取，否则不得取此值 |
| `假定不可判定` | 无显式论证可分析（L2 `verdict` = `无显式论证`）、文本截断、或补全句无法闭合且无触发词命中；原因写进 `unknowns[]` |

## 判定规则

- **L3-R1（可机械执行：无缝衔接补全检验，二元）** 对每一对 `grounds → claim` 填入同一句式：「我心底持有什么样的观念，才能把已知的前提和结论从逻辑上完成无缝衔接？」把候选观念写成补全句 `P + 候选假定 ⇒ C`。二元判定：补全句使链条闭合 → 记为该对论证的隐含假定并取原文位置（若文中无对应句，`原文位置` 写 `文中未给出（隐含）`）；补全句不闭合 → 弃用该候选。**弃用记录必须保留**（防止把任意观念塞成假定）。【出处：参考指南 L172–L174（「隐藏假定通常存在于论证前提里，它本质上就是没有说出来的前提」）；`docs/research/methodology.md` §7.1 第 4 条表行（「无缝衔接」是可操作的搜索目标）】
- **L3-R2（可机械执行：两种找法各执行一次，计数）** ① 反对者视角：假设自己是该结论的反对者，写出反驳路径；② 无关第三方视角：假设自己是无关第三方，找出**也能推导出同一结论**的其它可能路径。每个候选假定必须标注由哪种方法找到；两种方法都命中同一条 → 记 `发现方法: 两者`。两条找法都未执行时，本层不得出 `未发现隐含假定`。【出处：参考指南 L175–L176；`docs/research/methodology.md` §7.1 第 4 条表行】
- **L3-R3（可机械执行：事实型 / 价值型分流判据；`docs/PLAN.md` §四验收标准表 D1 第 ④ 项**后半**硬要求）** 按下列**有序步骤**判定，每步二元：
  1. **谓词扫描**：假定句含规范性谓词（`应该｜应当｜必须｜值得｜有权｜理当｜更重要｜更好｜不道德｜正当｜可取`）→ 价值型；只含描述性谓词（`是｜有｜会｜能｜导致｜意味着`）→ 事实型；两类谓词同句 → 标 `复合`，**在 `evidence` 里分别写出两类谓词的原文片段**（**不得**静默只归一类）。
  2. **事实型追加三问**（三问各答 是/否，全答「否」→ 标 `是否可核实: 可核实`，任一答「是」→ 标 `是否可核实: 存疑`）：该假定跟个人经验冲突吗？跟知识背景冲突吗？它来自哪里、来源原本可靠吗？
  3. **价值型不加上述三问**，改问「我认同这个假定吗？」——该问**只记录答案，不参与任何评分**，因为价值判断只能显式化后交读者裁决；`是否可核实` 固定写 `不可核实（价值型）`。
  4. `类型` 字段只有三个合法值：`事实型` / `价值型` / `复合`；写出其它值即判格式错误。【出处：参考指南 L161–L168（事实判断型 / 价值判断型两类隐含假定，含「每天吃一个鸡蛋…隐含假定是鸡蛋富含蛋白质」的例子）、L179–L181（事实型三问）、L184（价值型加问「我认同这个假定吗？」）；`docs/research/methodology.md` §7.1 第 5 条表行（把两类拆开是正确设计，CASP/GRADE/证据金字塔不含价值判断通道）、§7 表格「隐含假定」行（用指南版本 + Heuer 流程）】
- **L3-R4（可机械执行：预设触发词字符串扫描，可数）** 对全文逐个计数：核心词表（出处见右）＝`显然｜众所周知｜毫无疑问`；扩展词表＝`不言自明｜不言而喻｜毋庸置疑｜谁都知道｜大家都知道｜公认｜理所当然｜不用多说`（**本表是预设触发词的唯一真源**，其他层只引用、不得另行增删；`不用多说` 由 `05-defects.md` 归并至此；扩展项＝【本报告工程约定】）。规则：每命中一次记 1；命中句若承载对结论的支撑，必须生成一条候选假定并送交 L3-R1 补全检验（未通过则丢弃，不计入 `L3-A*`）。其解释基础是：这些词把本应举证的内容塞进了预设。【出处：`docs/research/methodology.md` §6.1（「『显然』『众所周知』『毫无疑问』是预设触发语」、结论「这类词应作为扫描字符串处理，而不是靠模型『理解』」）、§3.4（Grice 无阈值，其工程代用品为预设触发词清单）】 **跨层互引（只登记存在性，失效机制归 L4）**：本条只登记该处命中的**存在性**与位置；该处命中的**失效机制**由 L4 登记（`references/05-defects.md` R1），本层不重复判定；两条登记必须互相引用（本层条目写该命中的 L4 编号，L4 条目写 `参见 L3-R4 命中 #k`）；报告第 7 章（隐藏假定）与第 8 章（缺陷清单）**不得把同一处命中叙述成两条独立缺陷**。〔出处：`references/05-defects.md` R1 跨层去重（`:42`）；`docs/DECISIONS.md` #42；跨层去重规则本身为【本报告工程约定】〕
- **L3-R5（逐条质证：Heuer 关键假定检查 + 强规则重写）** 每条假定回答「若该假定不成立，结论是否仍成立？」，三选一：`仍成立`（非承重）/ `不成立`（承重）/ `部分成立`（记录适用范围）。**禁止照搬参考指南 L182 的强规则**（「只要有一个假定被判断成可驳或不成立的，那么就可以判断它支撑的结论也是可驳或不成立的」）——该规则在多前提论证中会系统性过度否决，按「结论的可信度是各前提的合取」重写为：**只有全部承重假定都被判为「不成立」时，才判结论不可信；单个承重假定取「不成立」只削弱结论**（「不成立」= L3-R5 的承重档取值，不是「假定本身被驳倒」）。【出处：参考指南 L182–L183（含其自相不对称处）；`docs/research/methodology.md` §7 逐行批判第 4 条、§3.x Heuer 关键假定检查（「列出全部未言明假定 + 逐条质证」）】
- **L3-R6（可选分支：沿用 L1 的来源判定）** 事实型假定若其来源在 L1 中被评 `L1-B1` Admiralty 信源可靠性 `D`–`F` 档 → 该条 `是否可核实` 标 `来源未核实`，并在 `unknowns[]` 记一条待人工核查。L1 降级（`无法判定`）时跳过本规则，并在条目里写明 `未做来源核查（L1 降级）`。【出处：参考指南 L181；`docs/research/methodology.md` §5.1 L1 行；`references/00-protocol.md` §5 降级表】
- **L3-R7（边界）** 本层只输出假定的**内容、类型、可核实性与位置**：不判缺陷与谬误（交 L4）、不判假定本身真假、不评作者信念、动机与情绪，相关观察只作可选提示、不计分；本层也不下档位/灯、不判 `V7`/`V8`（交 L6，`DECISIONS.md` #56①②）。【出处：`references/00-protocol.md` §7 边界行（`04-assumptions.md`：不判缺陷（交 L4））、§1「不回答」表；`DECISIONS.md` #17】
- **L3-R8（可机械执行：条数上限与排序）** 假定条目上限 `N = 7`；按 `承重性` 降序排列（承重优先）；超出上限的条目移入 `unknowns[]` 并注明「超上限未展开」。【出处：【本报告工程约定】】
- **L3-R9（可机械执行：`未发现隐含假定` 的三条件合取）** 只有同时满足下列三项才可输出该 `verdict`：① L3-R1 已对 L2 的每一对 `grounds → claim` 执行且全部补全句为空；② L3-R4 命中数为 0；③ L3-R2 两条找法均已执行。任一不满足 → 必须落 `假定不可判定` 并写明未完成的那一项。【出处：`docs/research/methodology.md`（可靠性纪律：判定规则必须可被两个独立执行者复算出同一结果）；三条件合取＝【本报告工程约定】】

## 已知局限

1. **指南 L182 的强规则已被判为过强并重写**（`docs/research/methodology.md` §7 逐行批判第 4 条）：照搬会系统性过度否决；本层按「结论可信度 = 各承重假定的合取」执行。这是对参考指南的**有意偏离**，不是遗漏。
2. **「我认同这个假定吗」本质不可机械执行**（价值判断无客观判定器）：本层只把它显式化并交读者，不产出分数，因此报告会系统性地出现「不可核实（价值型）」条目——这是设计的必然结果，不是缺陷，报告须显式说明。
3. **预设触发词表缺中文实证**：`docs/research/methodology.md` §6.1 只给出三个词与一条低权威线索（百度百科「预设触发语」，仅作词表线索），扩展词表是本报告的工程外推；中文论证标记词的误导率/滥用频率实证**未找到**（同文件风险表第 2 条）。误报需回读原文确认。
4. **假定条目无天然上限**，理论上可无限展开；`N = 7` 是工程折衷，非实证最优。
5. **Paul–Elder 只取「假定」与「视角」两要素当词汇表**；其 9 条智识标准作为评分表已淘汰（无阈值、无边界例、未找到效度研究），本层不得回退到该评分表。【出处：`docs/research/methodology.md` §5.2 淘汰清单、§3.x 适配结论】
6. **ACH（竞争性假设分析）禁用**：有随机对照实验未见准确率优势、RAND 未证实 SATs 整体价值，且矩阵逐格判定成本高；本层用 Heuer **关键假定检查**而非 ACH。【出处：`docs/research/methodology.md` §0③、§5.2 淘汰清单、§3.x】
7. **假定与「显式前提」的边界在中文里不总是清晰**（作者半写半不写）：判定简化为「该句是否在原文中以完整命题形式写出」——写出即归 L2 的前提假设，未写出即归本层的隐含假定。
8. **L3 无可用的中文标注语料做校准**，与 L2 同源风险（`docs/research/methodology.md` §5.3④；`docs/PLAN.md` 第六节风险表）；缓解只能靠锚例集与双执行者复算。
9. **`question` 字符串已由契约固定（缺口已关闭）**：`00-protocol.md` §3 新增「各层 question 固定表」，`L3` 行逐字给出本层取值，本文件「本层回答的唯一问题」节与其逐字一致（`DECISIONS.md` #26①）。本层不再自定该字符串。
10. **隐含假设的引用例外已由契约确认**：`DECISIONS.md` #26④ 明确隐含假设豁免「必须附原文引用」，改为强制给出补全句 `P + 假定 ⇒ C` + 最接近的触发片段（确无则写 `无`）+ 位置字段取 `文中未给出（隐含）`；本文件 L3-R1 已按此执行（`原文位置` 写 `文中未给出（隐含）`）。
