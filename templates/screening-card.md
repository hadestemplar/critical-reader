# 筛选卡 · 输出物模板

> 本文件定义**筛选卡**这一交付物的形态。
>
> **交付对象**：一个不懂本协议、不懂统计、也没读过这篇文章的人。
> **验收判据**：他只看这一页，能不能决定读不读、以及读的时候该防着什么。
>
> **三条禁止**：禁止出现协议内部标识（层号、规则号、条目 id、行号、形态代号）；禁止用代码块包裹正文；禁止写「不适用」却不说明它不适用在哪。

---

## 0 两种形态：小卡与大卡

**判据：只看「值得读吗」这一栏。**

| 情况 | 出哪种 | 理由 |
|---|---|---|
| **值得读吗 ＝ D**（没有信息增量） | **小卡** | 没有新东西可拿，不值得为它做完整分析。只给：三个档 + 一句话 + 核心观点 + 为什么是这个档 + 风险命中项。半页以内 |
| **值得读吗 ＝ A / B / C** | **大卡** | 有东西可拿，才值得逐条过四问、逐条核验 |

**「一句话」是两种卡都必须有的要素。** 它不是背景介绍——要答「作者到底想让你相信什么」：写「本文讨论了营销变难的原因」不合格，写「你以为营销变难是因为流量变贵了，但作者认为是因为价值攫取的机会消失了」合格。**至少 10 个非空白字符，不得超过两句。**

> 13 章完整报告**已废除**。本项目的交付物只有两件：**筛选卡**（本文件）与**证据卷宗**（被要求时另出）。

小卡不写：结构拆解表、逐条论题四问、逐条核验清单、读它时要注意什么。

**证据卷宗**：**默认不出**。它是卡的附件，只在被要求时另出——按卡上栏目顺序组织，只放证据（每条判定的原文片段与位置、本次检索了什么、未核项），不另起目录。规范见 `references/10-dossier.md`。

## 1 三栏的四档

**三栏各自独立、互不代偿。任何一栏不合格，不代表另外两栏也差。不出总分、不出总体等级。**

### 「说得有道理吗」

| 档 | 含义 |
|---|---|
| **A** | 每条论题的四个方向（前提、适用范围、边界、反例）都跑通，找不到断点 |
| **B** | 主干全通，断点只在**非承重位置**（引子、举例、顺带推广），不影响结论 |
| **C** | 有一处**承重环节**没接上——换了论题、缺了必要前提、或全称句找不到反例 |
| **D** | 承重主体断裂，或主论题本身没有支撑 |

### 「说的是真的吗」

| 档 | 含义 |
|---|---|
| **A** | 关键说法都查到源头，且与源头一致 |
| **B** | 关键说法都查到源头，只有次要说法没核到 |
| **C** | 有**承重**论据查不到源头 |
| **D** | 核到与源头冲突的说法 |

### 「值得读吗」

问的是**这篇文章有没有新的观点、新的思考、新的信息量**；不问你读了有没有用。

| 档 | 含义 |
|---|---|
| **A** | 有新观点或新信息，且不是已有概念的搬运 |
| **B** | 有少量新东西（一两条），其余是复述 |
| **C** | 基本是已有概念的复述或常识整理 |
| **D** | 没有信息增量 |

### 承重与非承重

**判据：把这条论题（或这一环）抽掉之后，主论题还成不成立。**

- 抽掉就塌 ⇒ 承重。它出问题，整栏降档。
- 抽掉不影响 ⇒ 非承重（引子、举例、顺带推广、外挂）。它出问题，只降不塌，记 B。

**由判定者直接判，不设机械判据。** 判完后在卡上把「哪条是承重、抽掉会怎样」写出来，让读卡的人能复核这个判断。

### 状态位

跟在档位后的一串固定说明，表明**这一栏到底跑没跑、跑到哪一步**。「没去核」与「去了核不了」是两件事，各有各的值，不得互相顶替。

| 状态位 | 何时取 | 必须附写 |
|---|---|---|
| `已评估` | 按规则跑了并出了档。**「没有可核项」也取此值**——没东西要核不等于没去核 | 本次核了什么、核了几条（可以是 0 条，写明「无可核项」） |
| `未评估` | 按规则**不该跑**（命中 `P3`，三栏全不出，只给体裁提示） | 原因 |
| `未核查` | **仅第二栏「说的是真的吗」**：该核，但**本次没去核**（未执行外部检索） | 为什么没去核 |
| `无法核` | **仅第二栏「说的是真的吗」**：**去核了，但核不了**（检索通道不可用 / 无权威源 / 无作者身份标识） | 缺什么才能核 |
| `无法判定` | 跑了但判不了（输入残缺、判据不可执行、四维凑不齐） | 缺什么才能判 |

**三栏都带状态位**：大卡写在栏目标题后（`## 说得有道理吗：<A/B/C/D> 　\<状态位\>`），小卡写在「为什么是这个档」的 bullet 后（`- **说得有道理吗 <档>** 　\<状态位\>`）。`未核查` 与 `无法核` 仍**只用于第二栏**（它们的「何时取」已限定），但 `已评估` / `未评估` / `无法判定` 三值对任何一栏都成立。

**卡面只写 `A` / `B` / `C` / `D` / `—`，不写灯（🟢🟡🔴🔵）。** `无法判定` 在卡面一律渲染为 `—`——它是哨兵值，表示「没有档位」，不参与排序与比较（`references/07-rating.md` R18）。本文件「风险识别」栏的 🔴🟡🔵 是**另一个轴**（风险强度），与此处无关。

**档位与状态位必须互相对得上**：档位写 `—` **当且仅当** 状态位不是 `已评估`。出了档就写 `已评估`，没出档就不许留 `A`–`D`。

## 3 风险识别清单（13 项）

风险栏用 **🔴 🟡 🔵**（不用 A–D，避免与三栏的档位混淆）：

| 灯 | 含义 |
|---|---|
| 🔴 | 命中，**且它承载结论**——该结论不可采信 |
| 🟡 | 命中，但只影响局部——结论仍可读 |
| 🔵 | 疑似，本次无法判定（信息不足或需外部核查） |

> A 组（结构对齐）和 B 组（论证）**不在这里**——它们已被第一栏「说得有道理吗」逐条检验过。
> F 组只有 F5 独立：F1、F2 归第一栏，F3、F4 归第二栏。

### C · 概念

| # | 项 | 判据 → 怎么识别 |
|---|---|---|
| C1 | **偷换概念** | 同一概念前后定义不一致 → 把承重概念每次出现时的实际所指列出来比对 |
| C2 | **关键概念未定义** | 承重概念只用了词、没给定义 → 试着给它下定义，下不出来就是没定义 |
| C3 | **一词多指** | 同一词在不同段落实际指不同对象 → 逐处标注实际所指 |
| C4 | **定义精度不足** | 定义模糊到无法支撑结论 → 问「这个定义能不能排除它需要排除的情况」 |

### D · 隐含假定

| # | 项 | 判据 → 怎么识别 |
|---|---|---|
| D1 | **事实型假定** | 想当然认定「世界是这样的」→ 问「要什么观念，才能把前提和结论无缝接上？」 |
| D2 | **价值型假定** | 想当然认定「世界应该这样」→ 同上，并追问「我认同这个假定吗？」 |
| D3 | **承载性假定未辩护** | 抽掉它结论就塌，而文章从未论证它 → 做删除测试 |
| D4 | **诉诸常识 / 多数 / 传统 / 权威** | 用「大家都这么做」「老祖宗的智慧」当论据 → 看这个论据本身是不是一个未经证明的信念 |

### E · 立场与动机

| # | 项 | 判据 → 怎么识别 |
|---|---|---|
| E1 | **明显的利益相关** | 文章是广告，或指向作者自有商品 / 服务 / 课程的导流 → 只判**浅显可见**的，不做动机推断 |
| E2 | **双重标准** | 对不同对象用不同的举证要求 → 把双方各自被要求的证据量列出来对比 |
| E3 | **情绪驱动价值判断** | 价值结论由情绪 / 欲望推动 → 问「换个相反情绪的人来看，会不会得出别的结论」 |
| E4 | **信念不可检验** | 断言上升到不可证伪的层面（宿命论、怪力乱神、无任何论据的信念）→ 问「什么证据能推翻它」，答不出即命中 |

**E3 / E4 不做硬性拦截**：识别到才预警，没识别到就默认文章里不存在。理由——这两项要求判定者读出作者的内心，误伤面大于收益。
**E1 不做机械判据**：不设「导流词 ≥N 次」这类阈值。

### F · 数字暗示

| # | 项 | 判据 → 怎么识别 |
|---|---|---|
| F5 | **数字暗示** | 用精确数字制造可信感，但数字无出处或口径被换 → 回原口径逐条核对 |

**13 项全跑**：每一篇都逐项过。理由——只有全跑，「查过、没有」和「没查」才区分得开。
结尾必须写「已逐项核查 13 项，未命中 N 项」；**不列未命中项的证据**。

## 4 写作纪律

1. **「一句话」必须给答案**，不给背景。读者看标题就想知道答案是什么。
2. **难懂且承重的概念，先解释再判**。不解释，读者就得回原文，卡片白写。
3. **表格优先**：能给表的先给表，解释放表后。
4. **每段用一句加粗的结论句打头**。
5. **明确分层**：用编号，让读者知道自己在第几层。
6. **主动列反证**：文章自己提过、却没用来自检的材料，必须单独列出。
7. **承重判断要写在卡上**：哪条论题抽掉会塌、哪条抽掉不影响，读者要能复核。
8. **结尾给边界声明**：未核项逐条列出，不合并、不含糊。
9. **写明保质期**：什么条件变了就该回来重判。
10. **定位用文章自己的章节名**（「第三节」「引言末段」）；引用直接抄原句，不转述。
11. **档位释义行末逐字追加结论标记串**：串文与出现规则见 `references/10-dossier.md` §10（本模板不复述串文）。

## 5 不合格长什么样（反例清单）

1. 把「这篇文章在说什么」或「核心观点清单」当可选项省略——两者是**必需内容**。
2. 三栏都给了档位，却不说这篇到底讲了什么事（「这篇文章在说什么」空着，或只写背景不给答案）。
3. 三栏只写两栏，或把两栏合并成一栏——三栏必填、各自独立、互不代偿。
4. `无法判定` 与某一档合并——它是独立取值，不得并进 `A` / `B` / `C` / `D`。
5. 核心观点清单为凑满 7 条而注水或重复。
6. 卡里出现需要填 0–120 数值的位置。
7. `判定者模型标识` 写成 `AI`；或写 `未提供` 却让 `自偏好风险` 记 `是`；或两项缺失（「交付与边界」节必填）。
8. 档位释义行漏掉结论标记串（串文唯一真源见 `references/10-dossier.md` §10）。
9. 大卡写成小卡的形式、或小卡写成大卡的形式（判据见 §0：小卡 ⟺ 「值得读吗」＝ `D`）。
