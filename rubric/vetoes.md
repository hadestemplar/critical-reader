# 门禁否决项清单（rubric/vetoes.md）

## 一、定位与用法

- 否决项是**非补偿轴**：命中 **`V1`–`V8` 任一** → **直接定档 `D`（🔴 不合格·不用花时间）**，**与质量分级无关**；`D` 档不由维度合成产生、也不参与 A/B/C 的分级（`DECISIONS.md` #56（v1 分级定义）之 ③ 档位判据；硬规则 7「门禁先于总分」的实质保留为「**红灯先于分级**」）。
- 判定顺序：**先判红灯（`V1`–`V8`）命中与否、后判 A/B/C 分级**，两次独立提问（`references/07-rating.md` R4）。
- 每条 veto 的命中必须附**原文证据 + `locator`**，并登记进 L6 的 `gateHits[]`（该字段在本制式下的含义＝**红灯命中登记**；`items[].id` 形如 `L6-G1`，见 `07-rating.md` 输出字段表）；写不出原文证据的命中**不得成立**。
- **条数：8 条。** 前 5 条直接取自 `docs/research/rating-design.md` §5.1（调研已给出的建议清单，不得擅自删减）；`V6` 是 L4 `items[].impact=致命` 在 L6 的唯一出口——若没有 V6，核心链断裂这类致命缺陷会静默流失；`V7`（无收获）与 `V8`（主张无据）来自 `DECISIONS.md` #56 ③ 的两条红灯判据，**并入本文件而不另立一处**，理由是红灯必须只有**一个**真源、一张表（若无此合并，红灯会变成跨两个文件的第二根轴）。除此之外**不设第 9 条**：否决项必须致命，「这篇写得一般 / 不够深入 / 观点浅」不是否决项（`DECISIONS.md` #15；`references/05-defects.md` R10）。
- **本文件是红灯（否决项）触发条件的唯一真源**（`references/00-protocol.md` 硬规则 8「门禁唯一真源」）：`V1`–`V8` 的触发条件、形态与适用轨**只在本文件定义并写全**；其余文件（含 `references/07-rating.md`）只许**引用编号**，不得复述、不得另立条件——两处不一致时一律以本文件为准。本轮三份端到端首跑实测该链曾在三个文件里互相矛盾，导致最高阶结论只能靠执行者临场裁定。

> 下列触发形态中的计数与比值（`M/N < 1/2`、≥3 处、>50%、<300 字、抽查 3 个单元）是**为了让否决项可机械执行的描述性量级**，标【本报告工程约定】。它们**不是**档位切点——v1 的 `A`/`B`/`C`/`D` 由红灯判据（`V1`–`V8`）+ 四维计数映射产生（`rubric/quality-dims.md` §三），不靠数值切点；若发现误杀/漏杀，只调这些量级，不动档位判据。

## 二、八条否决项（命中任一 → 定档 `D` ／ 🔴）

### `V1` 核心主张的支撑在原文 / 所引来源中查无此物

**触发它的原文证据长什么样**（三种形态，命中任一即命中）：
1. 承担全文结论的事实主张所引的材料（论文名 / 机构 / 数据 / 新闻事件），按图索骥后在原文与该材料的可打开来源中**都找不到**；
2. 同一份材料在文中出现两处且数字或说法**互相矛盾**（例：正文写 37%，文末数据区写 51%）——**内部矛盾可机械核对**；
3. 被引来源的强度被**明显加码**（原始表述是「可能 / 相关」，文中写成「证明 / 导致 / 必然」）。
> 形态示例（**非真实引文**，只示范证据长相）：「据 XX 大学 2019 年研究，A 导致 B 提升 37%」——按题名检索不到该研究，或原文写的是「与 B 提升相关」。

- **不越界**：判定者**不判真假**（`DECISIONS.md` #13）——只做「回文检索 + 内部一致性核对」，即**出处可追溯性**，不是真伪判断。任何「这篇文章说错了」式的结论都不得在 V1 下写出。
- **机械内核**：三形态逐条二元（找得到 / 找不到；一致 / 矛盾；加码 / 未加码）→ 任一二元命中即命中。
- **「无出处」与「不可核」都不构成 `V1`**（本轮裁定的分界；`references/07-rating.md` 早期「承重主张无出处 → `V1`」的写法**作废**）。三条理由：① `V1` 三形态**都以「文中存在一份被引用或被指称的材料」为前提**，判定动作是回文检索与内部一致性核对；`无出处` 条目**没有被引对象**，该动作是空操作，`不可核` 则是核查**无法执行**——两者都给不出 `V1` 要求的**正向发现**（检索后确认找不到 / 内部矛盾 / 被加码）。② 把「未给出来源」升格为否决，等于把质量属性判成致命错误，与 #13「只标注需核查项、不判真假」的分工冲突。③ 中文长尾语料里承重主张不附出处是常态，设为否决会系统性误杀（本轮实测文章有 7 处无主语来源指称）。
  处置：`sourceType ∈ {无出处, 不可核}` 的承重主张 → `needManualCheck=是` → 进筛选卡「交付与边界」的「未核项」，**不进门禁**（`references/06-evidence.md` R5）；`D4` 的取值一律按 `rubric/quality-dims.md` §三 第 1 步（见 `docs/DECISIONS.md` #61 裁定 3）——**承重主张无出处不等于该维必然低**（文本自身可能给了署名与可定位线索）。
- 触发层：`L2`（定位承重主张）+ `L5`（出处属性）；适用轨：A / B（**C 轨不适用**，C 轨不做论证要素判定）。
〔出处：`docs/research/rating-design.md` §5.1（`V1` 行）；`DECISIONS.md` #13；`references/00-protocol.md` 硬规则 3「L1 不得省略」〕

### `V2` 与标题 / 声称主题不符（挂羊头卖狗肉）

**触发它的原文证据长什么样**：
1. 标题承诺 N 个要点或一份「完整指南 / 全解析」，正文实际覆盖 `M` 个 → **`M/N < 1/2`**（可数）；
2. 标题问 A，正文主体段落主要在讲 B（主体段落按段落主题统计，`B` 类段落占多数）；
3. 结论不是对标题所设论题的回答——「结论加个问号等于论题吗？有没有正面回答问题？」答否，或结论只是**相关性很强的旁支**而不是对论题的正面回答。
> 形态示例（**非真实引文**）：标题《XX 完全指南：5 个必知要点》，正文只讲了 1 个要点，其余篇幅在讲作者的课程。

- **机械内核**：第 1 项是纯计数（`N`、`M` 都是清点结果）；第 2、3 项为二元判定。
- 触发层：`L0`（体裁与主题）+ `L2`（论题—结论对齐）；适用轨：A / B / C。
〔出处：`docs/research/rating-design.md` §5.1（`V2` 行）；`docs/research/methodology.md` §7.1（论题与结论对齐）；指南 `…\批判性思维-信息结构判断指南.md` L65「判断论题与结论是否对齐」、L70「结论加个问号等于论题吗？有没有正面回答问题？」、L83「用相关性很强的结论来掩盖掉正面回答问题的论题」；比值 1/2 为【本报告工程约定】〕

### `V3` 主体为广告 / 软文 / 导流，无独立信息

**触发它的原文证据长什么样**：
1. 导流动作出现 **≥3 处**（可扫关键词：加微信 / 扫码 / 关注公众号 / 私信 / 进群 / 领取资料 / 优惠码 / 购买链接 / 课程报名）；
2. 全文信息单元中**服务于同一商品、服务或课程**的占比 **> 50%**（可数，信息单元清点口径见 `references/08-track-c.md` C3 与 `06-evidence.md` 的事实主张清点）；
3. 通篇没有**任何可独立于该商品 / 服务使用的信息**（二元）。
> 形态示例（**非真实引文**）：正文 6 段中 4 段在介绍某课程的目录与讲师背景，且段末两处「扫码进群领取资料」。

- **机械内核**：第 1 项正则 / 关键词可扫、可计数；第 2 项依赖信息单元清点（计数）；第 3 项二元。
- 触发层：`L0` + `L1` + `L5`；适用轨：A / B / C。
〔出处：`docs/research/rating-design.md` §5.1（`V3` 行）；`docs/research/genre-taxonomy.md` §3.3（可自动判定信号：指示词密度、导购特征）；计数阈值 3 与 50% 为【本报告工程约定】〕

### `V4` 无信息增量（纯拼接已有内容，且不提供新组织方式或新证据）

**触发它的原文证据长什么样**：
1. 抽查 **3 个**信息单元，**全部**能在已有材料中找到同一内容（无新事实、无新数据、无新观察）——检索动作与结果都是二值；
2. 且全文**未提供**新的组织方式：没有新分类、新框架、新对比、新证据链（二元）。
> 形态示例（**非真实引文**）：三处「事实」分别是维基百科条目、两篇公众号文章的原文改写，全文结构照抄其中一篇，无任何新增分类或对比。

- **机械内核**：两项都必须为「是 / 否」；第 1 项为 3 次二值检索，第 2 项二元。**两项同时成立才命中**（只有第 1 项成立、但提供了新框架的，属于「编译类作品」，不否决）。
- 触发层：`L0` + `L2` + `L5`；适用轨：A / B / C。
〔出处：`docs/research/rating-design.md` §5.1（`V4` 行）；抽查 3 个单元为【本报告工程约定】〕

### `V5` 正文不可用（截断、乱码、仅目录页）

**触发它的原文证据长什么样**：
1. 提取到的可读中文正文 **< 300 字**；
2. 提取内容中导航 / 评论 / 推荐位 / 广告位占比 **> 50%**；
3. 正文明显截断：句子中途终止、只抓到目录页、登录墙 / 付费墙之后无内容；
4. 整篇乱码、编码错误，或非目标语言。
> 形态示例（**非真实引文**）：抓取结果只有「首页 > 专栏 > 正文」与 12 条推荐标题，正文被「登录后可见」替代。

- **机械内核**：四项均可计数或二元判定，命中任一即命中。
- 与 `degraded` 的分工：输入抓不全但**仍可判**时用 `degraded`；**抓不到可判的正文**时用 `V5` → 定档 `D`／🔴（此处的 `D` 是「不进流水线」，不是「文章差」）。该分工为【本报告工程约定】，需在筛选卡里写明。
- 触发层：`L0`（输入可用性）；适用轨：A / B / C。
〔出处：`docs/research/rating-design.md` §5.1（`V5` 行）；`references/00-protocol.md` §5（降级与失败表）；字数与占比为【本报告工程约定】〕

### `V6` 核心链断裂或核心假定未被辩护（L4 致命缺陷）

**触发它的原文证据长什么样**：
`L4` 输出中存在 **≥1 条** `items[].impact=致命`，且该条同时满足：
- `kind ∈ {结构缺口, 推理失效, 预设装载}`；
- `locator` 落在**承担全文核心主张**的段落上（核心主张由 `L2` 的结论 / 四要素定位）；
- 该条附有「最小修改」与原文片段（`05-defects.md` R3 的成条条件）。
> 形态示例（**非真实引文**）：全文结论是「X 应当被禁用」，而支撑它的唯一一段推理把「部分研究显示相关」直接当成「导致伤害」，且该断言位于结论段——L4 记 `kind=推理失效`、`impact=致命`。

- **单条即触发，不做条数累计**（`DECISIONS.md` #12：谬误与缺陷都不靠计数表严重度）。
- **不触发的情形**：`kind=疑似谬误`（#12 一律只作提示）；`impact=重要 / 提示`；单纯的修辞操纵命中（FLICC 五手法仅限健康 / 科学 / 医学题材，且只作提示——`05-defects.md` R9）；L4 `verdict=可败`。
- **机械内核**：只查 L4 的 `impact` ∈ {致命} ∧ `kind` ∈ {三类} ∧ `locator` 落点 → 三元组判定，**可脚本核对**。
- 触发层：`L2` + `L4`；适用轨：A / B（**C 轨不适用**，C 轨不做论证审查）。
〔出处：`references/00-protocol.md` §2 硬规则 7「门禁先于总分」与 §7；`docs/DECISIONS.md` #6、#12；`docs/research/rating-design.md` §4「最低项否决（veto / 连言规则）」与 §1.2 MQM 的 critical-error 先例〕

### `V7` 无收获（读完全文没有得到可用的信息、事实或方法）

**触发它的原文证据长什么样**：
1. 全文清点后**没有**任何可用的新信息 / 知识 / 数据 / 方法（判定者须写出「我找过哪三处、它们分别提供了什么」——找不出三处即不成立）；
2. 也**没有**提出有价值或新颖的观点（只有情绪、抒情、感悟、口号）。
> 形态示例（**非真实引文**）：全篇 1200 字只描述作者当天的心情，无任何事实、数据、方法或主张。

- **机械内核**：两项都是二元判定（有无可用信息 / 有无有价值的观点），**两项同时为「无」才命中**。
- **与 `D1`（信息增量）维度的边界**：`V7` 是**红灯级二元**（都是空的）；`D1` 度量**增量的多少**（程度）。命中 `V7` 即定 `D`，不再评 `D1`。
- 触发层：`L0`（体裁）+ `L2`（有没有主张）；适用轨：A / B / C。
〔出处：`docs/DECISIONS.md` #56 ③ 红灯判据「无收获」（lead 裁定并入否决项清单：红灯只留一个真源）；`docs/calibration-30.md` §2.2（用户判词中「读了没有收获」是最高频的红灯理由）〕

### `V8` 主张无据（承重主张完全没有支撑）

**触发它的原文证据长什么样**：
1. 文章提出了**实质主张**（故与 `V7` 互斥：`V7` 是无主张、`V8` 是有主张但悬空）；
2. 该主张的支撑**完全没有**，或**全部**是个人主观叙述 / 受访者口述 / 转述；
3. 全文**没有任何可核验材料**（数据 / 出处引用 / 可复现事实 / 可打开的外部来源）。
> 形态示例（**非真实引文**）：一整篇访谈稿，核心主张「这个行业三年内会消失」的全部依据是三位受访者的感受，无任何数据或报告。

- **机械内核**：三形态均为二元（有没有实质主张 / 支撑是否全为主观叙述 / 有没有任何可核验材料）→ **有主张 ∧ 零可核验材料**即命中。
- **与 `D2`（论证质量）维度的边界（必须一眼分清，否则重复计数）**：`V8` 只问「**承重主张有没有任何支撑**」——答「没有」即命中（二元、致命）；`D2` 问「**支撑有多好**」——多少条、是否处理反例、链条是否完整（程度）。**有支撑但很弱 → 不命中 `V8`**，只在 `D2` 上取低 / 中。
- **与 `V1` 的边界**：`V1` 针对「文中指称了一份材料、但按图索骥查无此物 / 内部矛盾 / 被加码」；`V8` 针对「**根本没有可核验材料**」。两者互斥，**不得对同一条主张同时命中**。
- **不构成 `V8` 的情形**：主张有作者自己给出的**推理链**支撑，或有**部分**可核验材料——那属于 `D2`（论证质量）的评分范围，不是红灯（这也与 `V1` 的裁定一致：承重主张「未给出处」本身不升格为否决）。
- 触发层：`L2`（承重主张定位）+ `L5`（出处属性；输入是 `references/06-evidence.md` 的 `sourceType`）：适用轨：A / B / C（**不因体裁豁免**——`DECISIONS.md` #56 ④ 已删除 `references/01-genre-routing.md` 的 `narrative` 豁免：叙述类不看论证链，但要按本条看「主张有没有支撑」）。
〔出处：`docs/DECISIONS.md` #56 ③ 红灯判据「主张无据」与 ④（删除体裁豁免）；`references/06-evidence.md` 的 `sourceType` 字段〕

## 五、已知局限

1. **`V1` 是「可追溯性」而非「真伪」**：一篇文章可以引用一份真实存在但质量很差的来源而通过 V1；本协议不替用户做事实核查（#13、`00-protocol.md` 硬规则 3「L1 不得省略」）。
2. **`V1`/`V4` 在无网络时都无法执行**：此时只能记 `degraded=true` 并把该条判为「未命中（无法执行）」——**不得**把「没查」写成「查过且通过」（#13）。
   - `gateHits[]` **只登记真正命中的条目**——「未命中（无法执行）」**不得**进 `gateHits[]`（登记条件是「有原文证据支撑命中」，见本文件开头「命中后果」与 `references/07-rating.md` R17）。
   - 筛选卡「风险识别」栏必须逐条写出**三态**之一，**不得**只写「未命中」：`未命中（已核查）` / `未命中（无法执行）` / `命中`。
   - 全篇若存在「无法执行」的条目，筛选卡「交付与边界」的「未核项」必须列出**是哪些条、因何无法执行**，并与该层的 `degradeReason` 同源（`references/00-protocol.md` §3 字段约束表 `degradeReason` 行）。
3. **计数与比值量级未经校准**：`M/N < 1/2`、≥3 处、>50%、<300 字都是工程约定，误杀/漏杀率未知；`DECISIONS.md` #55 已取消 30 篇锚例校准程序，这些量级只能靠用户日常积累的样本复核——复核只调计数/比值，**不改红灯的语义与条数**。
4. **`V3` 与正常商业内容的分界靠判断**：专业机构的技术白皮书带有产品倾向但不构成导流；「无独立信息」这一项在中文语料上需要判断者给出原文证据，否则容易变成口味判断。
5. **`V6` 依赖 L2 / L4 的产出质量**：L4 若漏报致命缺陷或 L2 未定位核心主张，`V6` 会系统性漏触发；反之，L4 若把「重要」误升为「致命」，会放大误杀。本条的正确性完全受制于上游层。
6. **8 条的边界互有重叠**：`V3`（软文）常伴随 `V4`（零增量），`V2`（不对齐）常伴随 `V6`（核心链断裂），`V7`（无收获）常伴随 `V8`（主张无据）。重叠时按「**命中即 `D`**」处理即可，但筛选卡里必须写出**实际命中的全部条目**，不得只写一条。
7. **本清单没有「时效性 / 版本过期」条目**：`genre-taxonomy.md` §2 表把「过期」列为技术参考类的失败模式，但它依赖版本知识、误判成本高，本次**不设为否决项**，改由四维里的 `D1`（信息增量）与 `D4`（来源与可核查性）承担。这是有意的取舍，不是遗漏；若日后积累的样本显示过期文章被系统性漏放，应新增 `V9`。
8. **`V7` / `V8` 是内容级判定，不是脚本可核**：「我找过哪三处」（`V7`）与「支撑是否全部为主观叙述」（`V8`）都需要判定者给出证据并分类；两条都是二元判据，但**机械可执行的是「成条条件」，不是「自动判定」**。
9. **红灯从 6 条增到 8 条，误杀面随之扩大**：`V7` / `V8` 是 `DECISIONS.md` #56 新设的两条（原 6 条里 `V1`–`V5` 引自调研清单），其中文长尾语料上的误杀 / 漏杀率未经实测；而 #55 已取消 30 篇锚例校准，样本改由用户日常阅读自然积累，**复核路径相应变慢**。
10. **（跨文件同步项，均已完成）** 原记录「契约硬规则 7「门禁先于总分」的 C 轨执行细则与本文件 §三 的适用性判据不一致；`references/08-track-c.md` 的 C 轨 `L6` 段为旧三值（`Reject` / `Borderline` / `Pass`）与 `S` 档」——两处**均已关闭**：契约侧由 lead 于 2026-10-14 改写为 `gateHits[]` 允许 `V2`–`V5` 与 `V7` / `V8`（`references/00-protocol.md` 硬规则 7「门禁先于总分」）；`08` 侧由 T-G1 包把 C 轨 `L6` 段改为五值档位并清除旧三值与 `S` 档。本文件按 `DECISIONS.md` #56（v1 分级定义，唯一真源）执行，与两处现行口径一致。
